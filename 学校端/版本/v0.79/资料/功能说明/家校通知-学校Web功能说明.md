# 家校通知｜学校 Web 功能说明

## 页面入口与范围

学校 Web 菜单“校务管理 → 家校通知”使用稳定菜单 ID family-notice。通知列表、编辑、预览、统计和相关弹窗通过统一菜单、顶部页签和页面宿主打开。

## 通知列表与发布设置

筛选条件包括通知来源、通知标题、通知类型、查收方式、发布状态和发布时间范围。发布状态为待发送、已发送；列表及发布设置不包含截止时间，也不提供“已截止”状态或筛选项。

列表显示通知来源、标题、发布名义、通知类型、查收方式、发布状态、发布时间、阅读与回执进度、创建时间、操作人和操作。编辑、删除及阅读统计根据通知状态和权限启用。

发布设置包括发布对象、查收方式、以学校名义通知和定时发送。发布对象可以按年级、班级或学生选择；查收方式为只需阅读、确认收到或签字确认。通知可立即发布或安排未来时间发送。

## 通知内容

通知内容包括标题、可选封面、正文、附件和全文背景。正文支持文本格式、文本/图片/视频/链接内容块；附件支持 PDF、Word、Excel 和 JPEG、JPG、PNG，最多 9 份，每份不超过 20MB。封面和正文图片建议使用 360×240px，图片展示不拉伸、不裁切。

保存草稿不会发送通知。发布和定时发送在本地原型中模拟；发布前可以返回修改内容或发布设置。已有接收记录的已发布通知不能修改发布对象、查收方式或发布时间。

## 阅读统计

学生统计以宽松、清晰的卡片展示学生总数、已读和未读；需要确认或签字的通知同时展示完成与待完成数量。筛选区和统计表格有清楚的间距。

学生统计可以按年级、班级筛选。班级行展示已读人数和学生总数。点击“明细”后，学生列表在当前班级下方展开，不跳到另一个页面，也不产生第二个返回按钮；可以按状态、学生姓名筛选并收起明细。

教师统计展示教师的阅读与回执状态。学生行“查看家长明细”打开该学生的家长回执弹窗。

## 家长阅读与回执明细

家长回执明细以表格逐家长展示家长姓名、操作时间和状态。家长姓名取回执提交时保存的家长快照名称；时间使用 YYYY-MM-DD HH:mm:ss。

- 只读通知：展示已成功阅读的家长，状态为“已读”。
- 确认收到通知：完成后状态为“已确认收到”；仅阅读但尚未确认时显示“已读”。
- 签字确认通知：完成后状态为“已签字”，并展示签字照片；仅阅读但尚未签字时显示“已读”。

同一家长对同一通知只允许一次成功确认或签字，操作完成后不提供再次提交或修改签字的入口。阅读记录可以重复查看，不会因此重复生成回执。签字照片列只在存在签字照片的回执明细中展示。

表格表头固定，中间内容区域可滚动；弹窗标题行和底部操作行固定。

## 预览、打印与演示边界

预览展示通知内容及适用附件；浏览器打印入口提供打印预览。页面、子页面和弹窗均在学校 Web 页面上下文中切换，合法路由可刷新恢复。

通知与回执数据保存在浏览器本地演示数据中，不连接生产权限、服务端持久化、真实消息推送或真实电子签收接口。通知查看、发布、提醒、筛选、校验和回执不写入学校操作日志。
