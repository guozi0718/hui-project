# 智小徽小程序

一个项目，内置可切换的教师、家长身份。每个版本保存完整双端原型及3份独立功能文档。

当前版本 **v1.22**：业务规则已确认、页面待验收。

| 身份 | 首页 | 通知 | 消息 |
|---|---|---|---|
| 家长 | [首页](版本/v1.22/端-家长/home.html) | [通知](版本/v1.22/端-家长/notification.html) | [消息](版本/v1.22/端-家长/msgs.html) |
| 教师 | [首页](版本/v1.22/端-教师/home.html) | [通知](版本/v1.22/端-教师/notification.html) | [消息](版本/v1.22/端-教师/msgs.html) |

文档：[通知](版本/v1.22/文档/通知功能产品需求文档.md)、[联系客服](版本/v1.22/文档/联系客服功能产品需求文档.md)、[客户反馈](版本/v1.22/文档/客户反馈功能产品需求文档.md)。文档不含截图。

每个业务页面有独立HTML入口；具体记录及视图状态用URL参数保存。教师端75个、家长端67个入口。入口文件复用共享运行时，后续逐步按功能拆分业务源码。页面对应关系见各端“页面路由.json”。

优先通过GitHub Pages或HTTP预览。直接双击本地HTML时，浏览器可能限制路径改写，自动退回可恢复的“#route=”地址；仍不会累积历史栈。未经同源服务不能假定多个file页面之间有生产级联动。

版本规则：复制当前完整版本为新版本，完成修改、同步文档、验证后更新“当前版本.json”“版本记录.md”，生成新版本文件清单并自动普通推送。已发布版本与标签保留，不覆盖。
