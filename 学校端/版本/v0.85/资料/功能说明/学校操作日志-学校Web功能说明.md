# 学校操作日志｜学校 Web 功能说明

## 页面入口

学校操作日志位于学校 Web“系统设置 → 操作日志”，用于查看学校人员成功提出反馈的记录。

## 记录规则

学校人员成功提交学校反馈后新增一条操作日志，操作类型统一为“提出反馈”。日志包含提交成功时间、操作人、反馈编号和反馈主题。

查看反馈或来源样例、查询与重置筛选、表单校验失败、权限校验失败、通知操作、阅读与回执、提醒及其他通知状态变化均不新增日志。

## 查询与列表

页面提供关键词筛选，可按反馈编号或反馈主题查询。“查询”应用关键词，“重置”恢复全部记录。

列表字段为操作时间、操作人、操作内容和反馈编号，按操作时间倒序排列，并显示当前结果数量。页面不展示通知、查看、查询、校验失败或系统提醒等日志。

## 演示数据边界

学校操作日志使用浏览器本地演示数据，不连接生产日志服务或生产审计数据。
