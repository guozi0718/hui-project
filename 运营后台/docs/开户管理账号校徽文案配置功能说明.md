# 监管账号与学校账号校徽文案配置功能说明

## 适用范围与业务边界

本功能在监管账号、学校账号的新增、编辑和只读详情中配置校徽文案替换。监管账号控制范围内的学校按继承规则展示；解除监管约束的学校可自行配置。账号开关关闭时不替换；账号开关开启且机构属于相应固定方案的适用范围时才执行替换。账号继承范围与固定方案适用范围相互独立，账号选择不得自动改写固定方案机构名单。

本功能只覆盖监管账号、学校账号的配置及选择学校弹窗；不提供独立的固定文案映射编辑、第三种替换类型、批量导入或生产端接入。

## 监管账号与学校账号设置规则

### 页面位置与共同规则

| 页面 | 设置位置 | 交互 |
|---|---|---|
| 学校账号新增、编辑 | 现有“审核配置”模块末尾直接展示校徽替换字段，不增加“校徽文案管理”小标题 | 只占一行：字段标题与其他表单标题统一右对齐，内容左对齐；主开关关闭时“替换类型”置灰禁用；受监管账号管控时开关和类型回显并置灰。 |
| 学校账号详情 | 现有“审核配置”模块内，校徽配置字段不增加独立小标题 | 只占一行，字段标签右对齐；开关和原生下拉框保留原表单样式并置灰禁用，回显当前保存值，不改为纯文字。 |
| 监管账号新增、编辑 | 原字段归入“基础信息”；新增“审核配置”模块，校徽字段直接置于该模块内，不增加“校徽文案管理”小标题 | 设置区严格两行：第一行标题右对齐且完整单行显示，内容左对齐；第二行标题必填并缩进，使“是否同步下级所有学校”的“是”与上一行“是否开启校徽文案替换”的“开”对齐。两行控件列保持对齐；主开关关闭时替换类型、同步开关和选择学校全部置灰禁用；同步关闭时“适用学校”、选择按钮和已选数量与同步开关同一内容行。 |
| 监管账号详情 | 与编辑页相同的“基础信息”“审核配置”分组；校徽字段直接归入“审核配置”，不增加独立小标题 | 设置区严格两行，开关、替换类型下拉框、同步开关及适用学校选择控件保留原表单样式并置灰禁用，回显当前保存值，不改为纯文字。 |

主开关默认关闭，替换类型默认“学生卡”；替换类型仅在主开关开启时可编辑。下级学校同步为必填项且默认开启；主开关关闭时同步开关和学校选择置灰禁用。替换类型选项为“学生终端”“学生卡”。标题列与其他表单标签共用右对齐基线，内容列左对齐；校徽标题不得换行，开关、替换类型标签和下拉框必须位于同一行。替换类型下拉框宽度为132px。监管配置仅占两行；第二行标题按本节对齐规则缩进，控件列仍与第一行一致。监管 ID 和监管—学校关系沿用平台已有标识和关系数据；本期不新增关系维护字段、关系选择器或关系保存逻辑。

账号设置只控制账号级的开启状态和替换类型，不扩展系统设置中的固定方案适用范围。实际发生替换须同时满足账号开启，且该机构位于所选替换类型对应的系统适用范围内；账号关闭时，即使机构在系统适用范围内也不替换。该范围限制作为业务规则保留，不在学校或监管账号设置区单独占行展示提示；详情页保留开关、下拉框等原控件样式并禁用，回显当前保存值。

### 学校账号设置

学校账号管理入口：新增或编辑学校账号
新增、编辑页面均在原有审核配置末尾直接显示校徽替换字段，不增加“校徽文案管理”标题，且配置只占一行：

- “是否开启校徽文案替换”为必填开关，默认关闭；其右侧同一行显示“替换类型”标签和下拉框。
- “替换类型”下拉项为学生终端、学生卡，默认学生卡；主开关关闭时下拉框置灰禁用。学校字段标题右对齐、内容左对齐；下拉框宽度约 132px，不拉伸填满剩余表单区域；标题、开关和下拉框垂直居中且不得换行。
- 无适用的监管账号设置时，学校账号可独立修改两个字段。
- 学校受监管账号同步或手动选中约束时，开关和类型按监管配置回显并禁用；学校不能自行覆盖监管要求。无监管约束时，学校主开关关闭仍使替换类型禁用。
- 即使学校账号开启替换，实际替换仍受系统设置中相应固定方案的适用范围限制；学校账号关闭时不发生替换。该范围规则不在账号配置区另加提示行。
- 新增页和编辑页均保留原有基本信息、审核配置字段和校验规则；本次不删改其他字段。

详情页在审核配置中以同一行展示“是否开启校徽文案替换”和“替换类型”，开关和下拉框保留新增/编辑时的原控件样式并置灰禁用，内容取当前账号保存值；字段标题右对齐、控件左对齐，不改成纯文字。

### 监管账号设置

监管账号管理入口：新增或编辑监管账号
#### 基础信息与审核配置

- 将监管账号原有字段置于“基础信息”分组，原字段值、顺序、校验和账号权限保持原状。
- 在其后增加“审核配置”分组，校徽配置字段直接归入该分组，不增加独立小标题。
- 配置严格两行。第一行标题列与其他表单标签统一右对齐，完整单行显示；内容左对齐。第一行与学校账号配置同结构：必填“是否开启校徽文案替换”开关，其后同一行排列“替换类型”标签和132px宽的下拉框。开关默认关闭，替换类型默认学生卡，主开关关闭时下拉框禁用。
- 第二行“是否同步下级所有学校”为必填项，显示必填标记并默认开启；标题缩进后，使首字“是”与上一行标题中的“开”字对齐，控件列仍与第一行相同。主开关关闭时同步开关和学校选择置灰禁用。主开关开启且同步关闭时，“适用学校”、“选择学校”按钮和已选学校数量/名称摘要与同步开关同一内容行显示，摘要超出一行时省略并可悬停查看完整名称；“选择学校”弹窗在表单上方居中显示，标题与底部按钮固定，中间学校列表区域纵向滚动；弹窗用于查看和变更选择；同步开启时隐藏适用学校控件。
- 设置区不单独增加系统适用范围提示行；替换仍受本章系统范围规则限制。
- 监管账号详情页保持相同两行结构，开关、替换类型下拉框和学校选择控件保留原控件样式并置灰禁用。同步关闭时第二行回显适用学校数量及名称摘要，名称超出一行时省略显示，完整名称可通过悬停查看；同步开启时只回显同步状态。详情不允许改值。
- 同步只决定账号级开启状态和替换类型继承给哪些学校账号；是否实际替换仍按本章账号状态与固定方案适用范围共同判断。

#### 同步下级所有学校

开启后，账号级设置覆盖该监管关系下全部现有学校及未来新增学校。学校账号的开关状态和替换类型均按监管设置回显并置灰；当监管开关关闭时，学校端同样显示关闭，但仍受监管账号控制，不能自行开启。未来新建学校识别到该监管关系后，默认纳入同步范围并按监管配置执行。监管账号保存替换类型或开关变更成功后，受同步约束的学校账号立即按新值回显；是否实际替换仍受当前固定替换方案的机构范围约束。

#### 同步关闭时的学校选择

- 首次进入手动选择时，默认勾选该监管关系下全部当前学校；已有配置按保存的学校稳定 ID 和明确排除的学校稳定 ID回显。
- 编辑已有监管账号时，按已保存学校 ID 回显勾选状态；不按名称比对。
- 用户可单选或多选；点击“选择学校”打开弹窗，弹窗只展示当前监管关系下的学校，不编辑监管—学校关系本身。
- 点击“确定”只更新当前表单草稿，点击“取消”、关闭或按 Esc 丢弃本次弹窗改动；只有保存监管账号后才提交设置。
- 被选中的学校按监管开关和替换类型执行，学校设置置灰。
- 未选中的学校解除该监管文案设置约束，恢复默认关闭、学生卡，并可在学校账号页自行修改。
- 同步关闭期间新关联到该监管 ID 的学校默认自动加入并勾选；用户在弹窗中取消勾选某校并点“确定”后，当前表单草稿记录该校稳定 ID 为明确排除项，保存监管账号后生效。此后刷新、重新打开或新增其他学校均不自动重新勾选该校。只关闭或取消弹窗，不记录排除项，也不改变表单原选择。
- 手动选中的学校与监管账号使用相同的账号级开关和替换类型，学校账号不可编辑；未选中的学校解除监管约束，恢复关闭、学生卡并可自行修改。
- 从“同步所有学校”切换为手动选择时，账号级继承范围从该监管下全部学校变为手动勾选集合；初次切换时当前学校默认全选，取消勾选并保存后，未选学校不再采用监管账号这套设置。
- 切回“同步所有学校”时，对全部现有与未来下级学校执行监管要求。再次切回手动选择时，按已保存的手动选择和用户明确取消记录回显。

### 学校选择弹窗状态

| 场景 | 页面表现与处理 |
|---|---|
| 存在下级学校 | 展示当前监管下的全部学校，每行学校名称及必要的区域识别信息、复选框；保留已有勾选。 |
| 当前无下级学校 | 展示空态，不伪造学校记录；弹窗仍可取消关闭。 |
| 名称重复 | 仍按学校 ID 分别显示、选择和计数；必要时用已有区域信息帮助区分。 |
| 用户单选、多选或取消 | 仅改变弹窗临时集合；确定后回写表单草稿，取消或关闭不改变原草稿。 |
| 保存账号时选择集未改变 | 按平台现有未修改处理，不因打开或取消弹窗而改动账号更新时间。 |
| 保存失败 | 不改变已保存监管或学校账号设置；保留当前表单草稿供修正。 |
| 监管—学校关系变化 | 学校范围取平台现有关系数据；关系维护仍由既有业务承担，本期不增加关系编辑入口。 |

### 状态组合

| 监管文案开关 | 同步所有学校 | 手动选中学校 | 学校端开关与类型 | 未选学校 |
|---|---|---|---|---|
| 关闭 | 开启 | 不显示 | 显示关闭；类型按监管回显；不可编辑 | 不适用，全部同步 |
| 开启 | 开启 | 不显示 | 显示开启；类型按监管回显；不可编辑 | 不适用，全部同步 |
| 关闭 | 关闭 | 已选 | 显示关闭和监管类型；不可编辑 | 默认关闭、学生卡；可编辑 |
| 开启 | 关闭 | 已选 | 显示开启和监管类型；不可编辑 | 默认关闭、学生卡；可编辑 |

学校端的开关和类型是两个互相联动的字段：受监管约束时二者一并锁定；解除约束时恢复独立学校默认值，之后可以自行修改。替换类型不因开关关闭而清空。

### 账号继承范围与系统适用范围

生效规则如下：

- 账号开关关闭时不替换；账号开关开启且机构在对应方案范围内时，才使用该方案；开启但不在对应系统范围内时，账号设置不覆盖系统范围。
- 监管账号保存成功后，按“同步下级所有学校”或手动已选范围，将最新开关和类型回显到受监管控制的学校账号。
- 监管账号设置区不额外显示系统适用范围提示；系统范围限制按前述规则执行。

“同步下级所有学校”默认开启并决定账号级设置的继承范围：开启时为监管下全部现有及未来学校；主开关开启后可关闭同步并手动选择范围，未选学校不采用同一套账号设置。主开关关闭时同步开关和学校选择不可编辑。用户已确认从全量同步切换到手动选择后，以手动勾选集合控制哪些学校继续继承。

账号继承范围根据同步开关和学校勾选结果自动变化；从全量同步切到手动选择后，继承范围缩为已选学校，未选学校解除监管账号约束。该变化只调整账号继承关系，不自动改写固定替换方案的机构名单。实际文案替换仍同时受账号开关/类型和系统固定方案适用范围控制。

## 校验与异常处理汇总

| 场景 | 处理 |
|---|---|
| 学校账号所属监管关系不存在或已变更 | 不沿用失效关系；按当前有效关系读取继承状态，无法确认时保留页面并提示重新读取，不写入推测配置。 |
| 监管账号没有下级学校 | 学校选择弹窗显示空态，不虚构学校；仍可取消关闭。 |
| 同名学校 | 按稳定学校 ID 分开展示和计数，并使用已有区域信息区分。 |
| 选择弹窗取消、关闭或按 Esc | 丢弃本次临时选择，不修改表单原草稿或已保存数据。 |
| 学校列表加载失败 | 显示读取失败及重试；不能误报为“暂无学校”。 |
| 保存账号失败 | 已保存配置不变；保留当前表单草稿，允许修正后再次提交。 |
| 账号保存时权限失效或版本冲突 | 拒绝覆盖并保留草稿；提示刷新或重新打开最新记录。 |
| 未选学校已被明确排除 | 通过稳定 ID 继续排除；刷新或新增其他学校不得自动重新加入。 |
| 学校从受控范围中移出 | 恢复学校独立默认状态：关闭、学生卡，并允许学校账号自行编辑。 |
| 固定方案范围外的机构开启账号替换 | 账号设置可被保存和继承回显，但实际替换受固定方案范围限制。 |
| 重复点击保存或结果未明确 | 保存处理中禁用重复提交；结果未知时先核对状态，不能直接重复写入。 |
| 只读详情或无编辑权限 | 保留开关、下拉框及适用学校选择控件的原样式并置灰禁用，回显当前值；不接受直接地址或脚本提交写操作。 |

## 交付边界

列表、表单、选择学校弹窗和详情中的数据为原型演示数据。页面表现不证明生产接口、账号权限服务或下游设备文案刷新已连接。

## 开户管理与校徽配置对应的操作日志

以下成功写操作进入系统既有“操作日志”菜单；本说明不改变该菜单位置，也不增加账号页内日志入口：新增/修改/删除监管账号，新增/修改/删除学校账号，重置账号密码，修改校徽活动配置，校徽文案适用范围调整。操作详情应标识账号或方案对象，并说明成功变化的配置类别和范围；密码和确认密码不得写入日志。

只有配置成功保存、密码成功重置或删除确认成功后才记日志。查看详情、未保存的开关/范围选择、学校选择弹窗内临时勾选、取消操作、校验失败、无权限、对象或版本冲突、保存失败及重复提交不记成功操作日志。因监管配置导致的下级学校回显或联动属于保存结果，在同一配置操作详情中说明，不伪造为多个学校账号人工编辑事件。
