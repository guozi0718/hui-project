# 运营后台操作日志功能说明

| 文档项 | 内容 |
|---|---|
| 文档版本 | v0.87（本地评审候选，未定版） |
| 适用端 | 智小徽运营管理后台 Web |
| 对应页面 | 系统设置 - 操作日志 |
| 文档范围 | 统一操作日志的记录边界、按功能区的事件类型、筛选和异常处理 |
| 样例边界 | 页面中的日志记录为原型演示样例，不代表生产审计服务已接通 |

## 1. 目标与范围

操作日志只记录运营后台前端用户主动发起且成功完成的业务写操作，供授权人员按时间、操作类型、操作人及对象追溯。页面继续放在当前“系统设置 - 操作日志”菜单位置；本次不调整菜单顺序、层级、路由和列表入口。

日志菜单只读。查看操作日志、查询和重置条件、筛选、翻页、展开详情都不生成新的业务操作日志。所有功能页面产生的日志汇入此菜单，不在各业务页面增加独立日志菜单或按钮。

本原型代码中的操作类型白名单共 61 项；下文按功能区逐项列出对应名称、成功记录条件和排除场景。

## 2. 记录判定规则

| 判定 | 规则 |
|---|---|
| 记录时点 | 业务写入已成功保存后记录；用户取消、提交失败、权限拦截、字段校验失败、版本冲突、重复提交失败均不产生成功操作日志。 |
| 去重 | 同一次成功提交只记录一次。超时或结果未知时先查询业务结果；确认已成功时不得再次补记，确认未成功后由用户重新操作。 |
| 自动后续动作 | 系统自动通知、自动同步、自动清理和自动提醒本身不单独作为用户操作事件；若它们是成功用户操作的后续结果，可在该用户操作的详情中说明。 |
| 无变化提交 | 未造成业务值变化且没有独立业务动作的重复保存不新增操作日志。用户明确执行了具有独立业务含义的动作（如重新获取数据、发送提醒、导出）时，按该动作成功结果记录。 |
| 访问与读取 | 查看、查询、预览、下载前的权限判断、访问受限、查询失败及空结果不写入本业务操作日志。安全审计由独立安全审计能力处理，不混入本菜单的成功业务事件。 |

## 3. 按功能区记录的成功事件

### 3.1 用户反馈

| 操作类型 | 记录条件 | 详情内容 |
|---|---|---|
| 提交反馈 | 反馈成功保存 | 反馈编号、来源角色、提交成功摘要 |
| 回复反馈 | 运营回复成功保存 | 反馈编号、操作人、回复摘要；按原规则触发的自动通知不另记一条 |
| 追问反馈 | 当前规则允许的代理商追问成功保存 | 反馈编号、代理商来源、追问提交摘要 |

详情查看、用户资料页打开、反馈列表查询、自动通知、提交校验失败、状态冲突和访问受限均不单独记日志。

### 3.2 家校通知

| 操作类型 | 记录条件 | 详情内容 |
|---|---|---|
| 代发通知 | 通知成功发布 | 通知编号、目标学校及发布成功摘要 |
| 定时发布通知 | 定时发布设置成功保存 | 通知编号、发布时间及保存结果 |
| 保存通知草稿 | 草稿成功保存 | 通知编号及保存结果 |
| 编辑通知 | 通知内容成功更新 | 通知编号及已修改内容的摘要 |
| 补充通知说明 | 说明成功保存 | 通知编号及说明已更新摘要 |
| 删除通知 | 二次确认后删除成功 | 通知编号及删除成功摘要 |
| 取消定时通知 | 取消定时操作成功 | 通知编号及取消结果 |
| 发送通知提醒 | 用户主动提醒成功完成 | 通知编号、提醒对象范围及操作成功摘要；不记录发送送达或已读结果 |

浏览通知、收件统计查询、打印预览、自动发送或自动提醒不独立记录。已读、过期、权限变化或保存冲突导致的拦截不形成成功事件。

### 3.3 开户管理与账号配置

| 操作类型 | 对应页面或动作 | 记录条件 |
|---|---|---|
| 新增监管账号、修改监管账号配置、删除监管账号 | 开户管理 - 监管账号 | 新增、修改或二次确认删除成功 |
| 新增学校账号、修改学校账号配置、删除学校账号 | 开户管理 - 学校账号 | 新增、修改或二次确认删除成功 |
| 重置账号密码 | 监管账号、学校账号等具备该动作的账号页面 | 密码通过校验并成功重置；日志不包含密码或确认密码 |
| 修改校徽活动配置 | 智能校徽配置 | 配置成功保存 |
| 校徽文案适用范围调整 | 校徽文案管理 | 适用范围成功更新；记录实际调整对象和范围 |

新增/编辑表单取消、查看页面、开关或范围选择未保存、重复保存无变化、密码校验失败和权限不足均不记录。

### 3.4 客户、合同、平台用户与角色

| 功能区 | 成功操作类型 |
|---|---|
| 客户管理 | 新增客户、编辑客户资料、删除客户 |
| 合同管理 | 新增合同、编辑合同、删除合同 |
| 平台用户 | 新增平台用户、编辑平台用户、删除平台用户、重置平台账号密码 |
| 角色管理 | 新增角色、编辑角色、删除角色 |

仅在对象成功新增、信息实际修改、删除确认通过或密码成功重置后记录。删除保护条件不满足、角色仍关联用户、表单校验失败和取消确认不记录成功事件。日志不得包含密码明文。

### 3.5 客服管理

| 操作类型 | 记录条件 |
|---|---|
| 新增平台客服、新增代理商客服 | 客服资料成功创建，并按客服归属区分事件类型 |
| 编辑客服信息 | 客服资料成功更新；详情写明实际变化字段 |
| 删除客服信息 | 依赖与默认客服校验通过，删除事务成功 |
| 关联代理商 | 客服与代理商关系成功新增或调整 |
| 关联学校 | 客服与学校关系成功新增或调整 |
| 设置默认客服 | 平台或代理商范围内默认客服成功切换；列出范围与新旧客服 |
| 修改学校负责机构 | 学校负责机构关系成功修改；如有自动解除客服关系，在该事件详情说明实际结果 |

取消关联弹窗、重复关联、未变化提交、默认保护拦截、版本冲突和权限失效均不记录。自动解除关系作为负责机构变更的后续结果描述，不伪装为单独的人工解绑动作。

### 3.6 智能校徽办理与物流

| 操作类型 | 记录条件 |
|---|---|
| 确认办理订单 | 确认资格、学校资料及订单状态复核通过，批次成功进入生产流程 |
| 取消办理 | 用户确认且取消资格复核通过，取消成功 |
| 发起退款 | 用户确认且可退校徽、退款金额及权限复核通过，退款申请成功建立 |
| 录入物流信息 | 承运商与物流单号核验通过并成功保存 |
| 承运商启停 | 二次确认后启用或停用成功 |
| 导出数据 | 任一支持导出的列表或生产数据文件成功生成并开始下载；记录菜单/业务对象、当前筛选范围及条数摘要；空结果、生成失败或下载未开始不记成功日志 |

表单校验失败、退款/取消资格变化、查询物流失败、确认弹窗取消、导出无数据等均不记成功事件。自动物流状态更新不单独记录。

### 3.7 发票管理

| 操作类型 | 记录条件 |
|---|---|
| 提交开票申请、编辑开票申请 | 申请成功保存；编辑仅在业务内容确有变化时记录 |
| 删除开票申请 | 允许删除的后台申请经二次确认删除成功 |
| 开具发票、换开发票 | 发票文件通过校验并成功保存；按操作前发票状态区分类型 |
| 重新发送发票 | 重发动作及收票邮箱校验通过并成功完成 |

查看申请、选订单、上传失败、邮件地址不合法、权限失效、删除被拦截及取消确认不产生成功操作日志。详情不得写入税号、银行账号等敏感字段值；原型若只模拟重发，应在操作详情明确未发送真实邮件。

### 3.8 系统配置与个人设置

| 操作类型 | 记录条件 |
|---|---|
| 新增常见问题、编辑常见问题、删除常见问题 | 内容成功保存或确认删除；编辑仅对实际变化记录 |
| 修改客服电话 | 电话号码通过格式与差异校验后成功保存 |
| 修改节假日配置 | 日期范围通过校验并实际更改后保存 |
| 重新获取节假日数据 | 用户主动发起且返回数据校验通过、页面配置已更新 |
| 发布节假日 | 发布确认通过并成功切换为已发布 |
| 编辑分享配置 | 图片与标题通过校验并成功保存；仅对实际变化记录 |
| 修改运营人员姓名 | 姓名通过校验并成功保存 |

预览图片、读取当前配置、读取失败、校验失败和取消不记录；自动定时生效不另记用户操作。

## 4. 统一日志字段和展示

| 字段 | 展示规则 |
|---|---|
| 操作时间 | 操作成功发生时间，按新到旧排列 |
| 操作人 | 实际操作账号当时的名称；历史姓名不随当前改名回写 |
| 操作类型 | 使用本说明各功能区列出的事件名称；类型筛选不包含查看、查询和失败类别 |
| 操作对象 | 可识别的业务对象编号或名称；支持按对象/详情关键词查找 |
| 操作详情 | 说明成功发生的具体变化或提交摘要；长内容可展开完整查看 |
| 来源 IP | 按原型已有列展示；本地演示值不代表真实网络审计来源 |

日志列表继续使用现有查询条件、类型筛选、操作人筛选、时间范围、分页和表格布局。此项只补齐功能事件定义，不移动或新增操作日志菜单。

## 5. 异常与边界

| 场景 | 业务数据结果 | 操作日志结果 |
|---|---|---|
| 必填项或格式校验失败 | 不提交；表单保留并提示修正 | 不写成功操作日志 |
| 提交时权限撤销或对象失效 | 拒绝写入；按页面规则提示并保留可恢复内容 | 不写成功操作日志 |
| 数据版本冲突 | 不覆盖新版本；提示重新读取 | 不写成功操作日志 |
| 用户取消新增、编辑、删除或二次确认 | 原数据不变 | 不写成功操作日志 |
| 保存返回失败 | 不声称保存成功；可按页面规则重试 | 不写成功操作日志 |
| 请求超时且保存结果未知 | 先核对目标记录状态，不盲目重复提交 | 未确认成功前不写；确认已成功时仅保留原有一条 |
| 查询结果为空 | 展示空结果 | 不写日志 |
| 日志读取或筛选失败 | 显示错误和重试入口，不能伪装成无数据 | 不生成业务日志 |
| 重复点击或重复提交 | 由业务防重规则阻止重复写入 | 同一业务成功结果最多一条事件 |

## 6. 原型边界与验收

本原型在本地浏览器中模拟写操作和日志行；不接入生产数据库、服务端身份、持久化审计、真实 IP、消息通道或第三方接口。不得把演示样例描述成生产审计记录。

验收应确认：日志菜单位置与现有路由不变；所有列出的成功写操作在成功后出现一条对应日志；详情查看、查询、分页、自动通知、权限拒绝、提交校验失败、取消和无匹配结果均不产生业务日志；不同功能区的操作类型可由既有类型筛选检索；敏感凭据不进入日志详情。
