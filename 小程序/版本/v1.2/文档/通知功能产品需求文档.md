# 智小徽小程序通知功能产品需求文档

文档版本：v1.2  
编制日期：2026-11-25  
适用产品：智小徽小程序，内置可切换的家长、教师身份。  
交付状态：业务规则已确认；可交互页面待验收。

## 1. 目标与范围

通知用于学校范围内的信息发布、接收、阅读、确认、签字及阅读统计。教师可在授权对象内发布普通通知、美文通知；家长与教师根据本人接收范围查收。发布成功后自动联动小程序消息及服务号消息。

家长首页只保留“通知”入口，位于“家校通讯”前，不再展示“家校通知”入口。教师首页“通知”位于功能宫格末尾。家长、教师沿用同端首页、消息Tab、“我的”、身份切换及统一视觉框架。本功能不包含家长发布通知、用户数据查询、客服配置、反馈受理或其他项目的后台改造。

本文件完整定义当前通知功能，可单独交付产品、设计、前后端及测试阅读，不需要结合其他需求文件理解。页面内演示说明仅面向技术开发，直接维护在对应原型中。

## 2. 身份、归属与权限

### 2.1 基础对象

| 对象 | 定义 |
|---|---|
| 当前账号与角色 | 同一账号在家长、教师身份下分别鉴权，不能因拥有另一身份而获得当前身份的管理权限 |
| 当前学校 | 当前教师任职学校，或当前家长学生所属学校 |
| 当前学生 | 当前登录家长所选学生；通知模块本身不另增加切换学生区域 |
| 发布人 | 通知创建角色与创建账号共同确定的本人，不以姓名相同判定 |
| 接收学生 | 进入发布对象名单的学生；由该学生当前有效绑定家长分别接收与办理 |
| 接收教师 | 发布对象名单中明确选中的教师本人 |
| 查收方式 | 只需阅读查看、需确认收到、需签字确认 |
| 消息已读 | 消息列表条目红点状态，与通知正文阅读回执分别保存 |
| 通知已读 | 有权接收人打开正文后成功登记的阅读状态 |

### 2.2 教师可见与可操作范围

| 身份与通知关系 | 查看正文 | 确认或签字 | 编辑 | 删除 | 阅读统计及家长明细 |
|---|---|---|---|---|---|
| 本校通知的发布教师本人 | 可以 | 本人同时在接收名单时可以 | 无任何人阅读时可以 | 随时可以，需确认 | 可以 |
| 本校其他教师，且在接收名单 | 可以 | 按查收方式可以 | 不可以 | 不可以 | 不可以 |
| 本校其他教师，不在接收名单 | 可以 | 不可以，不记录本人接收回执 | 不可以 | 不可以 | 不可以 |
| 其他学校教师 | 不可以 | 不可以 | 不可以 | 不可以 | 不可以 |
| 当前学生在名单内的有效绑定家长 | 可以 | 本人首次提交时可以 | 不可以 | 不可以 | 不可以 |
| 未登录、绑定失效或学生不在名单的家长 | 核验通过前不可以 | 不可以 | 不可以 | 不可以 | 不可以 |

所有写入必须再次核对账号、角色、学校、对象范围、通知存在性、内容版本和本人完成状态。隐藏按钮不能替代服务端鉴权。不得通过直接链接、缓存页面、手动调用动作或身份切换绕过校验。

### 2.3 编辑与删除

通知正式发布后，只要还没有任何接收人阅读，发布教师可以编辑。任何一个接收人产生阅读记录后，立即禁止编辑，仅读、确认、签字三种方式一视同仁。确认或签字也代表已经阅读，不能因阅读字段异常缺失而恢复编辑资格。

接收人读通知与发布人保存编辑同时发生时，服务端必须在同一次一致性校验中判定；阅读已成立就拒绝编辑，保留用户尚未保存的输入并提示刷新。消息列表“全部已读”不产生通知阅读回执，因此不锁编辑。

删除仅发布人可用，不受是否已读、是否完成确认或签字、发布时间长短影响。非发布人无编辑或删除按钮。删除前二次确认，取消不改变数据；删除成功移除通知正文及业务列表访问，保留消息历史和审计资料。删除失败、无权或版本冲突时不得提前移除卡片。

## 3. 教师端列表、搜索与详情

### 3.1 页签

| 顺序 | 页面显示 | 范围 |
|---|---|---|
| 1 | 校园通知 | 本校全部正式发布的通知，包括本校教师、学校端、代理商及平台发布的通知；保留本人待发送项目的既有展示 |
| 2 | 我发布 | 当前教师角色、当前本人创建的已发布或待发送通知，不混入其他账号或家长身份数据 |
| 3 | 我接收 | 当前教师本人明确位于通知接收名单内的已发布通知 |
| 4 | 草稿箱 | 当前教师角色、当前本人保存的草稿 |

校园通知不因当前教师所教班级而漏掉同校其他通知；“我接收”也不能因为可以浏览校园通知而纳入全部学校通知。其他发布人的草稿和待发送通知不得展示。各页签计数由当前搜索、筛选后的集合计算。

搜索按标题、发布人等当前范围信息匹配；点击搜索或当前既有即时搜索规则生效。筛选按通知状态、查收方式及通知类型执行，不扩大权限范围。无记录、无匹配和加载失败分别显示，不混成同一种空态。切换页签与筛选不增加页面栈。

### 3.2 卡片与详情

卡片展示封面、完整标题、来源和日期。校园通知与我发布的已发布通知展示汇总未读人数；需确认或签字时追加相应完成人数。接收卡片展示本人查收状态。未读统计以接收学生与教师对象为单位，家长人数不能直接加进学生总数。

详情展示标题、来源、日期、封面、全部正文与媒体、附件和查收方式，不展示截止时间。本人已发布通知可通过更多操作进入编辑、删除、存为模板、阅读统计；编辑被锁定时不展示可执行编辑动作，删除仍可用。本人待发送通知提供等宽编辑、删除按钮。其他教师只查看，处于接收名单时保留其本人应执行的查收动作。

进入详情、重新打开统计和收到新回执后，使用当前数据计算结果；不得固化为发布时或首次打开时的统计。加载失败保留当前通知上下文，提示重试，不将未知结果当作零人阅读。

## 4. 家长端列表与查收状态

### 4.1 列表

列表提供“全部”“待办”及计数、搜索和通知卡片。仅当前学生处于本次范围且账号具有有效关联时可查看。全部按发布时间倒序；待办表示本人尚未完成相应阅读、确认、签字的通知。其他家长已完成不替代当前家长的个人状态。

卡片显示封面、标题、来源、日期和本人状态。无封面沿用当前占位图。没有学生、无有效绑定、无通知、搜索无结果和读取失败各自有明确状态，不使用其他孩子或其他账号的数据补位。

### 4.2 状态机与按钮回显

| 查收方式 | 打开前 | 正文打开成功后 | 提交成功后 | 分享旁控件 |
|---|---|---|---|---|
| 仅读 | 请阅读通知 | 当前状态：已读 | 不需要额外提交 | “已阅读”，不可点击 |
| 确认收到 | 请点击确认 | 当前状态：已读待确认 | 当前状态：已读已确认 | “已确认收到”，不可点击 |
| 签字确认 | 请签字确认 | 当前状态：已读待确认 | 当前状态：已读已签字 | “已签字确认”，不可点击 |

首次有权打开正文才登记本人已读，重复打开保持首次阅读时间，不重复增加人数。阅读记录失败应提示同步失败，不假装已成功；重试不得重复计数。分享动作本身不记阅读、确认或签字。

确认收到点击后直接提交；成功立即回显完成状态并替换操作按钮，不要求返回列表再进入才生效。失败时继续保持可重试状态，明确告知未成功。签字必须有手写内容，空白签名不可提交；关闭签名板不产生签字，提交成功后立即回显完成状态。

### 4.3 每位家长仅一次提交

唯一办理关系为“通知＋学生＋家长账号＋家长角色”。同一关系只能成功确认或签字一次，不提供修改、重新签字、覆盖图片或撤销入口。同一账号关联多个范围内学生时，按学生分别办理。同一学生不同有效绑定家长分别办理，互不覆盖。

成功后再次点击、双击、刷新、换设备、从消息或分享链接进入，都读取原回执并显示已完成。并发请求、网络重试也不得追加第二条成功记录。签字图片、提交时间和内容版本均保持首次成功提交值。

结果不明确时先查询本人最新状态；已经成功则展示已完成，不要求再次提交；查不到成功记录才允许继续重试。明确失败不计入成功次数。离线原型演示不代替正式服务端事务、唯一约束与接口幂等。

## 5. 教师创建、编辑与内容资源

### 5.1 类型与限制

支持普通通知、美文通知，不提供独立链接通知类型，不增加背景音乐操作。普通通知在内容区编辑；美文按文本、图片、视频和链接模块组织，支持上移、下移、删除，首尾不可移动时禁用相应动作。显示顺序就是接收端阅读顺序。

| 字段或资源 | 要求 |
|---|---|
| 标题 | 必填，最多40字；超长拦截，详情允许完整换行 |
| 正文文本 | 最多3000字；至少一个有效文本或媒体模块，纯空白不视为有效正文 |
| 封面 | 可选、可替换；选择失败不清除已有图片 |
| 普通通知内容图片 | 最多9张 |
| 美文通知内容图片 | 最多60张，按全部模块累计，不能靠切换模块绕过 |
| 图片文件 | 有效图片、单张不超过10MB；读取失败可重试 |
| 视频 | 单个最长10分钟；无效或超时不能提交 |
| 链接 | HTTP或HTTPS地址；无效地址不能添加 |
| 普通通知附件 | PDF，最多5份，单份不超过20MB |
| 段首 | 非空文字段落默认两个可编辑删除的全角空格，回车新段同样处理 |

美文模板可含随素材已有的资源；继续使用本地实际支持的模块和资源校验，不编造缺失正文或素材。新增资源必须按当前编辑入口适用的限制校验。

封面及正文图片按原图比例缩放，最大显示宽度360px、居中、圆角，不裁切成固定比例。360×240px仅为建议尺寸。图片建议提示只放在编辑页封面区域，不在正文阅读页重复铺设。

### 5.2 预览、模板与草稿

预览只读展示当前输入；返回保留内容、顺序、图片和背景。美文可选择简洁白底、清新绿底、暖色信纸背景。切换背景不丢正文，取消保持原值。

模板中心提供分类、搜索、预览和选用，目录包含138项。没有可核验正文或图片时明确显示资料状态，不用其他内容补造。目录数量不代表逐项完成内容验收。个人模板按当前教师角色和账号隔离；选用模板不能静默覆盖未保存输入。

草稿保存当前标题、正文、封面、附件、背景以及已填写的发布设置，未完成字段也可保存；不产生接收消息或发送任务。再次打开应完整回显。预览、正式发布执行字段校验。草稿仅本人可见，删除需确认。

离开未保存编辑时二次确认。保存失败、存储不足或校验失败保留输入。遇版本冲突不覆盖其他端的新内容，可比较、载入最新或保存为独立草稿；通知被阅读而锁定时不能强行覆盖。

## 6. 发布设置、长期有效与定时发送

### 6.1 发布设置

发布对象支持学生、教师，至少选择一个有效对象。学生按年级、班级、人员选择；教师按当前教师可发布权限选择。整班与单人选择去重，已选人数、全选、全不选状态一致。当前界面不直接选择单个家长，家长由学生绑定关系展开。

查收方式必选。以学校名义发布使用既有权限开关，开关无权时不能伪装学校身份。定时发送默认关闭，关闭立即发布；开启默认次日09:00，选择年月日及精确到秒的时分秒，必须晚于当前时间。

### 6.2 通知无截止限制

发布设置不展示截止时间字段；通知没有默认30天截止。所有来源——教师、学校端、代理商、平台——在小程序里均不再按截止时间限制查看、确认、签字或提醒。已有通知中留存的截止值也不再产生限制。

长期有效不扩大身份或对象权限。通知被删除、绑定失效、账号无权或不属于范围时仍阻止访问和提交。每位家长只成功提交一次的约束始终生效。

发布对象按学生名单、整班关系及已形成的接收记录处理。整班新加入的范围内学生、该学生新建立的有效家长绑定可以续接消息；无效关系不能接收新投递。转班或离校不抹除已成立的阅读、确认和签字历史。对象统计每次读取当前有效接收集合与已保留回执，不能把历史回执物理删除。

### 6.3 定时发送

保存定时后状态为待发送，仅发布人可管理；此时不向接收名单发送小程序消息或服务号消息。到正式发布时刻，重新校验对象与发送条件，状态转已发布，建立接收范围并自动联动两渠道消息。发送动作应幂等，任务重复执行不重复创建通知或消息。

定时前编辑保存应回显已设内容和对象；删除待发送通知后不得到点发送。客户端未打开不应阻止正式系统的服务端定时任务；离线HTML只演示定时状态处理，不能声称已部署真实后台任务。

## 7. 阅读统计、家长明细与提醒

### 7.1 汇总规则

发布人可查看统计，按学生、教师分别计算。只有学生或只有教师时，隐藏顶部单一类型页签；两类都有时保留学生/教师切换。未读、已读未确认或已读未签字、已完成等筛选从同一对象集合及回执计算，不出现互相矛盾的数量。

学生阅读：任一有效接收家长产生阅读即算该学生已读。学生确认：任一家长成功确认即算该学生已确认。学生签字：任一家长成功签字即算该学生已签字。5位家长签字仍是1名学生完成，不计5名学生。教师按本人计算。

阅读统计每次打开、重新进入或刷新时重新读取当前回执。其他端产生回执后应同步或刷新重算；加载失败不覆盖已经确认的有效结果。

### 7.2 完成学生行“明细”

需确认、需签字通知中，已完成学生行右侧使用按钮“明细”，不再以该位置的“已确认”或“已签字”文字作为静态状态。未完成行保留原未读或已读状态；教师统计不套用家长明细。

点击明细打开底部弹窗，显示学生与明细标题，仅列实际成功提交的家长记录。1位提交展示1条，5位提交展示5条；未提交家长不填入空白记录。按提交时间倒序，时间相同时使用稳定顺序，不因刷新乱序。

记录展示提交时家长姓名、当时关系（有值时）、提交时间、完成状态。签字记录额外展示签字缩略图，点击查看原图；原图可关闭，关闭回到原明细及滚动位置。关闭明细回到原统计页签、筛选与位置。确认收到明细没有签字图片或图片占位。

签字图片加载失败显示失败提示，不影响姓名、时间及完成状态，也不能将成功签字改成未签字。缺图时提供可关闭的状态，不制造空白不可退出层。家长后来解绑或修改姓名不抹除提交快照，不将姓名回显为当前另一位家长。

非发布人、家长、跨学校、无效学生对象无法打开他人明细。打开弹窗及原图时都要复核权限；无权或通知被删除时提示并提供关闭，不泄露缓存图片。

### 7.3 提醒未读

仅向本通知当前仍未读的接收对象提醒。学生单位未读时向其有效关联家长触达，教师按本人；不能向其他学校、范围外、无效绑定或已经完成阅读对象误发。无未读或通知已删除时不能继续提醒。

通知不设截止，发布人可持续使用提醒未读，直到全部已读或删除。提醒失败不改变阅读回执，不假装已送达；重试不得制造重复业务办理记录。

## 8. 自动消息联动

### 8.1 触发、对象与去重

正式发布时，范围名单内的接收人自动形成小程序站内消息和服务号发送事件。家长按“通知＋学生＋家长账号”建立消息，教师按“通知＋教师角色＋教师账号”建立消息，学校及角色信息参与隔离。同一位家长有多个范围内孩子时各孩子一条，摘要明确学生，点击按对应学生核验并办理。

未读编辑、定时正式发布、新纳入的学生或新有效绑定家长触发范围同步。已有唯一消息不重复新增；尚未阅读的通知修改后读取当前内容，不能继续打开旧内容快照。已建立消息的读态不因同步被无故重置。

草稿和待发送都不生成接收消息。通知正式发布成功、站内可见与外部渠道送达分别记录，不能以外部渠道的失败回滚已经成立的通知。

### 8.2 小程序“消息”Tab

复用当前端的消息头部、时间状态栏、未读/已读/全部消息页签、全部已读、类别及时间筛选、列表卡片、分组、空态及底部导航。增加“通知”类别，通知消息与原有业务消息共存，不改动其他类别的业务行为。

条目显示通知标题、来源、学生（家长适用）及查收要求。条目红点按当前账号独立保存；“全部已读”只改变消息读态，不代表已读正文，不代表已确认、已签字，也不触发通知不可编辑。底部消息Tab保持当前框架的角标规则。

点击消息先核验登录身份、学生绑定、学校及本次对象范围，再打开当前正文；实际打开后才登记通知已读。返回消息页保留原筛选。通知被删除后保留消息条目，点击提示“通知已删除”，不能打开正文。账号无权、关系失效或范围外时明确提示，不回退展示其他通知正文。

### 8.3 服务号消息

复用服务号消息示例卡片，包含通知标题、学校或发布来源、学生（家长适用）、查收要求和查看入口。服务号消息与站内消息指向同一通知及学生对象，不另建一套确认、签字或阅读统计。

未关注、授权不足、发送失败、接口异常和重试结果分别记录。服务号无法送达时，通知发布成功与小程序站内消息仍成立；不能向用户宣称服务号已成功送达。发送去重以渠道、事件和接收关系为依据，外部重试不重复创建站内消息。

业务目标是自动触达范围内接收人；正式集成必须按微信实际能力与返回结果处理，未取得送达结果不得假定全部送达。原型只演示服务号卡片、成功或失败状态，不发送真实微信消息。

## 9. 分享、登录与站外落地

分享提供微信好友/群、复制链接，分享信息为标题、封面与受控标识，不通过链接公开正文、附件、签字或其他家长记录。查收依然回到同一条通知、当前学生与本人账号。

### 9.1 游客态

游客点击分享链接先进入现有登录页，不直接展示正文。登录完成后使用当前账号与当前登录学生核验该学生是否在本次通知范围，并核验有效绑定。未完成登录不记录阅读，不可确认或签字。登录失败、取消或无当前学生时不得默认核验通过。

### 9.2 已登录账号

已登录也要核验。范围内进入小程序现有通知详情框架，保留状态栏、顶部返回按钮与标题行、正文、分享与本人查收状态。该详情顶部返回到首页“通知”入口对应的通知列表，不返回站外仿页面。

范围外显示落地文案：“您不在本次通知范围内，请联系管理员。”关闭后返回首页，不显示正文。无权状态不泄露收件名单、其他家长身份或签名。

### 9.3 非微信环境打开

站外落地页保留状态栏，正文提示：“请登录微信智小徽小程序，核验通过后查看该通知。”只提供右上角关闭，不提供普通小程序返回箭头、通知正文或确认签字按钮。原型关闭返回安全首页；真实站外容器的关闭由实际宿主能力处理。

页面演示集中提供游客态、登录账号、站外打开三个入口。登录页可演示范围内和范围外核验，不能将演示登录成功当作真实鉴权成功。

## 10. 异常与一致性处理

| 场景 | 处理要求 | 不得发生 |
|---|---|---|
| 通知不存在、被删除 | 保留明确提示和关闭/返回路径，已发消息保留 | 展示缓存正文或跳到另一通知 |
| 身份、学校、范围不符 | 禁止读取与写入受保护内容，提示无权 | 仅凭链接或同校浏览权办理查收 |
| 家长绑定失效 | 阻止新查收与新投递，成功快照保留 | 删除已签字记录或冒用新绑定关系 |
| 两位家长分别提交 | 各保留本人记录，学生汇总只计1人 | 覆盖他人记录或计成2名学生 |
| 同一家长并发提交 | 只保留一次成功，返回已完成 | 追加多张签字或改写首次时间 |
| 通知版本变化 | 刷新正文及当前状态，保留未提交输入 | 按失效版本静默确认或签字 |
| 阅读与编辑并发 | 复核锁定并拒绝过期编辑 | 阅读成立后仍覆盖正文 |
| 网络失败 | 明确失败可重试，不改变完成态 | 提示成功却未保存 |
| 结果不明确 | 先查询本人状态再决定是否重试 | 直接引导重复提交 |
| 存储不足 | 保存失败提示，保留可恢复输入 | 清空内容或当作成功 |
| 空白签字 | 拦截并保留签名板 | 保存空白图片回执 |
| 图片或附件失败 | 提示失败，正文其他内容可读，弹层可关闭 | 覆盖通知、改变成功查收状态 |
| 无统计记录 | 展示真实零值或相应空态 | 将加载失败当作零值 |
| 单一统计对象 | 隐藏冗余类型页签，筛选继续可用 | 空白类型切换或错误计数 |
| 服务号失败 | 站内消息和发布保留，分别记录失败 | 伪造送达或撤销通知 |
| 定时重复执行 | 一次发布、消息按唯一关系去重 | 提前发消息或重复创建 |
| 通知有过往截止字段 | 不再据此限制查看、查收与提醒 | 继续按30天自动禁用 |
| 切身份、切学生 | 重新校验上下文，回执与消息隔离 | 教师权限穿透到家长，或孩子串数据 |
| 多次开关弹层 | 逐层关闭并恢复来源位置 | 一次关闭跨越多层或失去返回出路 |

真实实现应保存通知标识、学校、来源角色、发布账号、内容版本、发布时间、接收范围、提交快照及审计事件；消息保存通知/学生/账号/角色/渠道和发送结果。统计从唯一接收对象与成功回执聚合，展示缓存不得成为权限或成功判定依据。

正式接口需保证编辑锁、确认签字唯一性、删除与读取竞态、定时发布和渠道发送的事务或等效一致性。通知删除后不得继续发出迟到任务；客户端迟到响应必须与当前通知、身份和页面请求对应，不能覆盖另一个对象。

## 11. 视觉、演示与页面栈

画布390×844 CSS px；状态栏44px、标题行44px；标题16.5px/700、颜色#233047，时间及系统状态、返回箭头、胶囊、按钮字号配色均复用当前端框架。真实小程序按设备安全区和原生能力适配，不能把固定原型尺寸当成所有设备的屏幕尺寸。

业务页面具备独立HTML文件入口、对象参数和可恢复路由；例如通知详情、阅读统计、编辑各有独立文件，通知ID区分具体记录。当前共用原型运行时，后续随功能修改逐步拆分源码。通知列表、页内Tab、详情、编辑、预览、设置、统计、底部明细和签字原图在现有容器中切换。演示说明、筛选和同页状态切换不新增业务页面，不以反复跳转制造无界栈增长。消息与通知之间仅保存明确来源上下文，返回恢复对应列表。

开发演示说明跟随页面、页签和弹层变化。说明入口复用当前宽屏侧栏、窄屏浮层、搜索、折叠与更多场景操作。业务页面不加入技术调试开关。HTML验证与微信真实页面栈验证分别记录。

## 12. 验收条件

1. 家长首页只有通知入口，没有家校通知入口；教师首页入口顺序保持正确。
2. 校园通知覆盖本校各来源；我发布仅本人教师角色；我接收严格按名单；其他学校和他人草稿不可见。
3. 非发布人没有编辑删除；三种查收方式任一人阅读后锁编辑；发布人随时可删除。
4. 所有来源与已发布通知无截止限制；发布设置、详情不显示截止字段或默认30天提示。
5. 草稿保存完整内容和已填设置；定时未到无接收消息，到点正式发布才联动两渠道。
6. 仅读打开即已读且显示不可点击已阅读；确认成功即时显示已读已确认与已确认收到；签字同理。
7. 空白签字失败；同一家长同一学生通知只提交一次，刷新、重复点击与其他入口不能修改首次成功结果。
8. 单类型统计隐藏顶部类型条；两类型切换保留；统计每次打开读取最新回执。
9. 完成学生行按钮为明细，1位/5位家长分别1条/5条，学生汇总均1名；按时间倒序。
10. 签字缩略图可开原图并逐层关闭；确认无签字图片；解绑后提交快照仍在。
11. 消息复用现有框架并支持读态、通知类别及时间筛选；全部已读不更改通知回执。
12. 多孩子按孩子分条；范围同步不重复生成；删除后消息保留且正文不可打开。
13. 服务号失败不影响通知与站内消息；不得将本地演示记作真实推送成功。
14. 游客先登录核验，范围内正常小程序详情且返回通知列表；范围外提示关闭回首页；站外仅提示及右上角关闭。
15. 网络、权限、存储、并发、图片失败、版本变化及定时重复执行符合异常矩阵。
16. 客服、反馈和未涉及页面维持既有内容；双端身份互切、返回与资源完整性通过；真实生产鉴权、微信投递和原生栈须独立验收。
