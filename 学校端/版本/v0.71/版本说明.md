# 学校 Web v0.68

学校 Web v0.68 是学校端主菜单、页签、学校反馈及家校通知页面的最终原型版本。统一入口管理菜单切换、页签切换和页面内容加载；点击已接入菜单显示对应页面，并保留查询参数恢复子页面与弹窗。

学校反馈保留来源筛选、关联学生快照及学校专属字段边界。教师和家长演示样例可打开运营后台人员资料。学校操作日志只记录成功提出反馈。

家校通知的学生统计使用宽松卡片布局；班级明细在当前页展开；家长回执显示快照姓名、精确操作时间和结果，签字回执显示照片。发布设置和筛选不提供截止时间或已截止状态。

学校端一级菜单默认折叠，内容区左右留白 24px，通知筛选区保留边框。弹窗标题行与底部操作行固定，正文区域独立滚动。菜单及页签不使用小红点。

本版包含三个独立功能说明，无截图、无历史说明、无跨文档版本引用。所有运行页面与资源随版本包保存；后续学校端变更在 `hui-project/学校端` 中创建新版本并更新固定入口。
