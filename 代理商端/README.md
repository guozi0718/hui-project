# 代理商 Web 主菜单原型 v0.81

状态：最终版本。GitHub 仓库 `guozi0718/hui-project` 的 `代理商端` 目录是代理商 Web 的唯一维护目录；后续修改在该目录持续版本化，不再关联功能项目。

## 固定入口

[打开代理商主菜单](https://guozi0718.github.io/hui-project/%E4%BB%A3%E7%90%86%E5%95%86%E7%AB%AF/index.html?page=family-notice)

入口必须通过 `index.html?page=family-notice` 进入，以确保首次打开呈现实际页面。后续在左侧菜单切换功能，顶部页签保持统一管理。

## 菜单与稳定页面地址

| 菜单 | 地址参数 |
|---|---|
| 校务管理 → 家校通知 | `page=family-notice` |
| 客服管理（一级菜单） | `page=cs` |
| 用户反馈 → 学校反馈 | `page=school-feedback` |
| 用户反馈 → 代理商反馈 | `page=agent-feedback` |

智能校徽、资金结算、系统管理沿用本版现有菜单结构。所有已接入页面由统一主菜单与页签宿主管理；菜单切换显示目标主页面，加载失败显示明确状态和重试入口，不以空白内容代替失败提示。

## 最终视觉与交互规范

- 家校通知封面建议使用清晰素材 `900×383px`；正文配图建议上传宽 `1080px` 的清晰原图。
- 通知详情和模板预览中的封面最大 `320×136px`，正文配图最大 `320×180px`；按原图比例缩放、居中完整显示，不裁切。
- 正文图片不使用固定大画框，不保留多余留白。
- 封面控件下方提示显示为一行，首字与“未设置封面”左侧对齐。
- 弹窗标题行和底部操作行固定；仅中间内容区域滚动。
- 菜单和页签不显示未读小红点或计数徽标。
