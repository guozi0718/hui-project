# 代理商 Web v0.81 定版字段清单

状态：最终版本。清单记录当前锁定的菜单结构、统一页面入口、封面与正文图片规范及共同交互。

| 类别 | 定版值 | 行为/约束 |
|---|---|---|
| 固定入口 | `index.html?page=family-notice` | 首次进入显示家校通知实际主页面，禁止空白入口 |
| 校务管理 | 家校通知，稳定 ID `family-notice` | 左侧二级菜单点击切换主页面，顶部建立对应页签 |
| 一级菜单 | 客服管理，稳定 ID `cs` | 位于校务管理之后，点击直接展示客服主页面 |
| 用户反馈 | 学校反馈 `school-feedback`、代理商反馈 `agent-feedback` | 作为同一一级菜单下两个二级菜单切换页面 |
| 其他菜单 | 智能校徽、资金结算、系统管理 | 延续当前菜单结构；未接入页面显示明确状态，不以空白代替 |
| 页面加载 | 统一菜单登记、主页面加载、顶部页签管理 | 任意菜单点击后显示对应实际主页面；加载失败提供状态说明和重试入口 |
| 页签关闭 | 依主原型已定版的页签关闭规则处理 | 关闭后不得退回空白或错误页面 |
| 通知封面上传 | 建议使用 `900×383px` 高清素材 | 提示文案位于封面控件下方，单行展示，首字与封面预览左侧对齐 |
| 正文配图上传 | 建议上传宽 `1080px` 的清晰原图 | 上传提示为正文图像素材建议，不限制原型中的演示内容 |
| 通知封面显示 | 详情和模板预览最大 `320×136px` | 宽高均受限，保持原图比例，水平居中完整显示，不裁切 |
| 正文配图显示 | 详情和模板预览最大 `320×180px` | 宽高均受限，保持原图比例，水平居中完整显示，不裁切 |
| 正文图片容器 | 无固定大画框、无额外大块留白 | 图片按实际比例呈现，图片周边仅保留必要段落间距 |
| 弹窗通用布局 | 标题行固定、底部操作行固定 | 仅中间正文区域滚动，关闭或完成后回到原页面上下文 |
| 未读标记 | 不显示任何小红点或计数徽标 | 左侧菜单、顶部页签均无此类提示 |
| 说明文档 | 三个独立完整 Markdown，不放截图 | 每份各自说明该功能入口、权限、字段、操作、校验、异常和恢复方式 |
| 维护来源 | `guozi0718/hui-project` 的 `代理商端` 目录 | 代理商 Web 后续修改只在该目录按版本管理 |
| 运行环境 | 静态原型、示例数据 | 无生产接口、持久化服务、真实权限校验或消息发送 |
