# 用户反馈演示说明

## 页面用途与入口

“用户反馈”为代理商 Web 一级菜单，包含“学校反馈”和“代理商反馈”两个入口。

- “学校反馈”用于处理当前代理商负责学校在代理模式下产生的学校、教师或家长问题，入口地址为 index.html?page=school-feedback。
- “代理商反馈”用于查看代理商本人或当前代理组织向运营提交的问题，入口地址为 index.html?page=agent-feedback。
- 两类记录按不同权限和问答状态处理，不在同一列表合并，也不互相改变状态。

## 数据权限与记录类型

| 记录来源 | 代理商可见范围 | 代理商可执行操作 |
|---|---|---|
| 学校、教师或家长在代理模式提交 | 当前代理商仍负责的学校 | 记录待回复时答复一次；答复后查看 |
| 学校、教师或家长在直营模式提交 | 不显示在代理商列表 | 由运营后台处理 |
| 代理商本人或组织提交给运营 | 当前账号或组织有权查看的代理商自有记录 | 新增首问；收到运营答复后在原记录追问 |
| 不属于当前代理商或已失去负责关系的记录 | 不可查看 | 不允许打开、回复或追问 |

受理模式、当前负责学校和组织权限以记录提交及当前查询时的有效关系为准。学校反馈详情不会显示代理商自有记录；代理商反馈详情不会变成学校、教师或家长收到的回复。

## 学校反馈列表

### 筛选与字段

- 所在地区选项取当前代理商负责区域和负责学校所在区域的合集；无负责关系的地区不出现。
- 选择地区后，所属学校候选按当前可负责范围收窄。改变地区后清除已经不适用的学校选择。
- 可按反馈人、联系电话、反馈类型和状态筛选。反馈类型为“功能建议”和“问题反馈”；状态为“全部”“待回复”“已回复”。
- 点击“查询”应用所有条件；“重置”清空自填条件、恢复默认选择并回到第1页。
- 列表显示来源、反馈人、联系电话、关联学生姓名、地区、所属学校、反馈类型、内容、首次反馈时间、状态和操作。联系电话按页面的脱敏显示规则处理。
- “关联学生姓名”位于联系电话之后：家长来源只读取提交时保存的学生姓名快照；老师或学校来源，以及缺少家长学生姓名快照的记录均显示“--”。不读取实时学生资料补值。
- 列表排序采用记录最近更新时间从新到旧；时间列显示首次反馈时间。查看详情或日志不会改变记录更新时间和列表顺序。

待回复的学校、教师或家长来源记录只显示“回复”；已回复记录只显示“查看”。列表中不放通知按钮或行内日志按钮。

## 学校反馈详情与回复

详情保留“反馈人信息”块，依次显示反馈来源、反馈人、联系电话和关联学生姓名；关联学生姓名紧跟联系电话，仅家长来源读取提交时保存的学生姓名快照，老师/学校来源或快照缺失显示“--”，不回退实时资料。该信息块不显示反馈编号；反馈编号仍在详情内容区显示。学校反馈详情保留地区和所属学校。标题、正文、附件、反馈类型、状态及消息时间线按当前记录展示。

仅在学校来源记录当前仍为代理模式、代理商仍负责该学校且最近消息等待代理商回复时显示“回复”。回复正文必填，1—1000字；输入框显示计数，超出限制不能继续输入或提交。快捷回复仅填入当前草稿，不会直接发送。附件可选，支持 JPEG、JPG、PNG，最多9张，每张不超过10MB；文件读取完成前不能提交。

点击提交时重新检查代理商责任关系、受理模式、记录状态和最近消息方向。成功后新增一条代理商回复并把状态更新为“已回复”，之后该记录只允许查看，不允许第二次答复或追问。

图片点击后可预览原图。单张图片无法打开时，其他正文和附件仍可查看。关闭详情返回原列表筛选、页码和滚动位置；查看不会改变状态。

## 代理商反馈列表、新增与追问

### 列表

代理商反馈只展示当前登录代理商本人或当前组织有权访问的记录。可按反馈类型、状态和反馈时间筛选；类型为“功能建议”和“问题反馈”，状态为“全部”“待回复”“已回复”。列表按最近更新时间从新到旧排列，显示来源、反馈人、联系电话、类型、内容、首次反馈时间、状态和操作；筛选、列表和详情均不显示所在地区或所属机构。

详情中的“反馈人信息”块显示反馈来源、反馈人和联系电话，不显示所在地区或所属机构；反馈编号显示在详情内容区。代理商首问后等待运营处理，状态为“待回复”，只显示“查看”。运营回复后，状态为“已回复”，显示“追问”。提交追问后状态回到“待回复”，等待运营下一次答复。首问、每次追问及运营回复都属于同一反馈编号；问答严格交替，轮数不限。

### 新增首问

点击新增后必须选择反馈类型，填写标题1—50字、正文1—200字。标题和正文去除首尾空白后仍需有内容；实时计数，超出上限阻止继续输入和提交。可添加 JPEG、JPG、PNG 图片，最多9张、每张不超过10MB。提交前再次确认当前代理商身份和组织权限。成功后生成唯一代理商反馈编号，状态为“待回复”。

### 继续提问

只有最近一条消息来自运营、当前记录状态为“已回复”时才能追问。追问正文必填，1—1000字，可选同规格图片附件。提交后仍使用原反馈编号并等待运营答复。运营未答复时不得连续新增代理商问题。

## 消息、通知与操作日志

- 已提交反馈、首问、追问和回复均不可修改；页面不提供编辑、删除或撤回操作。
- 学校来源反馈由代理商成功答复后，自动向原反馈提交账号及其来源端触发一次通知。
- 代理商自有反馈由运营成功答复后通知代理商；多轮问答中每次运营答复成功后各触发一次。
- 固定通知文案为：您提问的“{{首条反馈信息前五个字}}”问题已有回复，请查看。变量取首条反馈正文从左至右前五个字符，不足五个字符时使用全部正文，不取标题、追问或回复。小程序消息和服务号消息使用同一文案。
- 代理商端不提供手动通知、补发或重试入口。回复保存成功但通知渠道不可用时，回复仍有效；页面不展示送达、失败或已读状态。
- 代理商和运营端发出的回复作者统一显示“平台客服”，不显示客服姓名；反馈人自己的提问仍显示其提交身份。
- 操作日志只读，位于“系统管理 → 操作日志”。列表和详情不提供行内日志按钮。日志按操作时间从近到远显示操作时间、操作人、角色、模块、类型、内容、相关学校和结果；超长详情悬停可读全文。查看日志不改变反馈更新时间、状态或排序。

## 异常与处理结果

| 异常场景 | 页面处理 |
|---|---|
| 查询无匹配数据 | 显示空结果和当前筛选条件，不报系统故障 |
| 列表查询失败或超时 | 保留筛选条件和当前页，不把旧数据当新结果；由用户再次查询 |
| 当前页数据变化后为空 | 回到有效页码并提示列表已更新 |
| 代理商负责区域或学校关系变化 | 移除不再负责的记录并重新查询，不保留过期权限 |
| 学校来源记录转为直营模式 | 阻止代理商打开或回复，提示记录当前由运营处理 |
| 编号缺失、无效、记录已失效或无权访问 | 不显示空详情、不切换到其他记录；保持列表可用 |
| 打开回复后其他代理商已回复 | 提交被阻止，显示最新记录，不重复写入答复 |
| 回复前失去负责权或受理模式变化 | 不提交、不泄露新的处理方信息；保留草稿，关闭后刷新列表 |
| 类型未选择、标题为空或全空格、标题超50字 | 阻止新增；定位对应字段，保留其他输入和附件 |
| 首问正文为空、全空格或超过200字 | 阻止提交；不截断合法输入，保留草稿 |
| 回复或追问为空、全空格或超过1000字 | 阻止提交并说明长度要求，保留正文和附件 |
| 运营尚未答复时代理商连续追问 | 阻止新增消息，记录保持“待回复” |
| 附件不是 JPEG/JPG/PNG | 拒绝无效文件，保留正文和其他合规附件 |
| 单条消息超过9张附件或单张超过10MB | 不加入超限文件；已选有效附件保留 |
| 文件正在读取或读取失败 | 读取未完成时阻止提交；失败文件可移除后重选 |
| 重复点击或并发提交 | 禁止同一轮重复新增；提示刷新核对当前记录 |
| 记录在弹窗打开后被另一端更新 | 重新读取最新消息和状态；阻止方向错误操作，保留输入供核对 |
| 当前账号失去自有记录权限 | 不提交、不展示其他代理商信息，返回当前有权列表 |
| 回复提交校验失败或记录状态已变化 | 不新增消息，也不触发通知 |
| 回复已保存但通知渠道失败 | 回复仍成功；不显示送达失败，不自动重试 |
| 提交结果未知 | 先查记录和操作日志；未核对前不自动重发 |
| 离开未提交表单 | 二次确认；继续编辑保留正文和附件，确认离开才丢弃 |
| 取消确认操作 | 关闭确认窗口但不改变记录、状态、权限或消息内容 |

## 返回、弹窗与演示场景

关闭详情、回复、追问或确认窗口返回所属列表。列表到详情返回保留筛选、页码和滚动位置；菜单或页签重新进入时按主菜单规则重新加载。浏览器前进、后退和刷新只恢复合法页面上下文，不会自动发送回复、通知或新建反馈。

所有弹窗的标题行、关闭入口和底部操作行固定；只有正文中部独立滚动。没有底部操作行的只读窗口不补造按钮。

“演示说明”随学校反馈、代理商反馈、列表、详情、回复或追问上下文更新。列表场景可预览无匹配、查询异常、无权限和记录失效；编辑场景可预览提交校验、无权限、记录已变化和提交失败。场景互斥；“恢复默认”回到正常展示。模拟场景不写入记录、不修改问答状态，也不调用真实通知服务。

本端是静态原型，反馈、权限、负责关系、附件、操作日志和消息均为样例演示，不代表生产服务、真实账号权限或真实通知已经接通。
