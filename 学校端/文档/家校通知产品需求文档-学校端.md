### 家校通知一期产品需求文档｜学校端

产品版本：V1.0.0（第一期，新增功能）  
文档编号：PRD-NT-SCH-20261125  
文档版本：V1.0  
适用端：学校端（学校后台）

---

#### 1. 需求背景与业务目标

学校后台需要为本校管理人员提供面向全校或指定年级、班级、学生及教职工的“家校通知”发布与查收管理能力，用于日常校务通知、活动告知、安全须知签收等高频家校协同场景。学校端发布或管理的通知与教师小程序、家长小程序、代理商后台及运营后台代发共用同一套底层通知与回执数据，多端实时同步。

本期核心目标：

1. **统一通知台账与多来源管理**：学校端集中展示本校所有“待发送”与“已发送”通知（涵盖学校端自发、本校教师小程序发布以及平台/代理商授权代发），支持多维度组合筛选、分页查看、通知预览与导出 PDF。
2. **两步式清晰发布与定时发送**：学校端通过“第 1 步：填写内容 → 第 2 步：准备发布”两步向导完成通知发布。新建通知默认支持图文、视频、链接混排的富媒体内容（归类为“美文通知”），支持可选封面、最多 9 份附件与三种全文背景；可按年级/班级/学生及教师精准选择发布对象，配置三种查收方式（只需阅读查看、需确认收到、需签字确认），支持立即发送或精确到秒的定时发送；**通知长期有效，不设截止时间与“已截止”状态**。
3. **严格的查收锁定与内容保护**：通知正式发布后，一旦有任一接收人产生阅读、确认或签字记录，立即锁定禁止编辑，保障家校签收凭证的严肃性与一致性；编辑既有待发送或未查收通知时，发布对象、查收方式、发布名义与定时时间均锁定不可变更。
4. **精细化阅读统计与家长回执留证**：已发送通知支持按“学生统计”与“教师统计”双维度查看实时进度。学生统计与教师统计顶部均采用单行紧凑卡片展示汇总指标（每卡两行：指标名 ＋ `X人`），班级学生明细以**独立弹窗**呈现，并可逐学生弹窗查阅家长姓名快照、精确到秒的操作时间、查收状态及签字照片；每位家长对同一通知同一学生仅允许成功确认或签字一次。

#### 2. 一期功能范围

##### 2.1 本期包含范围

| 功能模块 | 学校端业务范围 |
| --- | --- |
| 家校通知列表 | 位于“校务管理 → 家校通知”；展示当前学校全部“待发送”与“已发送”通知（不含草稿与已删除记录）；支持按通知来源、通知标题、通知类型、查收方式、发布状态、发布时间范围组合筛选；表格共 14 列，固定提供“预览、编辑、删除、阅读统计”四项行级操作及分页控制。 |
| 发布与修改通知（两步向导） | **第 1 步（填写内容）**：填写通知标题（新建必填≤50 字；**编辑既有通知时标题锁定只读不可修改，其余内容均可修改**）、可选封面、通知内容（必填，支持纯文本、图片、视频、链接内容块，文本框无格式编辑工具栏；编辑既有普通通知时锁定单文本块）、可选附件（3 块统一附件盒：`添加图片`、`添加视频`、`添加链接`，不含 PDF，合计最多 9 份）、全文背景；支持随时预览。**第 2 步（准备发布）**：选择发布对象（学生三级树 / 教师列表）、查收方式（只需阅读查看 / 需确认收到 / 需签字确认）、定时发送开关与精确到秒时间输入框（**新增与编辑页面均不展示“以学校名义通知”字段，学校端来源通知由后端固定以学校名义发送**）；最终经二次确认后发布或保存修改。 |
| 通知预览与导出 PDF | 点击列表“预览”进入通知预览页，按实际背景风格完整展示通知正文、封面、媒体与可点击预览/下载的附件，支持一键导出 PDF（调用打印导出视图）与关闭返回列表。 |
| 删除通知 | 有权限的通知在二次确认后可执行删除，不受是否已读、是否已确认或已签字限制；删除后从学校业务列表移除，接收端不可再查看正文，历史审计留档保留。 |
| 阅读与回执统计 | 仅针对“已发送”通知开放；支持切换“学生统计”与“教师统计”。两端顶部均以单行紧凑卡片展示汇总指标（每卡两行：指标名＋数字与单位同行），表格标题与内容全部居中对齐；学生统计支持年级/班级筛选、按班级汇总表及点击“明细”打开**班级学生明细弹窗**（弹窗内支持按状态、学生姓名筛选）；教师统计展示教师汇总卡片、筛选与教师明细表。 |
| 家长阅读与回执明细 | 在阅读统计页点击“查看家长明细”打开弹窗，逐家长展示提交回执时的家长姓名快照、精确到秒的操作时间、查收状态，以及签字确认通知的签字照片（支持查看大图）。 |
| 放弃未保存内容确认 | 发布或修改通知存在未提交改动，点击返回列表、切换左侧菜单、关闭页签或刷新离开时弹出确认拦截，避免误丢已编辑内容。 |
| 操作日志接入 | 接入学校后台既有菜单“系统设置 → 操作日志”（菜单位置不变），自动记录学校端成功执行的“发布通知、定时发布、修改通知、删除通知”四类写操作；操作对象展示对应**通知标题**（不使用编号），支持筛选、重置与导出。 |
| 原型状态演示面板 | 家校通知列表、编辑页、预览页、统计页及弹窗右上角统一提供“演示说明”入口，支持按当前上下文快捷预览空态、无匹配、必填校验、附件校验、并发冲突、加载失败与权限异常。 |

##### 2.2 本期不包含范围

本期学校端不包含：草稿箱与“保存草稿”功能、通知截止时间设置与“已截止”状态、已读锁定后的“添加补充说明”、学校端手动“提醒未读对象”、通知“存为模板”与“复制使用”、定时通知“取消定时转草稿”、代发其他学校通知。

#### 3. 核心业务概念、权限矩阵与全局一致性规则

##### 3.1 核心业务对象与基础规则

| 业务概念 | 业务定义与数据来源 | 一期核心业务规则 |
| --- | --- | --- |
| 通知记录 | 一条面向本校学生和/或教职工的正式通知 | 系统为每条通知生成唯一内部标识与递增版本号（每次成功修改版本号加 1）；列表仅展示处于**`待发送`**或**`已发送`**状态的通知，草稿与已删除通知不进入学校端主列表。 |
| 通知来源 | 发起创建该通知的端口与主体 | 枚举包括：`学校端`（本校后台创建）、`教师端`（本校教师小程序创建）、`平台端`（运营后台直营代发）、`平台（【代理商名称】）`（所属代理商授权代发）。来源在创建时锁定，后续编辑不改变来源。 |
| 通知类型 | 通知内容的编排形态 | 分为**`普通通知`**（单文本块结构，仅教师端可创建）与**`美文通知`**（支持文本、图片、视频、链接多块混排）。**学校端新建通知、学校端自发通知、代理商代发通知及平台端代发通知全部固定为`美文通知`**；列表同时展示并可筛选本校所有普通通知与美文通知。编辑时按来源与类型区分：**① 编辑教师端发布的`普通通知`**：锁定为唯一 1 个文本块，不展示`文本 / 图片 / 视频 / 链接`添加内容块选项卡，不可增加也不可删除该文本块；**② 编辑教师端发布的`美文通知`、学校端自发通知、代理商/平台代发通知**：均按美文通知样式回显原有全部内容块（原有几个块即回显几个块），支持自由增加、删除与排序内容块。 |
| 发布名义 | 接收端看到的通知落款身份 | **学校端、代理商端、运营后台端来源的通知，前端新增与编辑页面均不展示“以学校名义通知”字段，由后端固定写死以「学校名义」（当前/目标学校全称）发送**；其他端（教师小程序端）维持原定规则（支持以学校名义或教师个人名义发送）。 |
| 查收方式 | 接收人需要完成的动作要求 | 固定三选一：**`只需阅读查看`**（打开正文即完成）、**`需确认收到`**（须点击确认收到）、**`需签字确认`**（须手写签名提交）。 |
| 长期有效（无截止限制） | 通知的有效期规则 | 通知发布后长期有效，发布设置、筛选区、列表与统计页均**不设置截止时间**，也**不出现“已截止”状态**；只要通知未被删除且接收人关系有效，随时可阅读、确认或签字。 |
| 接收人数去重口径 | 统计通知覆盖对象与进度的计算单位 | **按学生与教师个人分别去重统计，绝不把家长人数直接加进学生总数**。同一学生关联多名家长时：任一有效家长阅读即计该学生“已读”，任一家长确认即计“已确认”，任一家长签字即计“已签字”（5 位家长均签字仍计为 1 名学生已完成）。列表的“未读人数 / 已读人数 / 已确认人数 / 已签字人数”为该通知接收学生数与接收教师数之和。 |
| 每位家长单次回执约束 | 家长端确认与签字的防重原则 | 同一通知 ＋ 同一学生 ＋ 同一家长账号，**仅允许成功确认收到或成功签字 1 次**；完成后不可修改、重签或撤销。同一学生不同绑定家长可分别提交，互不覆盖；重复打开通知仅保留首次阅读时间，不重复生成回执。 |
| 家长姓名快照 | 家长提交阅读或回执时保存的称谓 | 家长回执明细中的“家长姓名”取动作成功瞬间记录的快照，后续家长改名或修改亲友关系不重写历史回执；时间精确到秒（`YYYY-MM-DD HH:mm:ss`）。 |
| 查收锁定规则 | 已发布通知的编辑保护机制 | **待发送**通知在到点发送前允许编辑正文内容（发布设置锁定）；**已发送**通知只要尚无任何接收人产生阅读、确认或签字记录，仍可编辑正文内容；一旦产生任一阅读、确认或签字记录，立即永久锁定不可编辑（列表“编辑”按钮置灰禁用）。 |
| 操作日志记录口径 | 接入“系统设置 → 操作日志”的入库范围 | 仅在学校端成功执行**`发布通知`**、**`定时发布`**、**`修改通知`**、**`删除通知`**时写入 1 条日志，**操作对象展示对应通知标题（非编号）**；预览、导出 PDF、查看阅读统计、查看家长回执、筛选查询、校验拦截及权限拦截均不写入日志。 |

##### 3.2 角色权限与数据范围矩阵

| 权限控制项 | 学校端可见与可操作范围 | 权限校验时机与无权限表现 |
| --- | --- | --- |
| 菜单与列表访问 | 具备“校务管理 → 家校通知”查看权限的当前学校账号 | 左侧导航渲染、直达链接、刷新与筛选翻页时均校验。无权限时隐藏菜单；直接进入页面时居中提示**“当前账号没有家校通知权限，请联系管理员。”**，不展示任何通知标题、统计数字或发布按钮，其他有权菜单正常可用。 |
| 发布通知 | 具备本校家校通知发布权限的学校账号 | 渲染“发布通知”按钮、进入两步向导、最终二次确认提交时均校验。无发布权限时隐藏或禁用入口，强制触发拦截提示无权限。 |
| 预览与导出 PDF | 具备查看权限且通知归属于本校（非草稿、非已删除） | 点击“预览”及进入预览页时均校验。通知不存在、已删除或属于其他学校时提示**“通知不存在或无权限查看”**。 |
| 编辑通知 | 具备该通知管理编辑权限，且通知处于“待发送”或“已发送但尚无任何人查收”状态 | 列表按钮渲染、进入编辑页、最终点击保存提交时均校验。无编辑权限时按钮置灰（悬停提示`无操作权限`）；已有人查收时按钮置灰（悬停提示`已有人查收，不可编辑`）；提交瞬间若刚刚产生阅读记录则拦截提示**“已有接收人阅读、确认或签字，通知不可编辑。”**。 |
| 删除通知 | 具备该通知删除权限的学校账号（不受已读/已确认/已签字影响） | 列表按钮渲染、打开删除确认框、点击最终确认时均校验。无权限时按钮置灰（悬停提示`无权限`），强制触发拦截提示**“当前账号无权删除此通知”**。 |
| 阅读与回执统计 | 具备本校通知统计查看权限，且通知状态为“已发送” | 列表按钮渲染、进入统计页、打开班级学生明细弹窗、打开家长回执弹窗时均校验。“待发送”通知按钮置灰（悬停提示`该状态暂无阅读统计`）；无权访问拦截提示**“通知不存在或无权查看”**。 |

##### 3.3 全局数据一致性、并发冲突与动态权限变化总则

1. **多端并发修改冲突保护**：当学校后台与教师小程序或平台/代理商后台同时打开同一条可编辑通知进行修改时，若另一端率先保存使通知版本号递增，后提交一方立即拦截覆盖，并在编辑页顶部展示冲突提示栏（标明另一端已更新的版本号与操作人），完整保留当前用户未保存的输入，允许用户对照差异或重新载入最新版本后再决定是否修改，绝不静默覆盖他人更新。
2. **编辑期间恰逢接收人查收的原子拦截**：若学校端正在修改一条已发送但原本 0 人阅读的通知，在点击“保存修改”的瞬间，恰好有一名家长或教师打开阅读了该通知，系统在提交复核中立即拒绝本次编辑保存，提示**“已有接收人阅读、确认或签字，通知不可编辑。”**，保留页面已填内容供复制留存。
3. **定时发送幂等与删除拦截**：处于“待发送”状态的通知到点后自动转为“已发送”状态并向发布对象生效，同时生成接收名单快照；定时发送动作具备防重保护，不会对同一通知重复推送两次。若通知在到点前已被删除，则定时任务自动终止，绝不向家长或教师发出已删通知。
4. **防连点与网络超时防重**：发布通知、保存修改、删除通知的最终确认按钮点击后立即进入提交禁用态，屏蔽连点与重复回车；若因网络超时未能收到明确结果，提示**“请求超时，操作结果未确认。请先核对通知列表后再重试，避免重复提交。”**，保留输入内容供核实，避免重复发布两条相同通知。
5. **停留期间权限动态回收与账号切换原则**：
   - **仅收回写权限（保留查看权）**：已打开的编辑页点击保存/发布，或已打开的删除弹窗点击确认时拦截提示**“权限已变更，当前操作无权限。”**，不改写数据；
   - **收回查看权限**：立即清空通知列表、预览正文、统计卡片、班级学生明细及家长签字照片，提示权限已变更，延迟返回的旧查询结果直接丢弃；
   - **登录失效或切换学校/账号**：登录过期提示**“当前操作人身份失效，请重新登录后操作”**；切换账号或学校时立即清空上一身份的筛选词、编辑草稿、发布对象勾选与统计状态，按新身份重新加载；权限恢复后不自动重放旧提交。
6. **全局无数据展示统一原则**：本模块所有列表及表格（含家校通知列表、阅读统计班级汇总表、班级学生明细弹窗表、教师统计表及家长阅读与回执明细表）在无数据或筛选无匹配结果时，**均保持页面或弹窗原本框架完整不变（筛选区、操作工具栏、统计卡片及表格表头标题行全部保留）**，表格数据区**仅在第一行合并所有列居中展示“暂无对应数据”**（仅此一行），且**不显示底部分页栏（无分页）**。

##### 5.1 家校通知列表页（NT-01）

###### 5.1.1 页面定位与整体规则

1. **菜单入口与统一框架**：左侧主导航 `校务管理 → 家校通知`（一级菜单默认折叠）。打开后在顶部页签栏生成“家校通知”页签；内容区左右保持 24px 统一留白，顶部筛选区采用无外边框平铺样式，菜单与页签不展示小红点。
2. **数据展示范围**：仅展示归属于当前学校且状态为**`待发送`**或**`已发送`**的通知（涵盖学校端、教师端、平台端及所属代理商代发）；草稿及已删除通知不在本表展示。
3. **默认排序与首次状态**：首次进入全部筛选项为空/全部，默认第 1 页、每页 10 条，按**最近更新时间从新到旧倒序排列**。
4. **加载、空态与异常区分**：
   - 加载未完成显示“加载中…”，不提前显示无数据；
   - 加载失败提示**“当前数据暂不可用，请重新加载。”**并保留重试按钮与当前筛选词，**绝不伪装为无数据**；
   - 无通知数据或筛选无匹配结果时，**保持页面原本框架不变（筛选区、“发布通知”工具栏及 14 列表头标题行全部保留），表格数据区仅第一行合并所有列居中显示“暂无对应数据”（仅此一行），且不显示底部分页栏（无分页）**。

###### 5.1.2 筛选查询区

筛选区采用无外边框平铺样式，包含 6 项条件及右侧“查询”“重置”按钮，**不包含截止时间或“已截止”筛选项**：

| 筛选项顺序与名称 | 控件类型与必填 | 默认值与占位提示 | 选项枚举与匹配规则 |
| --- | --- | --- | --- |
| 1. 通知来源 | 下拉单选框；非必填 | 默认“全部” | 枚举：`全部`、`学校端`、`教师端`、`平台端`、以及各合作代理商对应项`平台（【代理商名称】）` |
| 2. 通知标题 | 单行文本输入框；非必填 | 默认空；占位“请输入通知标题” | 去除首尾空格后按包含关键词模糊匹配通知标题；支持按回车键触发查询 |
| 3. 通知类型 | 下拉单选框；非必填 | 默认“全部” | 枚举：`全部`、`普通通知`、`美文通知` |
| 4. 查收方式 | 下拉单选框；非必填 | 默认“全部” | 枚举：`全部`、`只需阅读查看`、`需确认收到`、`需签字确认` |
| 5. 发布状态 | 下拉单选框；非必填 | 默认“全部” | 枚举：`全部`、`待发送`、`已发送`（不含草稿、不含已截止） |
| 6. 发布时间 | 日期区间选择（开始时间 至 结束时间）；非必填 | 默认空 | 横向留足展示宽度，确保“开始时间”“结束时间”占位文字与日历图标单行舒展显示、不换行挤压；按北京时间自然日匹配：已发送通知按实际发布时间匹配，待发送通知按计划定时发送时间匹配；允许仅填开始日期、仅填结束日期或起止选同一天 |

**筛选交互、校验与异常场景**

1. **点击查询生效**：更改下拉选项、输入标题或选择日期时不自动刷新列表；点击**“查询”**按钮或在标题框按回车后按所有非空条件**“同时满足（且）”**过滤并回到第 1 页。
2. **日期区间合法性校验**：若同时选择了开始时间与结束时间且开始时间晚于结束时间，点击“查询”时轻提示**“开始时间不能晚于结束时间”**，不发起查询，保留原筛选输入与原列表结果。
3. **点击重置**：清空全部 6 项筛选条件并恢复为“全部 / 空”，自动回到第 1 页并重新加载本校全量通知列表（每页条数保持当前选择）。

###### 5.1.3 列表字段、行内操作与分页

**表头顺序（共 14 列，固定左→右）**：`通知来源` → `通知标题` → `发布名义` → `通知类型` → `查收方式` → `发布状态` → `发布时间` → `未读人数` → `已读人数` → `已确认人数` → `已签字人数` → `创建时间` → `操作人` → `操作`（宽表在窄视口下支持横向平滑滚动，表头与单元格内容整齐对齐不挤成竖排）。

| 列顺序与字段名 | 数据来源与展示规则 |
| --- | --- |
| 1. 通知来源 | 展示`学校端`、`教师端`、`平台端`或`平台（【代理商名称】）` |
| 2. 通知标题 | 超过 10 个字时展示前 10 字加省略号`…`，鼠标悬停完整展示原通知标题 |
| 3. 发布名义 | 开启以学校名义显示学校全称，否则显示发布人姓名（如`王雅琴老师`） |
| 4. 通知类型 | 展示`普通通知`或`美文通知` |
| 5. 查收方式 | 展示`只需阅读查看`、`需确认收到`或`需签字确认` |
| 6. 发布状态 | 徽标展示：`已发送`（绿色）或`待发送`（橙色） |
| 7. 发布时间 | 已发送显示实际发布时间，待发送显示计划定时发送时间，格式 `YYYY-MM-DD HH:mm`（北京时间），单行完整展示不换行 |
| 8. 未读人数 | 该通知总接收人数（学生＋教师）减去已读人数，实时重算 |
| 9. 已读人数 | 该通知接收学生已读数与接收教师已读数之和，实时重算 |
| 10. 已确认人数 | 仅`需确认收到`通知展示已完成确认的接收人数；其他查收方式固定展示`--` |
| 11. 已签字人数 | 仅`需签字确认`通知展示已完成签字的接收人数；其他查收方式固定展示`--` |
| 12. 创建时间 | 通知首次创建时间，格式 `YYYY-MM-DD HH:mm`（北京时间），单行完整展示不换行，整体表格保持紧凑行高 |
| 13. 操作人 | 展示创建人姓名快照，鼠标悬停提示对应创建端角色；缺失显示`—` |
| 14. 操作 | 固定按顺序展示 4 个操作按钮：**`预览`**、**`编辑`**、**`删除`**、**`阅读统计`** |

**行级操作可用状态与分页规则**

1. **`预览`**：点击进入 5.6《通知预览页》，所有有权查看的待发送与已发送通知均可用。
2. **`编辑`**：点击进入 5.2《修改通知》第 1 步。
   - 当前账号无该通知编辑权限：按钮置灰禁用，悬停提示`无操作权限`；
   - 通知为`已发送`且已有任一接收人阅读、确认或签字：按钮置灰禁用，悬停提示`已有人查收，不可编辑`；
   - 通知为`待发送`，或`已发送`但尚无任何人查收且有权限：按钮正常可用。
3. **`删除`**：点击打开 5.7《删除通知确认弹窗》。无删除权限时按钮置灰禁用（悬停提示`无权限`）；有权限时不受是否已读或是否已签字影响均可点击删除。
4. **`阅读统计`**：点击进入 5.8《阅读与回执统计页》。仅`已发送`状态可用；`待发送`状态置灰禁用（悬停提示`该状态暂无阅读统计`）。
5. **分页规则与无数据隐藏**：有数据时底部展示`共 X 条`、每页条数下拉（`10 / 20 / 50`，默认 `10`）、`上一页`、`第 X / Y 页`、`下一页`。首末页对应翻页按钮置灰禁用；切换每页条数回到第 1 页；在第 2 页及以上删除末页最后一条通知后自动回退至上一有效末页。**当列表无数据或筛选无匹配结果时，不展示底部分页栏（无分页）。**

##### 5.2 发布 / 修改通知 — 第 1 步：填写内容（NT-02）

点击列表上方“发布通知”进入新建流程，或点击列表行“编辑”进入修改流程。页面顶部展示返回按钮 `‹`、标题（`发布通知`或`修改通知`）、当前学校名称标签及两步步骤条（`1 填写内容` 进行中 → `2 准备发布`）。

| 附件 | 否 | 默认空 | 对齐教师小程序统一 **3 块「附件」盒（不含 PDF）**：固定展示 **`添加图片`**、**`添加视频`**、**`添加链接`** 三个添加块，下方固定提示：**`支持JPEG、JPG、PNG图片以及MP4视频，图片最大10M，视频最大100M，合计最多九份文件`**；图片限 `JPEG/JPG/PNG` 且≤10MB，视频限 `MP4` 且≤100MB，链接弹窗录入选填标题（≤40 字）与必填网址（`http://` 或 `https://` 开头），三类合计最多 **9 份**；已添加附件按上传顺序以**紧凑横向缩略行**展示（图片带小缩略图、视频带图标、链接带标题与网址）并支持逐个 `×` 移除；预览页在正文下方「附件」区按上传顺序展示（链接固定两行＋`复制链接`按钮；历史兼容文档附件仍可查看下载） |

###### 5.2.2 内容校验、按钮操作与异常场景

1. **内容合法性校验规则**（点击最终发布/保存时统一核验，报错区展示清晰提示并自动滚动定位，保留全部已填内容）：
   - 标题为空或纯空格：提示**“请填写通知标题”**；超过 50 字：提示**“通知标题最多50字”**；
   - 未包含任何有效内容（无非空文本、无已选素材的图片/视频、无有效链接）：提示**“请至少添加一段文本、一张图片、一个视频或一个链接”**；
   - 所有文本块纯文本合计超过 5000 字：提示**“正文文本合计最多5000字”**；
   - 正文图片块累计超过 60 张：提示**“图片最多60张”**；
   - 链接块地址未以 `http://` 或 `https://` 开头：提示**“链接须以 https:// 或 http:// 开头”**；
   - 图片或视频块未选择具体素材：提示**“请为图片选择素材”**或**“请为视频选择素材”**；
   - 本地上传图片超过 10MB 提示**“单张图片不能超过10MB”**；视频无法播放或超过 10 分钟提示**“请选择可播放且不超过10分钟的视频”**；
   - 附件累计超过 9 份提示**“附件合计最多9份，不能继续添加”**；图片非 `JPEG/JPG/PNG` 提示**“仅支持JPEG、JPG、PNG格式图片”**、超 10MB 提示**“单张图片不能超过10MB”**；视频非 `MP4` 提示**“仅支持MP4格式视频”**、超 100MB 提示**“单个视频不能超过100MB”**；链接地址非 `http://` 或 `https://` 开头提示**“链接须以 https:// 或 http:// 开头”**。
2. **底部操作按钮**：
   - **`返回列表`**（或顶部返回箭头 `‹`）：若当前未做任何修改直接返回列表页；若存在未保存改动，弹出 5.10《放弃未保存内容确认弹窗》。
   - **`预览`**：弹出**小程序样式**的“家长阅读预览”只读弹窗（手机端模拟框，含顶部状态栏、小程序导航栏与胶囊按钮），按当前填写的标题、封面、正文块、附件与全文背景即时渲染效果；其中**通知标题、图片/视频素材说明均居中完整显示（一行不够自动换行多行，不截断），封面图与正文配图/视频正常等比居中展示，链接固定两行展示并提供`复制链接`按钮（点击复制链接地址，成功 Toast 提示“链接已复制”，失败提示“复制失败，请手动复制”），PDF 附件维持现状**；**编辑预览绝不触发正式发布，也不产生任何阅读记录或锁编辑**；关闭预览返回第 1 步，完整保留输入。
   - **`下一步`**：切换至 5.3 第 2 步“准备发布”，第 1 步所有内容与附件完整暂存，支持随时返回修改。
3. **多端并发冲突提示栏**：编辑既有通知期间若另一端已保存新版本，页顶展示冲突提示条，提供`查看两份内容`（对照当前输入与最新版本）与`载入最新版本`（二次确认后刷新为最新内容；若最新版本已被阅读锁定，则自动退出编辑进入只读查看）。

##### 5.3 发布 / 修改通知 — 第 2 步：准备发布（NT-03）

###### 5.3.1 发布设置字段定义

| 字段名称 | 必填 | 默认值 | 交互与修改锁定规则 |
| --- | --- | --- | --- |
| 发布对象 | 是 | 新建未选（显示`已选中学生0人，教师0人`）；修改回显原对象人数 | 点击选择框打开 5.4《选择发布对象弹窗》；至少选中 1 名有效学生或教师；**修改既有待发送或已发送通知时锁定置灰不可改** |
| 查收方式 | 是 | 新建默认`只需阅读查看`；修改回显原方式 | 下拉单选：`只需阅读查看`、`需确认收到`、`需签字确认`；**修改既有通知时锁定置灰不可改** |

###### 5.3.2 校验、二次确认与异常场景

1. **底部操作按钮**：
   - 左侧**`上一步`**：返回第 1 步“填写内容”，本页已配置的所有发布设置完整保留不丢失；
   - 右侧主按钮：新建且未开定时显示**`发布通知`**，新建且开启定时显示**`定时发布`**，修改既有通知显示**`保存修改`**。
2. **发布前校验拦截**：
   - 未选择任何有效发布对象：提示**“请选择发布对象”**；
   - 选中的班级、学生或教师已失效/不在本校范围内：提示**“发布对象包含无效的班级或人员”**；
   - 开启定时发送但未选时间、格式非法或所选时间早于/等于当前时间：提示**“请填写有效的定时发送时间，格式为 YYYY-MM-DD HH:mm:ss”**；
   - 修改既有通知时试图篡改已锁定的发布对象、查收方式或定时时间：拦截提示**“发布对象、查收方式和发布时间不能修改”**。
3. **发布 / 修改二次确认弹窗**：
   - 点击主按钮后先弹出全局统一风格的紧凑确认弹窗（宽度 432px、顶部标题无分割线、正文居中橙色感叹号图标＋汇总说明，标题对应`确认发布` / `确认定时发布` / `保存修改`，正文汇总`学校名称`、`接收对象（学生 X 人，教师 Y 人）`、`查收方式`及`计划发送时间（仅定时发送展示）`），底部右侧固定仅提供**`取消`**与**`确认`**两个按钮；
   - 点击`取消`回到第 2 步保留所有配置；点击`确认`则执行最终权限、版本与查收锁定复验，保存成功后轻提示**“保存成功”**（定时通知提示**“定时通知已保存”**），**并直接跳转返回家校通知列表页（不进入详情页）**，同步更新列表。
4. **提交异常场景**：
   - 修改既有通知提交瞬间已被他人修改：拦截并展示冲突栏，保留当前输入；
   - 修改已发送通知提交瞬间恰有接收人阅读：拦截提示**“已有接收人阅读、确认或签字，通知不可编辑。”**；
   - 保存失败提示**“提交失败，请重试。”**，保留全部输入；网络超时提示核对结果后再重试，防重复发布。

##### 5.4 选择发布对象弹窗（NT-04）

在第 2 步“准备发布”点击发布对象框打开，弹窗标题为`选择发布对象`，标题行与底部`取消 / 确定`固定，中间名单区独立滚动。顶部提供`学生`与`教师`两个页签，页签下方实时展示跨页签合并统计文案：`已选中学生X人，教师Y人`。

| 页签 | 结构与选择规则 |
| --- | --- |
| 学生 | 按**年级 → 班级 → 学生**三级折叠树展示（默认折叠，点击左侧 `+` / `−` 展开或收起，同班学生按姓名拼音升序排列）：（1）勾选某年级复选框，自动全选该年级下全部有效班级及学生；取消勾选则全部取消；（2）勾选某班级复选框，自动全选该班全部学生；仅勾选部分学生时，所属班级与年级复选框自动呈**半选态**；（3）整班选择与单人选择自动去重，不重复累计学生人数。 |
| 教师 | 顶部提供`全选教师`复选框（部分勾选时呈半选态），下方按姓名拼音升序展示本校全部教师（姓名 ＋ 主职务，无职务显示`--`），支持逐人多选。 |

**交互与异常规则**

1. **跨页签勾选记忆**：在“学生”页签勾选部分班级/学生后切到“教师”页签继续勾选，切回“学生”页签原勾选状态与统计数字完整保留。
2. **取消 vs 确定**：点击`取消`、右上角`×`或按`Esc`，丢弃本次弹窗内未确认的临时勾选变化并关闭弹窗，外层发布设置保持打开弹窗前的原选结果；点击`确定`将最新去重名单写回发布设置并更新人数摘要。
3. **空名单与加载失败**：若本校尚无可选学生或教师，对应页签展示“暂无可选对象”；若名单加载失败提示“对象名单加载失败，请重试”，不清空此前已选对象。

1. **顶部单行统计卡片与筛选**：顶部汇总卡片采用与学生统计**完全一致的单行紧凑两行式卡片**（`教师总数`、`已读`、`未读`；需确认/签字时追加`已确认收到`/`待确认`或`已签字`/`未签字`，每卡 2 行：指标名＋`X人`）；筛选栏采用无外边框平铺样式，提供`状态`下拉、`姓名`输入框与`查询`按钮。
2. **教师明细表格（4 列，表头标题与数据内容全部居中对齐，按教师姓名拼音升序，每页 10 人）**：`教师姓名` → `阅读情况`（已读/未读）→ `查收结果`（无需确认/已确认/未确认/已签字/未签字）→ `明细`（点击`查看`打开对应教师的回执明细弹窗）。
3. **空态与异常**：班级汇总表、班级学生明细弹窗表或教师统计表无数据或筛选无匹配时，**均保持原本框架不变（顶部统计卡片、筛选区与对应 4 列表头标题行全部保留），表格数据区仅第一行合并所有列居中显示“暂无对应数据”（仅此一行），且不显示底部分页栏（无分页）**；统计读取失败提示**“统计数据加载失败，请重试”**，**严禁将读取失败显示成全员 0 人已读**；收到家长/教师新回执后重新打开或刷新统计页立即重算最新数据。

##### 5.9 家长阅读与回执明细弹窗（NT-10）

在学生统计明细表点击`查看家长明细`（或教师统计表点击`查看`）打开，弹窗标题为`家长阅读与回执明细`，标题栏、表头与底部`关闭`按钮固定，中间表格区独立纵向滚动。

| 列顺序与列名 | 数据来源与展示规则 |
| --- | --- |
| 1. 家长姓名 | 展示该家长提交阅读或回执瞬间保存的**家长姓名快照**（如`周女士`、`爸爸`），后续修改姓名或亲友关系不改写已有记录；缺失显示`—` |
| 2. 操作时间 | 精确到秒的成功操作时间，格式 `YYYY-MM-DD HH:mm:ss`（北京时间）：仅读通知取首次阅读时间；确认通知已完成取确认时间、仅读未确认取阅读时间；签字通知已完成取签字时间、仅读未签字取阅读时间 |
| 3. 状态 | **仅读通知**：`已读`；**确认收到通知**：已完成显示`已确认收到`，仅阅读未确认显示`已读`；**签字确认通知**：已完成显示`已签字`，仅阅读未签字显示`已读` |
| 4. 签字照片 | 仅对存在签字照片的回执记录展示手写签名缩略图（点击可在新视图查看清晰原图），未签字或非签字通知不展示照片（非签字通知明细隐藏或以`—`占位） |

**业务校验与异常场景**

1. **单次提交与多家长并存**：同一学生多位家长分别阅读或办理时逐行展示（1 位展示 1 行，3 位展示 3 行），未阅读家长不生成空白占位行；同一家长重复查看通知不新增重复行，且完成后绝不出现再次提交或修改签字入口。
2. **空态展示**：当该学生未关联任何有效家长，或已关联家长但尚无人阅读/提交回执时，**保持弹窗原本框架与表头标题行不变，表格数据区仅第一行合并所有列居中显示“暂无对应数据”（仅此一行），且无分页**。
3. **图片与权限异常**：签字照片加载失败时单独提示图片暂不可预览，不影响家长姓名、时间与状态核对；从班级学生明细弹窗进入时，点击关闭自动返回原班级学生明细弹窗（保留当前班筛选条件）；从教师统计页进入时，关闭返回教师统计页。

##### 5.10 放弃未保存内容确认弹窗（NT-11）

在发布/修改通知（第 1 步或第 2 步）存在未提交的输入或配置改动时，点击顶部返回箭头、`返回列表`、切换左侧菜单、关闭顶部页签或刷新浏览器触发：

| 弹窗区域 | 固定文案与按钮 |
| --- | --- |
| 标题 | 放弃编辑（或：放弃未保存内容？） |
| 正文说明 | 确认放弃当前输入吗？确认后将丢失本次填写内容。 |
| 底部按钮 | `取消`（留在本页继续编辑）、`确认`（确认放弃并离开） |

1. **点击`取消`、`×`或按`Esc`**：仅关闭本确认框，回到通知编辑页并完整保留第 1 步与第 2 步的全部未提交内容。
2. **点击`确认`**：丢弃本次未提交改动，不发布也不修改既有通知，执行原返回或跳转动作；若编辑页处于多层弹窗（如正打开“选择发布对象”弹窗），按 `Esc` 优先关闭最顶层小弹窗，绝不直接触发外层放弃确认。

##### 5.11 家校通知操作日志接入规则（NT-12，系统设置 → 操作日志）

本功能不单独新增日志菜单，所有成功生效的写操作统一接入学校后台既有菜单 **`系统设置 → 操作日志`**（菜单位置保持不变）。

1. **本功能入库与不入库边界**：
   - **记入事件**：学校端成功执行`发布通知`、`定时发布`、`修改通知`、`删除通知`时各写入 1 条日志；
   - **不记入事件**：通知列表筛选与重置、点击预览、导出 PDF、查看阅读统计、打开班级学生明细弹窗、查看家长回执明细、取消确认弹窗、表单校验失败及权限拦截均不写入操作日志。
2. **筛选与导出**：支持按`操作对象 / 详情关键词`、`全部操作类型`（可筛`发布通知`、`定时发布`、`修改通知`、`删除通知`）、`全部操作人`、`时间范围`（默认`近30天`，支持`今天`/`近7天`/`近30天`/`全部时间`）组合筛选，提供`重置`与`导出`按钮。点击`导出`导出 Excel 文件（`.xlsx`，工作表名`操作日志`），第 1 行为合并居中的标题行`学校端操作日志`，第 2 行为 6 列表头，第 3 行起为数据行（`操作详情`左对齐自动换行，其余列居中对齐）；导出范围与当前筛选条件强联动，导出当前筛选命中的全部记录（不受分页限制）；筛选结果为 0 条时点击导出提示“暂无可导出数据”，不生成空文件。
3. **六列表头与展示规则**（固定左→右：`操作时间` → `操作人` → `操作类型` → `操作对象` → `操作详情` → `来源 IP`）：
   - **`操作时间`**：操作成功时间（`YYYY-MM-DD HH:mm:ss`，北京时间），按时间倒序排列；
   - **`操作人`**：操作成功瞬间快照，格式`姓名(手机号)`（如`陈老师(13800138212)`）；
   - **`操作类型`**：标签展示`发布通知`、`定时发布`、`修改通知`或`删除通知`；
   - **`操作对象`**：展示对应通知的**通知标题**（如`家校携手，赴一场秋日之约`），**不使用编号**（编号仅针对订单类日志）；
   - **`操作详情`**：左对齐清晰写明通知类型、查收方式及发布对象人数（如`发布美文通知（需确认收到），发布对象：学生20人，教师2人`）或具体修改/删除说明；
   - **`来源 IP`**：展示操作发起时的客户端 IP。
4. **空态与分页**：有数据时展示标准底部分页；无数据或筛选无匹配时保留筛选栏、导出按钮与 6 列表头标题行，数据区仅第一行合并显示“暂无对应数据”，且隐藏底部分页栏（无分页）。

##### 5.12 原型状态演示面板（NT-13，右上角“演示说明”）

在家校通知列表页、两步编辑页、预览页、阅读统计页及各业务弹窗右上角统一提供**“演示说明”**入口，支持按当前所处视图切换预览对应状态：

1. **列表页适用场景**：无数据、无匹配、加载中、加载失败、加载超时、无权限（其中“无数据 / 无匹配”预览须严格保持原本框架与表头标题行，仅表格第一行显示“暂无对应数据”并隐藏分页，不得隐藏整张表格）。
2. **发布/修改页适用场景**：必填校验、附件校验、版本冲突、加载失败、权限失效、对象失效、提交失败、结果未知。
3. **预览页、统计页与删除确认框适用场景**：加载失败、权限失效、对象失效、版本冲突、提交失败、结果未知。
4. **安全隔离**：演示状态互斥切换，点击“恢复默认”或离开当前界面立即还原正常展示，绝不污染或删除已有业务通知与回执数据。

#### 6. 跨端协同与界面交互通用规范

##### 6.1 多端数据共享与联动规则

| 协同场景 | 业务规则 |
| --- | --- |
| 学校端 ↔ 教师小程序 / 家长小程序 | 学校端发布（或定时到点发送）的通知实时同步至目标学生绑定家长的家长小程序（“全部 / 待办”）与目标教师的教师小程序（“我接收”），同时全校教师可在教师小程序“校园通知”查阅；家长或教师在小程序完成阅读、确认收到或签字确认后，学校端列表进度数与阅读统计页实时同步最新结果。 |
| 学校端 ↔ 代理商后台 / 运营后台 | 所属代理商（代理模式）或运营平台（直营模式）为本校授权代发的通知，自动出现在本校家校通知列表（来源分别标示`平台（代理商名称）`或`平台端`），与学校自发通知共享同一套阅读统计与回执数据。 |
| 删除联动 | 学校端确认删除某条通知后，家长端该通知展示规则为：（1）**家长消息列表**：这条通知条目保留，不会自动消失；（2）**家长点进详情**：正文隐藏，展示提示页：`该通知已由发布老师删除，内容不可查看`；（3）**删除时家长正在看通知**：下次点击进去时正文隐藏，展示提示页：`该通知已由发布老师删除，内容不可查看`；同时不再允许新阅读、确认或签字。 |

##### 6.2 统一版式与交互规范

1. **留白与视觉体系**：学校端整体视觉对标线上运营后台规范（主品牌绿 `#01a239`、浅灰表头 `#f2f5fa`、32px 标准控件高度与 4px 圆角）；内容区左右留白固定 24px；全局筛选区域均采用无外边框平铺样式；阅读统计顶部指标卡片间距宽松清晰。
2. **全局确认弹窗与业务弹窗规范**：所有风险提示与二次确认弹窗（删除通知、发布/修改确认、删除内容块、放弃未保存内容等）统一采用**紧凑标准样式（宽度 432px，无边框分隔线，正文居中橙色圆形感叹号图标＋各场景原有提示文案，底部右侧固定仅展示`取消`＋`确认`两个按钮）**；业务列表/多选类弹窗（发布对象、班级学生明细、家长回执明细、附件预览）顶部标题栏与底部操作按钮栏固定不动，仅中间内容区产生纵向滚动条。
3. **图片等比完整展示**：封面图、正文配图、附件图片预览与签字照片均按原图比例完整缩放居中展示，不裁切、不拉伸。
