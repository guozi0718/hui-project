# 家校通知演示说明

## 页面用途与入口

本页用于代理商查看本代理商成员代发的家校通知，并按当前代理商身份代发通知。入口为左侧“校务管理 → 家校通知”，稳定页面地址为 index.html?page=family-notice。列表、通知详情、预览、统计和编辑均属于家校通知页面，不另开菜单页。

## 角色、数据范围与权限

- 代理商用户只能查看本代理商成员代发且当前代理商有权访问的通知。代理商成员共享本代理商的代发记录。
- 代理商代发必须使用学校名义；学校名义保持开启，不能切换为个人名义。
- 代理商 Web 新建通知直接进入发布流程，不提供草稿箱。
- 列表中全部四个操作按钮（预览、编辑、删除、阅读统计）均受运营后台“合同管理”菜单下的代理商权限管辖控制；超出管辖范围时全部禁用并说明原因，且不能通过直接输入通知编号越权查看或操作。
- 删除按钮在代理商合同管辖权限范围内随时可用（不限通知发送状态及是否已有家长或教师查收），点击后需二次确认再执行删除。
- 编辑按钮受合同管辖权限及查收记录共同控制；通知一旦有人阅读、确认或签字，编辑置灰并说明原因。
- 代理商代发的新通知类型为美文通知。符合编辑条件的普通通知编辑后仍保持普通通知类型。

## 列表筛选与字段

筛选可按通知标题、发布名义、通知类型、查收方式、状态和时间范围组合。状态选项为待发送、已发送、草稿和已删除，不包含截止状态。代理商列表不提供来源筛选或来源列，也不提供内容形式筛选。选择条件后点击“查询”才应用条件；点击“重置”清除筛选并回到第一页。

列表显示目标学校、通知标题、发布名义、通知类型、查收统计、创建时间、操作人和当前可用操作。未读、已读人数显示数字；“需确认收到”时显示确认人数，“需签字确认”时显示签字人数，不适用的统计显示“--”。列表标题表头居中、标题内容靠左，其他字段按页面当前对齐规则呈现。标题超过10个字时省略显示，悬停可查看全文；来源等其他信息不拼入标题。

筛选无匹配数据时显示空结果，不把旧列表伪装成新查询结果。查询失败或超时保留筛选值和当前页，明确提示并允许手动重试。数据变化导致当前页失效时回到有效页并提示列表已更新。

## 新建、复制与编辑

### 新建代发

点击“代发通知”后进入发布流程。新建代发的发布设置不提供截止时间字段。接收对象的下拉多选只提供“全体学生”和“全体教师”，可以选择其中一类或同时选择；不能选择单个学生、单个教师、班级或年级。发布对象必须是有效范围，发布前再次核对。通知发布后不因经过时间而改变发送状态，已发布通知仍按权限规则进行查收、提醒和管理。

### 复制

复制已有通知会创建新的通知记录，不沿用原通知的接收对象。代理商必须重新选择允许的全体对象范围，避免把旧名单误带到新通知。

### 编辑

只可编辑当前身份有权限且未产生阅读、确认或签字记录的通知。通知一旦有人查收，编辑操作置灰并说明原因。编辑冲突时不覆盖其他端的新内容；当前输入保留，用户需重新核对最新内容后再决定后续操作。编辑已存在通知时，表单按该通知的当前发布设置展示相关字段；历史截止时间不参与状态、发布校验、提醒、查收或编辑权限判断，历史记录和新通知均不自动进入截止状态。

## 内容字段与限制

| 内容 | 当前规则 |
|---|---|
| 标题 | 必填，最多40字；输入框显示计数，超出上限阻止继续输入和提交 |
| 通知类型 | 新建为美文通知；符合条件的普通通知可编辑，保存后仍为普通通知 |
| 正文文本 | 可使用多个文本块，文本总计最多5000字 |
| 图片 | 最多60张；封面建议900×383px高清素材；正文配图建议上传宽1080px清晰原图。详情及模板预览封面最大320×136px、正文最大320×180px；等比居中完整显示、不裁切；正文不放入固定大画框、不留多余空白 |
| 视频、音频、链接 | 使用已选素材或有效链接；链接必须以 http:// 或 https:// 开头；素材未选好时不能提交 |
| 附件 | 最多10个，单个不超过20MB；逐个校验格式、大小和读取状态 |
| 查收方式 | 只需阅读查看、需确认收到、需签字确认 |
| 发布对象 | 对象必须存在且处于当前代理商管理范围 |
| 发布名义 | 固定学校名义；不允许代理商切换个人名义 |

代理商编辑页的封面控件下方以单行、与“未设置封面”左对齐的方式显示提示：“封面建议采用900×383px高清素材；正文配图建议上传宽1080px清晰原图”。通知详情和模板预览中的封面最大320×136px，正文配图最大320×180px；均按原图比例完整缩放、居中显示，不裁切。正文配图不放入固定大画框，不增加多余留白。Web 编辑页不提供录音入口；预览按编辑后的实际内容呈现。

## 预览、统计与删除

- 操作“预览”打开标题为“通知预览”的只读视图，只显示通知内容，不显示查收统计。通知正文单独滚动，预览标题固定。
- 操作“阅读统计”参考学校端阅读统计样式，采用指标卡片网格、圆角筛选栏与舒展行距表格展示。学生统计先展示按年级/班级汇总的阅读进度表，点击某班级的“明细”可在当前页内展开该班学生阅读明细区，按状态和学生姓名筛选并点击“查看家长明细”打开家长阅读与回执明细弹窗；点击“收起”或“收起明细”折叠。
- 教师统计采用相同的指标卡片网格、筛选栏与舒展表格展示教师名单及回执明细。两个统计视图均不提供提醒按钮。
- 操作“删除”在运营后台“合同管理”代理商管辖权限内随时可用，删除前展示确认窗口；取消不改变记录，确认时再次校验合同管辖权限。无权限时按钮保持禁用，不绕过权限执行。
- 打印或预览不等同于通知发布，也不会产生阅读、确认或签字记录。

## 状态、异常与恢复

1. 标题为空、内容没有有效文本/图片/视频/链接、正文超过5000字或图片超过60张时，阻止保存或发布，指出字段并保留编辑内容。
2. 链接不是 HTTP 或 HTTPS 地址、素材未选择、附件格式不支持、单个附件超过20MB、附件超过10个或文件尚未读取完成时，阻止提交并保留其他合规内容。
3. 学校或接收对象无效、超出代理商负责范围，或选择了不支持的个人/班级范围时，阻止发布，不改用其他学校或默认接收对象。
4. 发布通知不设置截止时间；通知状态不随时间进入截止状态。有效权限下，查收、提醒和编辑资格不受经过时间影响；编辑资格仍受查收记录和记录状态限制。
5. 当前用户无编辑或删除权限、记录状态不允许该操作时，显示只读或禁用状态，不提交写操作。
6. 其他端先修改记录时显示冲突，保留本地输入；不得静默覆盖，可返回核对最新内容。
7. 用户连续点击发布、确认或删除，或第一次操作结果不确定时，同一通知不得重复创建或删除；先核对列表、通知状态和操作结果，不自动重试。
8. 浏览器本地存储不可用、空间不足或事务保存失败时，保留当前编辑内容并提示未保存，不显示为已发布；释放空间后由用户手动重试。
9. 图片、视频、音频或附件读取/预览失败时标示对应素材不可用，保留其他已完成内容；未通过校验的素材不得随通知发布。
10. 页面收到未知视图、弹窗类型或不完整记录参数时，不打开空白详情、不自动执行写操作；提示参数无效并提供返回通知列表入口。
11. 查询失败、超时或无数据时分别显示错误、重试状态或空结果；重试由用户发起。通知ID缺失、无效或超出权限时不显示空详情，也不切换到其他通知。
12. 未保存内容关闭或切页时显示“放弃编辑”确认，文案为“确认放弃当前输入吗？确认后将丢失本次填写内容”，按钮为“取消”“确定”。取消后保留输入；确认后才丢弃。

所有弹窗的标题行、关闭入口和底部操作行固定；只有中部正文区域滚动。关闭详情、预览或统计弹窗后回到原通知上下文。合法查询参数可恢复页面；缺失或无效参数不得触发发布、删除、查收等写操作。

## 演示操作与边界

页面“演示说明”随当前通知列表、详情、编辑、预览或统计上下文更新。可用互斥场景查看无数据、无匹配、查询失败、无权限、记录失效、必填校验和版本冲突；选择另一场景会替换当前场景，“恢复默认”返回正常显示。

演示场景只改变页面显示，不执行真实通知发送、真实签收或生产写入。通知、名单、回执和统计均为静态原型中的示例数据；页面不连接生产接口或真实消息渠道。原型在本地存储演示状态，重置原型存储可恢复初始示例数据。
