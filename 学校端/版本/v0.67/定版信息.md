## 锁定的菜单与交互

| 项目 | 定版值 |
|---|---|
| 学校反馈 | 稳定 ID `school-feedback`；筛选顺序为反馈来源、反馈人、联系电话、反馈类型、状态；列表和详情按本版字段清单展示 |
| 关联学生 | 列表与详情均紧跟联系电话；家长来源显示提交时学生快照，学校和教师来源显示“—” |
| 组织字段 | 学校反馈筛选、列表、详情不展示所在区域、所属单位或所在机构 |
| 通知统计 | 学生总数、已读、未读采用有留白的统计卡片；学生班级明细在当前统计页内展开 |
| 家长回执 | 按家长姓名快照、成功操作时间、状态展示；签字记录增加签字照片；每位家长每条通知仅成功提交一次 |
| 通知截止 | 发布设置、筛选和状态均不提供截止时间或“已截止” |
| 学校操作日志 | 仅成功提出反馈新增操作日志 |
| 主菜单与页签 | 由同一学校框架和统一链接宿主加载；一级菜单默认折叠；关闭当前页签优先回到左侧相邻页签；全部关闭时回到首个一级菜单的首个二级菜单 |
| 公共样式 | 学校内容区留白 24px；通知筛选区域保留边框；无菜单和页签小红点；弹窗标题行和底部操作行固定，仅中间内容区滚动 |
