### 家校通知产品需求文档｜运营后台

产品版本：V1.0.0（新增功能）  
文档编号：PRD-NOTICE-OP-20261126  
文档版本：V1.0  
适用端：运营后台  

---

#### 1. 需求背景与业务目标

此前运营后台缺少面向学校与家校沟通的通知监管及平台代发能力：当学校遇到紧急事务需要平台协助以学校名义发布正式图文通知，或运营人员需要全局巡检各校、教师及代理商已发布的家校通知内容与阅读回执进度时，无法在运营后台直接完成。本期作为**全新新增功能**，在运营后台左侧导航新增一级菜单分组 **`校务管理`** 及二级菜单 **`家校通知`**，打通运营后台、代理商端、学校管理端及家校小程序的通知发布、预览、A4 规范导出 PDF 与阅读回执统计全链路。

本期新增核心目标：

1. **全校全来源通知统一巡检**：运营后台《家校通知》列表支持查看全平台全部学校、全部来源（学校端、教师端、平台端、平台（代理商名称））的已发布及待发送通知（自动排除草稿与已删除通知），实时掌握未读、已读、已确认与已签字人数。
2. **三步式“以学校名义”代发通知**：运营人员可在授权管理的学校范围内，通过“选择学校 → 填写内容 → 准备发布”三步向导，以目标学校名义代发规范的美文图文通知，支持封面、富文本图文/视频/链接、最多 9 个附件、全文背景样式、按学生年级班级与教师通讯录精准选人、普通/确认/签字三种查收方式及可选定时发送。
3. **严谨的编辑锁与数据范围控制**：运营可查看、预览、查看阅读统计全部可见通知，但“代发通知”“编辑”“删除”严格校验学校管理范围；且只要已有任意一名接收人完成阅读、确认或签字，通知即自动锁定禁止编辑，保障已公示通知的严肃性与一致性。
4. **手机框所见即所得预览与标准 A4 导出 PDF**：提供逼真的手机端预览效果及一键导出符合公文排版的无冗余页眉页脚 A4 PDF 文件，方便学校存档与线下张贴。
5. **操作留痕并入统一《操作日志》**：代发通知、编辑通知、删除通知等核心动作统一写入系统既有《操作日志》（菜单位置保持 `系统设置 → 操作日志` 不变），使用可读的目标学校与通知标题作为操作对象，严禁使用单据编号。

##### 2.2 本期不包含范围

本期不包含：Web 端通知草稿箱、Web 端“提醒未读”催办按钮、设置通知“截止时间”与“已截止”状态（运营后台仅包含待发送与已发送）、Web 端新建“普通通知”（Web 端新建统一固定为“美文通知”，仅兼容编辑符合条件的既有普通通知）、批量向多所学校同时群发同一条通知（每次代发针对单所目标学校）。

#### 3. 核心业务概念、权限矩阵与全局一致性规则

##### 3.1 核心业务对象与基础规则

| 业务概念 | 定义与来源 | 核心业务规则 |
| --- | --- | --- |
| 通知来源 | 发起创建该条通知的系统终端与机构主体 | 共 4 类展示值：`学校端`、`教师端`、`平台端`（运营后台代发）、`平台（代理商名称）`（代理商端代发）。 |
| 发布名义 | 通知对外向家长和教师展示的落款主体 | **学校端、代理商端、运营后台端来源的通知，前端新增与编辑页面均不展示“以学校名义通知”字段，由后端固定写死以「学校名义」（目标学校全称）发送**；其他端（教师小程序端）维持原定规则（支持以学校名义或教师个人名义发送）。 |
| 通知类型 | 通知正文的呈现形态 | 分为 `美文通知` 与 `普通通知`。运营后台新建代发固定为 `美文通知`（支持封面、图文混排、视频、链接、附件与全文背景）；若编辑一条尚未有人查看的既有 `普通通知`，保持其 `普通通知` 类型并仅允许编辑纯文本段落，不可转换为美文通知。 |
| 查收方式 | 接收人查看通知后的反馈动作要求 | 固定 3 类：`普通`（仅需阅读）、`确认`（需点击确认收到）、`签字`（需手写电子签名提交）。列表“已确认人数”仅在查收方式为`确认`时显示数值，否则显示 `--`；“已签字人数”仅在查收方式为`签字`时显示数值，否则显示 `--`。 |
| 发布状态 | 通知当前的发送阶段（运营后台口径） | 仅包含 `待发送`（已设置定时发送且尚未到达预定时间）与 `已发送`（即时发送或定时已触发发出）；不包含草稿、已删除及“已截止”状态。 |
| 操作人快照 | 发起创建该通知的操作人员身份快照 | 统一格式为 `姓名（身份标签）`：如 `王芳（老师）`、`陈校长（学校管理员）`、`李明（平台（厦门代理商））`、`刘俊涛（平台）`。 |
| 已读即锁编辑规则 | 防止已公示通知内容被篡改的强约束 | 无论通知处于何种发送方式，只要已有**至少 1 名接收人**产生了阅读、确认或签字记录（即已读人数 ＞ 0），该通知即永久锁定不可再编辑，“编辑”按钮置灰或点击拦截提示**“已有接收人阅读，暂不支持编辑。”**；未有人阅读的 `待发送` 或 `已发送` 通知，在有权限范围内允许编辑。 |
| 管理范围边界 | 运营账号可“看”与可“管”的权限区分 | 具备查看权限的运营账号可在列表查看、预览、导出 PDF 及查看阅读统计全平台可见通知；但**代发通知、编辑通知、删除通知**严格限制在当前运营账号获授权管理的学校范围内，超出管理范围的学校不可选择代发，对应通知行禁止编辑与删除。 |

##### 3.3 全局数据一致性、并发冲突、无数据与动态权限总则

1. **编辑期间并发已读拦截原则**：运营人员在编辑一条尚无人阅读的`已发送`通知过程中，若恰有家长或教师在小程序端打开阅读了该通知，运营点击“保存发布”时后端再次实时校验已读数，检测到已读人数 ＞ 0 立即拦截并提示**“该通知已有接收人阅读，无法保存修改。”**，保护已阅内容不被篡改。
2. **定时发送临界点保护原则**：运营正在编辑或删除一条`待发送`通知时，若定时时间恰好到达并已触发系统派发，点击保存或删除时按最新状态校验（若已发送且已有阅读则拦截编辑），不产生重复派发。
3. **防连点与超时防重原则**：发布、保存、删除按钮点击后立即置灰显示“提交中…”，防止重复发出两条完全相同的通知；网络超时提示**“请求超时，发布结果未确认，请返回列表核对后再操作。”**，系统自动防重。
4. **全局无数据展示规范（强制统一）**：系统内所有列表与统计表格（包含《家校通知》列表页、第 1 步学校选择列表、阅读统计的班级汇总表/学生明细表/教师统计表、《操作日志》列表及原型“演示说明”中的无数据场景），当无匹配数据或暂无记录时，**一律保持原有页面框架不变，筛选区、工具栏与列表标题行（表头）完整保留，仅在表格内容区第一行合并单元格展示“暂无对应数据”，仅仅这一行，且不展示分页栏**。
5. **停留期间权限动态变更原则**：停留在向导或弹窗期间被收回写权限，点击提交立即拦截并提示**“权限已变更，当前操作无权限。”**；被收回查看权限时立即清空列表与详情内容并拦截展示无权限提示。

###### 5.1.2 列表字段与行内操作（共 15 列）

| 列顺序与字段名称 | 展示规则与交互说明 |

##### 5.2 三步代发 / 编辑通知向导（NT-02、NT-03、NT-04）

- **新建代发通知**：固定为**美文通知**，顶部展示 3 步进度条：**`1. 选择学校`** → **`2. 填写内容`** → **`3. 准备发布`**。

###### 5.2.1 第 1 步：选择学校（NT-02，仅新建代发展示）

1. **单行紧凑筛选区**：将 `省份`、`城市`、`区县` 下拉框与 `学校名称` 输入框合并为**同一行紧凑展示**（标签与控件同行排列、宽度适中，不换行占两行），与下方学校列表实时联动筛选。
2. **标准表格与单选分页**：候选学校以标准列表表格展示，共 3 列：**第 1 列为选择列（无表头标题，仅放置圆圈单选框）**、第 2 列为 `学校名称`、第 3 列为 `所在地区`；每页固定展示 **10 条**并沿用系统正常列表分页样式，每次代发仅限单选 1 所授权管理学校。
3. **空态与下一步校验**：无匹配学校时保留表头，第 1 行合并展示“暂无对应数据”，无分页栏；未选择学校时点击“下一步”提示“请先选择目标学校”。

###### 5.2.2 第 2 步：填写内容（NT-03）

#### 6. 跨端协同、原型演示与核心验收清单

##### 6.4 各页面与弹窗异常校验、额度超限及轻提示清单

| 触发位置 | 异常 / 额度超限场景 | 系统拦截行为与轻提示文案 |
| --- | --- | --- |
| 家校通知列表页 | 无页面查看权限访问 | 整页拦截，不展示任何通知数据，提示：“当前账号没有家校通知权限，请联系管理员。” |
| 家校通知列表页 | 筛选无匹配或暂无数据 | 保持筛选栏、工具栏与 15 列表头不变，第 1 行合并展示“暂无对应数据”，无分页栏。 |
| 家校通知列表页－编辑 | 目标通知已有接收人阅读/确认/签字 | 行内“编辑”按钮置灰禁用，点击或强触拦截提示：“已有接收人阅读，暂不支持编辑。” |
| 家校通知列表页－编辑/删除 | 目标学校超出当前运营管理范围 | 拦截操作并弹出轻提示：“当前账号无权操作该学校。” |
| 第 1 步－选择学校 | 未选择任何学校点击“下一步” | 阻止跳转，弹出轻提示：“请先选择目标学校。” |
| 第 2 步－通知标题 | 为空或纯空格提交；超过 50 字 | 为空提示：“请输入通知标题”；输入框上限硬截断 50 字。 |
| 第 2 步－通知内容 | 正文块全部为空点击“下一步” | 拦截提示：“请填写通知内容。” |
| 第 2 步－图片/视频/链接 | 封面或正文图片格式不符；视频超 10 分钟；链接非 `http://` 或 `https://` | 分别弹出轻提示：“仅支持上传 JPG、JPEG、PNG 格式图片”、“视频时长不能超过 10 分钟”、“请输入以 http:// 或 https:// 开头的有效链接地址”。 |
| 第 2 步－附件上传 | 附件数量超 9 个；单文件超 20MB；格式不在白名单 | 拦截上传并分别弹出轻提示：“最多支持上传 9 份附件”、“单个附件大小不能超过 20MB”、“仅支持 PDF、Word、Excel、JPEG、JPG、PNG 格式文件”。 |
| 第 3 步－发布对象 | 未选择任何学生和教师点击发布 | 拦截提交并弹出轻提示：“请至少选择 1 名发布对象。” |
| 第 3 步－定时发送 | 开启定时但时间早于或等于当前时间、或格式非法 | 拦截提交并弹出轻提示：“定时发送时间须晚于当前时间，请重新输入。” |
| 第 3 步－发布/保存 | 并发已读锁冲突；权限被动态收回；网络超时 | 并发提示：“该通知已有接收人阅读，无法保存修改。”；撤权提示：“权限已变更，当前操作无权限。”；超时提示：“请求超时，发布结果未确认，请返回列表核对后再操作。” |
| 预览弹窗－复制链接 | 点击“复制链接”成功 / 链接为空 / 剪贴板不可用 | 成功轻提示：“已复制链接”；为空轻提示：“链接地址为空，无法复制”；失败轻提示：“复制失败，请手动复制链接”。 |
| 删除确认弹窗 | 确认删除成功 / 目标通知已被他人删除 | 成功轻提示：“删除成功”；不存在轻提示：“该通知已不存在，请刷新列表。” |
