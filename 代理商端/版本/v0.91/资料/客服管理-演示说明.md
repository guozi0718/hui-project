# 客服管理演示说明

## 页面用途与入口

本页用于代理商维护本代理商自建客服、设置本代理商默认客服，并管理客服与学校的关联。入口是左侧独立一级菜单“客服管理”，稳定页面地址为 index.html?page=cs。页面没有客服二级菜单。查看、新增、编辑、删除和关联学校都在同一客服列表上下文中完成。

## 数据范围与权限

- 列表只显示本代理商自建客服及运营后台已成功关联给本代理商的平台客服；其他代理商的客服和未关联的平台客服不可见。
- 代理商自建客服可按当前代理商权限查看、新增、编辑、删除、设为默认及关联学校。
- 关联到本代理商的平台客服作为临时客服显示，保留平台客服身份，只能查看；代理商端不能编辑、删除或修改其学校关联。平台客服资料由有权的运营人员维护。
- 默认客服按本代理商服务范围单独管理。代理商新建的第一名自建客服自动成为默认客服；之后新增的客服不会自动替换默认。每个代理商服务范围最多一名默认客服；当前默认客服不能被单独关闭或删除，先将其他合格客服设置为默认后才能删除原默认客服。
- 客服详情为只读展示。客服操作日志不在本页单独查看，统一从“系统管理 → 操作日志”进入。

## 列表、筛选与操作

筛选字段为客服姓名、联系电话。输入条件后点击“查询”才更新列表；点击“重置”清空条件并回到第一页。列表按当前筛选结果分页，支持每页10、20或50条。

列表字段为客服类型、客服姓名、联系电话、工作时间、默认客服、已关联学校和操作。平台代理商客服带有“临时客服”标记。操作包括“查看”，以及对本代理商自建客服提供的“编辑”“删除”“关联学校”。平台临时客服不出现可写操作。

无匹配时显示“暂无符合条件的客服”。查询失败、超时或权限失效时显示对应提示，不用旧结果冒充新列表；可在权限有效后重新查询。

## 客服资料与校验

| 字段 | 规则 |
|---|---|
| 客服姓名 | 去除首尾空格后必填，1—50字；只有空格视为空 |
| 联系电话 | 只允许数字，不限制位数；本代理商负责机构范围内不得与其他有效客服重复 |
| 工作日期 | 至少选一个星期日期 |
| 工作时间 | 只支持一段起止时间，结束时间必须晚于开始时间 |
| 客服类型与归属 | 新建时由当前端确定；保存后不能更改既有客服类型或所属代理商 |
| 默认客服 | 该代理商第一名自建客服自动成为默认；后续新增不自动切换；切换默认后原默认自动取消，每个服务范围至多一名默认 |
| 学校关系 | 只允许选择当前代理商负责且有效的学校；一所学校可关联多位专属客服 |

新建和编辑成功后回到当前客服列表。编辑读取打开时的客服版本；提交前重新核对身份、权限、记录版本和负责范围。保存失败时保留输入，不用旧资料覆盖最新数据。

## 默认客服规则

默认客服用于没有学校专属客服时的服务兜底。学校有专属客服时，优先展示该校专属客服；没有专属客服时，按当前服务范围的默认客服回退。平台默认客服必须保持有效。

代理商首次新增自建客服时，系统将其设为该代理商默认客服；如已有平台代理商默认客服，则本次自建客服成为该代理商默认。该代理商之后新增的客服不自动切换默认，用户可在列表主动切换。切换成功后原默认自动取消，任何时刻每个代理商服务范围至多一名默认客服。无法关闭当前默认、客服已失效或超出当前代理商范围时阻止操作。默认客服关联平台关系被解除前，须先更换该代理商的默认客服。

## 关联学校

点击“关联学校”进入所选客服的学校选择弹窗。可以按地区及学校名称筛选候选学校；筛选只改变当前候选列表，不自动取消其他条件下已选学校。点击“查询”应用候选条件，“重置”清除候选查询条件。

“全选/全不选”只作用于当前筛选结果。筛选外的已选学校继续保留；无候选结果时全选操作禁用。底部计数显示已选与可选学校数量。确认保存前重新检查客服权限、学校归属和记录版本；无效学校不写入。取消关闭不改变已保存的学校关系。

## 查看、删除与返回

- “查看”打开只读客服详情，显示当前客服资料、工作时间、默认状态和已关联学校；关闭后回到原列表条件和页码。
- “删除”先展示确认窗口，说明删除后将解除客服与学校的关联。取消不改变客服和关联；确认时再次校验客服仍有效、属于当前代理商且不是当前默认客服。
- 默认客服不能删除。平台临时客服不能在代理商端删除。
- 切换菜单或重新打开客服页签时，按主菜单规则重新加载初始筛选和分页；仅关闭弹窗时保留本次列表上下文。
- 客服菜单加载失败时显示错误和重试入口；切换其他菜单后其他功能仍可用。

## 异常逻辑

| 场景 | 处理 |
|---|---|
| 姓名为空、全空格或超出50字 | 定位姓名字段、阻止保存并保留其他输入 |
| 电话含非数字字符 | 提示只允许数字、阻止保存 |
| 电话与当前代理商有效客服重复 | 提示重复并保留表单，用户需修改号码 |
| 未选择工作日 | 阻止保存并提示至少选择一天 |
| 结束时间早于或等于开始时间 | 阻止保存，不自动替换为默认时间 |
| 客服 ID 缺失、失效或不属于当前代理商 | 不展示空详情、不提交变更，返回可访问列表 |
| 打开后客服资料已被其他操作更新 | 阻止旧版本覆盖，保留当前输入并提示重新核对 |
| 失去代理商责任范围或权限 | 禁用写操作；不展示其他代理商资料，不自动重放旧提交 |
| 尝试编辑/删除/关联平台临时客服 | 阻止操作并提示平台客服只能查看 |
| 删除或解绑当前默认客服 | 阻止操作，提示先设置其他有效默认客服 |
| 关联选择中地区/学校失效 | 删除不可访问候选；确认保存时复验，失效学校不写入 |
| 查询无匹配、失败或超时 | 空结果、查询异常、超时分别提示；失败时保留条件，允许手动重试 |
| 重复点击或提交结果不确定 | 避免重复写入；刷新列表或日志核对后再继续，不自动重提 |
| 取消确认弹窗 | 关闭弹窗并保留原资料、关系和默认值 |

所有客服弹窗的标题行和底部按钮行固定，中间内容独立滚动；外层页面不随弹窗正文滚动。没有业务底部按钮的详情窗口不额外增加操作按钮。

## 演示操作与边界

页面“演示说明”随列表、查看、新增、编辑、删除确认及学校关联上下文更新。列表场景可查看无匹配、加载失败、超时和无权限；编辑和关联场景可查看必填校验、记录变化、权限失效和提交失败。“恢复默认”撤销当前演示覆盖。场景按钮互斥，不能触发真实写操作。

本页使用静态演示数据，不连接生产账号、权限、持久化服务或实际客服拨号。默认值、关联结果和操作日志仅展示原型中的样例行为，不代表线上服务状态。
