# 小程序开发与发布

这是一个完整小程序，家长与教师是两种可切换身份。所有功能在此项目内维护。

1. 读取当前版本.json、该版本页面路由与文档，按用户要求从最新完整版本新建递增版本。
2. 只修改点名功能，保留其他页面、样式、演示说明及已确认规则；每个版本自带完整双端和3份独立MD。
3. 采用独立页面入口与参数路由；详情刷新恢复具体记录，缺参/无权明确提示。同页Tab和弹层不累积页面栈。本期共享运行时保留，后续逐步拆源码。
4. 三份功能MD完整独立，包含异常逻辑，不关联其他版本文档，不插截图。
5. 更新版本文件清单与当前版本.json、版本记录.md；运行“node 小程序/工具/校验版本.cjs vX.Y”和必要交互检查。
6. 用户2026-11-25已授权：修改与验证完成后自动普通推送本仓库小程序目录。使用“node 小程序/工具/发布版本.cjs”。不得推其他端、不得推旧库、不得强推或覆盖已发布版本。
7. 项目产品文档不插入技术实现细节；页面级开发说明维护在原型中。文件与路由及源码组织约定放协作文档。
8. 已发布版本和标签保留。业务定版与候选发布分别记录，不能将一次推送当作用户验收。
