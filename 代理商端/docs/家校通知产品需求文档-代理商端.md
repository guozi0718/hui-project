产品版本：V1.0.0（第一期·新增功能）  
文档编号：PRD-HUI-AG-FN-20261125  
文档版本：V1.0  
适用端：代理商端

#### 1. 需求背景与业务目标

在徽项目代理商后台中，本期全新上线“校务管理 → 家校通知”功能模块，并将其作为代理商后台首次进入的默认首屏业务页面。代理商人员需要在授权范围内为名下代理模式的合作学校代发校园通知（如安全宣教、校徽办理说明、家庭教育课程等），并在同一页面内集中查看本代理商团队成员代发的全部通知、预览阅读效果、导出打印版 PDF、跟踪学生与教师查收统计，以及对尚未产生查收记录的通知进行修改或删除。

本期核心目标：

1. **三步向导精准代发**：采用“选择学校 → 填写内容 → 准备发布”三步向导流程，先明确锁定 1 所授权代理模式学校，再编辑图文音视频内容与附件，最后配置接收范围与发送方式，彻底杜绝发错学校或误带他校名单。
2. **代理商专属范围与名义管控**：
   - 代理商仅能查看和操作**本代理商成员代发**且所属学校仍在当前代理商授权范围内的通知（同属一家代理商的成员共享本代理商代发记录）；
   - 新建代发通知时，**“以学校名义通知”开关固定开启且不可关闭**（强制以目标学校名义对外展示，严禁以代理商个人名义发布）；
   - 新建代发的接收对象严格限定为**“全体学生”**与**“全体教师”**两项多选（可选其一或同时全选，不支持挑选单个年级、单个班级或具体个人）；
   - 新建代发固定为**美文通知**，**不提供草稿箱，也不提供截止时间字段**（通知发布后不因经过时间而进入截止状态）。
3. **图文素材清晰度与等比不裁切呈现**：明确规范通知封面（建议 `900×383px` 高清素材）与正文配图（建议宽 `1080px` 清晰原图）上传指引；在通知详情与预览中，封面最大 `320×136px`、正文配图最大 `320×180px` 按原图比例居中完整显示、不裁切，正文图片不套固定大画框、不留多余空白。
4. **查收锁定防篡改与分级统计**：通知一旦有任意 1 位家长或教师产生阅读、确认或签字记录，立即锁定禁止编辑，保障家校回执凭证严肃性；提供“学生统计（班级汇总 A 页 → 班级学生明细 B 页）”与“教师统计”双视图及家长手写签字/确认回执明细查阅。
5. **统一日志留痕**：代发通知的发布、修改、删除等关键操作统一接入`系统管理 → 操作日志`页面留存备查。

#### 2. 一期功能范围

| 家校通知列表 | 仅展示本代理商成员代发且当前仍有授权的通知；提供通知标题、发布人、通知类型、查收方式、发布状态（待发送/已发送）、发布时间共 6 项组合筛选（不展示通知来源与内容形式筛选）；14 列表格展示目标学校、标题、名义、四项统计人数及`预览`、`编辑`、`删除`、`阅读统计`操作。 |

| 阅读与回执统计 | 支持切换`学生统计`（班级汇总页 A → 班级学生明细页 B）与`教师统计`页签，按查收方式动态统计已读/未读/已确认/已签字人数，支持点击`查看`查阅每位关联家长的阅读、确认或手写签名明细（不提供提醒按钮）。 |
| 删除通知与离开保护 | 点击`删除`经风险确认弹窗复验后删除归档，全端普通列表立即隐藏；编辑存在未保存修改时返回、切菜单或关闭页签触发放弃确认拦截。 |

##### 2.2 本期不包含范围

本期不包含：Web 端通知草稿箱与保存草稿功能；已发通知撤回或添加补充说明入口；新建代发截止时间设置及“已截止”状态；挑选单个年级、单个班级或单个学生/教师发送；正文录音块录入；阅读统计页内的“提醒未读”催办按钮；查看学校自发、教师自发或平台直营学校的通知记录。

#### 3. 核心业务概念、权限矩阵与全局一致性规则

##### 3.1 核心业务对象与基础规则

| 业务概念 | 业务定义与数据来源 | 一期核心业务规则 |
| --- | --- | --- |
| 代发通知归属 | 代理商代某所学校发布的家校通知 | 每条通知唯一绑定 1 所目标学校；通知资产归目标学校所有（学校端可见），同时在代理商端由同一代理商组织内的全部授权成员共享查看与管理。 |
| 通知类型 | 通知的版式分类 | 仅分 **`普通通知`** 与 **`美文通知`** 两类。代理商端新建代发固定为 **`美文通知`**；若编辑符合未查收条件的既有`普通通知`，则仅展示唯一文本块且保存后仍维持`普通通知`类型不变（链接属于正文内容块之一，不单列为第三种通知类型）。 |
| 发布名义 | 家长与教师端看到的发布落款主体 | 代理商代发通知时，**`以学校名义通知`固定开启且置灰禁用**，对外统一展示目标学校名称，严禁切换为代理商个人名义。 |
| 发布状态 | 通知当前的发送生命周期状态 | 本端仅包含 **`待发送`**（开启了定时发送且尚未到达计划时间，橙色标签）与 **`已发送`**（即时发布成功或定时任务已到点发出，绿色标签）。通知发布后**不设截止时间，也不随时间流逝进入截止状态**；草稿与已删除记录不在列表展示。 |
| 查收方式 | 接收人需要履行的阅读或回执动作 | 共 3 种枚举：<br>1. **`只需阅读查看`**：打开通知详情即计为已读并完成；<br>2. **`需确认收到`**：打开计已读，点击“已收到”确认后计为已确认；<br>3. **`需签字确认`**：打开计已读，提交手写签名后计为已签字。 |
| 代理商发布对象范围 | 新建代发允许勾选的接收人群 | 仅提供 **`全体学生`** 与 **`全体教师`** 两个勾选项（可单选其一，也可同时勾选两项；至少勾选一项）。系统不直接勾选家长——勾选`全体学生`后，目标学校全部在籍学生名下关联的所有家长均可接收。 |
| 学生汇总 vs 家长个人回执 | 多家长家庭的统计去重口径 | 统计人数按**学生个体去重计算**（1 名学生关联爸爸、妈妈多位家长时，学生总数只计 1 人）：只要其中**任意 1 位关联家长**阅读，该学生即计入`已读`；任意 1 位家长完成确认或签字，该学生即计入`已确认`或`已签字`。在个人`明细`弹窗中仍分别保留每位家长的独立阅读、确认与签字记录。未关联任何家长的学生仍计入学生总数与进度分母，并标注`（未关联家长）`。 |
| 查收锁定规则 | 保障已触达通知不被事后改写 | 只要通知已产生**任意 1 条**接收人阅读、确认收到或签字记录，该通知立即进入查收锁定态——列表`编辑`按钮置灰禁用（悬停提示`已有人查收，不可编辑`），后台同步拒绝任何内容修改请求。 |
| 操作人快照 | 创建通知时记录的执行人姓名 | 列表`操作人`列展示通知创建发布时保存的操作人员真实姓名快照，不随事后账号改名而改变。 |

##### 3.2 角色权限与数据范围矩阵

| 权限控制项 | 代理商端可见与可操作范围 | 校验时机与越权处理 |
| --- | --- | --- |
| 合同管理管辖权限（总控规则） | **列表操作列的全部 4 个按钮（`预览`、`编辑`、`删除`、`阅读统计`）均统一受“运营后台 → 合同管理”菜单的代理商权限管辖控制** | 按钮渲染及点击进入/提交瞬间均实时校验当前代理商在“运营后台 → 合同管理”中对目标学校的代理商权限管辖是否有效。若管辖权限被收回、到期或学校不再归属当前代理商管辖，全部 4 个按钮一律置灰禁用并悬停提示**“无操作权限（受运营后台-合同管理代理商权限管辖控制）”**，直接访问对应入口一律拦截拒绝。 |
| 列表与预览/统计查看 | 当前代理商组织成员代发、且在“运营后台 → 合同管理”中仍处于当前代理商有效管辖范围内的未删除通知 | 进入页面、筛选查询、翻页、点击`预览`或`阅读统计`时均校验。非本代理商代发、超出合同管理管辖范围或已删除通知一律不可见/不可操作；手工构造无效地址访问时拦截提示**“通知不存在或无权限查看”**并退回列表。 |
| 选择代发学校与新建发布 | 在“运营后台 → 合同管理”中具备当前代理商有效代理管辖授权的学校 | 打开第 1 步选学校、点击`下一步`进入编辑、最终点击`发布通知`提交时三重校验。无管辖授权学校不出现在候选列表；提交前若目标学校管辖权限刚被收回或转为直营模式，立即阻止发布并提示**“当前账号无权操作这所学校”**。 |
| 编辑通知 | 在合同管理代理商权限管辖范围内、未删除，且**当前尚无任何接收人阅读、确认或签字记录**的通知 | 列表按钮渲染、进入编辑页、最终点击`保存修改`时三重校验。无合同管辖权限时按钮置灰提示合同管理权限不足；已有人查收时按钮置灰提示`已有人查收，不可编辑`。 |
| 删除通知（随时可删） | 在“运营后台 → 合同管理”代理商权限管辖范围内的全部未删除代发通知（**不限通知发送状态，不限是否已有人阅读、确认或签字，随时可以删除**） | 列表按钮渲染、打开删除确认框、点击最终`确定`时均校验合同管理管辖权限与通知存在状态。无合同管辖权限时按钮置灰提示权限受控，强制触发拦截提示`当前账号无权删除此通知`。 |
| 操作日志查看 | 本代理商权限范围内的家校通知操作记录 | 在`系统管理 → 操作日志`页面按账号权限校验展示，只读不可篡改。 |

##### 3.3 全局数据一致性、并发冲突与动态权限变化总则

1. **编辑期间并发修改防覆盖原则**：当两名本代理商成员（或有权限的学校管理员/运营人员）同时打开同一条未查收通知进行修改时，若另一方已抢先保存新版本，当前编辑页顶部立即弹出并发冲突提示面板（提示**“其他端已更新此通知，你的输入已保留。请先查看最新版本。”**），直接点击保存会被拦截，支持点击`查看两份内容`逐项比对差异或点击`载入最新版本`，绝不静默覆盖他人刚保存的内容。
2. **编辑期间产生首个查收记录实时拦截原则**：打开编辑页面时通知尚无人阅读，但在用户编辑过程中恰好有第 1 位家长或教师打开阅读了该通知——用户点击`保存修改`时系统实时复验回执状态，立即拦截保存并报错**“已有接收人阅读、确认或签字，通知不可编辑。”**。
3. **定时通知自动到点发布原则**：状态为`待发送`的定时通知到达计划发送时间后，系统自动将其状态切换为`已发送`，按发布时锁定的接收范围向学生关联家长及教师开放查收，并记录定时发布日志。
4. **防连点、素材完整性与存储失败保护**：
   - 正文图片、视频或附件未读取保存完成、或添加了空的图片/视频内容块未选素材时，禁止提交发布；
   - 点击确认发布期间防重复点击，同一通知绝不重复生成两条记录；保存异常或网络失败时停留在编辑页，完整保留标题、正文块、附件与发布设置供重试。
5. **权限动态回收与切换账号隔离原则**：停留期间若某学校解除与本代理商的合作授权或转为直营模式，刷新列表、选择学校或提交保存时立即剔除无权学校数据并阻止写入；切换账号时彻底清空上一账号状态。

##### 3.4 主菜单导航与顶部页签通用交互规则

1. **固定默认入口**：代理商后台通过主入口进入时，默认展开左侧`校务管理`并打开二级菜单`家校通知`实际列表页，同步在顶部页签栏建立`家校通知`激活页签（禁止出现空白首屏；左侧菜单与顶部页签均无未读小红点或计数徽标）。
2. **页内子视图与页签联动**：家校通知的列表、三步新建向导、编辑页、通知预览页、阅读与回执统计页均在同一个`家校通知`页签工作区内切换展示，不额外裂变多个顶部页签；当处于新建或编辑向导且存在未保存内容时，点击左上角返回、点击左侧其他菜单或关闭顶部`家校通知`页签，均统一触发未保存离开确认拦截。

##### 5.1 家校通知列表页（FN-01）

###### 5.1.1 页面布局与数据范围

###### 5.1.2 筛选查询区（6 项筛选 ＋ 查询/重置）

**筛选交互、逻辑校验与异常场景**

1. **点击查询或回车生效**：选择下拉项或日期后不立即刷新表格；点击`查询`按钮或在标题/发布人输入框内按回车键才应用全部条件并重置回第 1 页。

4. **空结果与查询失败区分**：无匹配通知时表格居中展示铃铛空态图标与文案**`暂无符合条件的通知`**；查询失败或超时时保留当前筛选词与页码并提示手动重试，绝不将读取失败伪装成 0 条记录。

4. **`阅读统计`**：须同时满足“合同管理代理商管辖权限有效”且通知状态为`已发送`，点击进入 5.5《阅读与回执统计》子页；若无合同管辖权限则置灰禁用；若状态为`待发送`，按钮置灰禁用并悬停提示**`该状态暂无阅读统计`**。
5. **底部分页栏**：左侧展示`共 X 条`，右侧提供`每页 [10 / 20 / 50] 条`下拉框（默认 `10`）、`上一页`、`第 M / N 页`、`下一页`；切换每页条数回第 1 页，删除当前页最后一条记录后自动回退至有效页。

###### 5.2.3 第 3 步：准备发布（FN-04 / FN-05 / FN-06）

采用横向对齐表单版式：每行左侧固定宽度展示字段标签，右侧展示对应控件，同一行垂直居中对齐。**代理商端新建代发不展示`截止时间`字段。**

| 1. 发布对象 | 是 | 默认未选（显示`已选中学生0人，教师0人`） | 点击展开**代理商专属下拉多选菜单**（点击外部空白收起），菜单内**仅提供两个选项**：<br>• **`全体学生`**（右侧显示该校学生总人数，勾选带绿色 `✓`）<br>• **`全体教师`**（右侧显示该校教师总人数，勾选带绿色 `✓`）<br>支持单选其中一类或同时勾选两类，按钮实时汇总显示 `已选中学生X人，教师Y人`；**严禁选择单个年级、单个班级或具体个人**（异常篡改拦截提示`代理商只能选择全体学生或全体教师`） |
| 2. 查收方式 | 是 | 下拉框默认`只需阅读查看` | 可选：`只需阅读查看`、`需确认收到`、`需签字确认` |
| 3. 以学校名义通知 | 是 | **默认开启，且置灰禁用** | 代理商代发强制使用目标学校名义，开关不可关闭（异常篡改拦截提示`代发必须使用学校名义`） |
| 4. 定时发送 | 是 | 开关默认关闭（即时发布） | 开启开关后，右侧同行展示日期时间选择框并默认填入**次日 `09:00:00`**；点击选择框打开《选择定时发送时间》弹窗（FN-05，含`日期`与精确到秒的`时间`输入框，按钮`取消`/`确定`），格式为 `YYYY-MM-DD HH:mm:ss`，**所选时间必须严格晚于当前点击发布的时间** |
| 底部向导栏 | — | 左侧`上一步`；右侧`发布通知`（开启定时后显示`定时发布`） | 点击`上一步`返回第 2 步且完整保留已填写的标题、封面、正文、附件与背景；本端不提供`保存草稿`按钮 |

**发布校验、二次确认弹窗（FN-06）与异常场景**

1. **发布前置校验**：未勾选任何发布对象（学生 0 人且教师 0 人）点击发布时报错**`请选择发布对象`**；开启定时发送但时间为空、格式非法或早于等于当前时间时报错**`请填写有效的定时发送时间，格式为 YYYY-MM-DD HH:mm:ss`**；第 2 步若有未通过的内容校验项同样在顶部红色错误框明确提示。
2. **发布二次确认弹窗（FN-06）**：点击`发布通知`（或`定时发布`）弹出二次确认弹窗，标题为`确认发布`（或`确认定时发布`），正文逐行清晰列出：
   - `学校：【目标学校名称】`
   - `接收对象：学生 X 人，教师 Y 人`
   - `查收方式：【所选查收方式】`
   - `计划发送：【定时时间】`（仅开启定时发送时展示）
   底部按钮为`取消`、`确定`。点击`取消`留在第 3 步；点击`确定`再次复验学校代发权限与全部字段后正式入库：即时发布状态直接变为`已发送`（立即生成接收学生名单快照并开放家长/教师端查收），定时发布状态变为`待发送`，弹出轻提示`保存成功`（或`定时通知已保存`）并展示最新通知结果。
3. **保存失败与超时防重**：提交期间按钮防连点；若网络或保存失败，留在当前页顶部提示未保存原因并保留全部输入与选择；若请求超时结果未确认，先返回家校通知列表核对该标题是否已生成，避免重复发布两条相同通知。

##### 5.3 修改已有通知（两步向导，FN-07）

从列表操作列点击未锁定通知的`编辑`进入修改流程（顶部显示返回箭头、标题`修改通知`及目标学校徽标，步骤条显示 2 步：**`1 填写内容` → `2 准备发布`**，无需重新选学校）。

**编辑边界、锁定规则与并发冲突处理**

1. **可修改字段 vs 锁定字段**：
   - **允许修改**：`通知标题`、`封面`、`通知内容`、`附件`、`全文背景`；若原通知为符合条件的`普通通知`（如历史协同记录），编辑时正文仅保留唯一富文本块（不展示新增内容块、上移、下移、删除块按钮），保存后仍保持`普通通知`类型不变；若为`美文通知`则支持完整多内容块增删调序；
   - **严格锁定不可改**：进入第 2 步`准备发布`核对时，**`发布对象`、`查收方式`、`以学校名义通知`、`定时发送`及计划时间全部置灰禁用只读展示**（任何试图篡改发布设置的提交一律拦截提示`发布对象、查收方式和发布时间不能修改`）。
2. **查收实时锁定拦截**：进入编辑页前及点击最终`保存修改`确认时均实时检查回执——只要已有任意 1 位学生家长或教师阅读、确认或签字，立即阻止保存并提示**`已有接收人阅读、确认或签字，通知不可编辑。`**。
3. **多端并发修改冲突面板**：若编辑期间其他有权账号已先行更新了该通知，页面顶部立即展示冲突提示框（标明最新版本号与修改人，说明当前本地输入已保留、直接保存不会覆盖最新版本），提供`查看两份内容`（弹窗上下对照本地未保存输入与最新版本内容）与`载入最新版本`（二次确认后刷新为最新内容）操作。

##### 5.4 通知预览与导出 PDF（FN-08）

1. **列表入口《通知预览》页**：
   - 在家校通知列表点击任意行的`预览`按钮，进入页内只读《通知预览》视图；
   - **固定头尾与独立滚动布局**：顶部标题栏（含左侧返回按钮与标题`通知预览`）和底部操作栏（含主按钮`导出 PDF`、次按钮`关闭`）固定在视口上下两端，**仅中间通知正文工作表区域独立纵向滚动**；
   - **只读纯净呈现**：仅按该通知所选全文背景完整渲染通知标题、发布名义、发布时间、封面（最大 `320×136px` 等比居中不裁切）、正文各内容块（配图最大 `320×180px` 等比居中不裁切且无固定大画框留白；视频/链接/附件可交互查看），**绝不展示接收对象名单、查收统计数字或个人回执**。
2. **导出 PDF 与打印隔离**：点击底部`导出 PDF`按钮调起浏览器打印/导出 A4 文档，系统自动隐藏顶部导航栏、`通知预览`外层标题栏、右上角`演示说明`及底部操作按钮，仅输出排版干净的通知正文内容；导出取消或失败时停留在当前预览页可再次点击导出。
3. **关闭返回与零副作用**：点击`关闭`或左上角返回箭头，立即回到家校通知列表并完整保留进入前的筛选条件、每页条数与当前页码。**任何预览、打印或导出 PDF 行为均不会触发通知发布，也绝不产生任何家长或教师的阅读、确认或签字记录。**

##### 5.5 阅读与回执统计（参照学校端视觉与排版规范，FN-09 / FN-10 / FN-11）

状态为`已发送`且在合同管理管辖权限内的通知，点击列表操作列`阅读统计`进入独立统计子页面：整体视觉风格、卡片式指标栏、筛选容器、表格行高与间距严格参照**学校端阅读统计页面**标准，保持留白舒展、行间距清晰易读。顶部左侧提供返回列表箭头按钮与标题`阅读与回执统计`，下方提供 **`学生统计`**（默认选中）与 **`教师统计`** 两个切换页签。**两个统计页签均不提供“提醒未读”按钮。**

###### 5.5.1 顶部卡片式汇总指标栏

以横向自适应卡片网格展示（蓝色总数卡、绿色已读/已完成卡、暖橙未读/待完成卡，含清晰大字号数字与单位“人”，不展示完成率），根据当前通知的`查收方式`与当前页筛选范围动态计算：

| 通知查收方式 | 学生统计顶部指标卡片 | 教师统计顶部指标卡片 |
| --- | --- | --- |
| 只需阅读查看 | `学生总数`、`已读`、`未读` | `教师总数`、`已读`、`未读` |
| 需确认收到 | `学生总数`、`已读`、`未读`、`已确认收到`、`待确认` | `教师总数`、`已读`、`未读`、`已确认收到`、`待确认` |
| 需签字确认 | `学生总数`、`已读`、`未读`、`已签字`、`未签字` | `教师总数`、`已读`、`未读`、`已签字`、`未签字` |

###### 5.5.2 学生统计：班级汇总表 ＋ 内联展开班级学生明细

1. **班级汇总筛选区（圆角浅灰筛选卡片，仅 2 项下拉）**：
   - `年级`：默认`全部年级`，仅列出本次通知学生接收范围内实际包含学生的年级；切换年级后，`班级`自动重置为`全部班级`且页码回第 1 页，顶部指标卡片与下方班级表同步按所选范围重算；
   - `班级`：默认`全部班级`；当年级处于`全部年级`时，下拉选项同时展示**`年级名称 班级名称`**（如`五年级 2班`），已选具体年级时展示`班级名称`。
2. **班级汇总表格（圆角表格容器，舒展行高，共 4 列，每页 10 个班级分页）**：
   - 列顺序：**`年级` → `班级` → `阅读进度` → `学生明细`**；
   - `阅读进度`展示 **`已读学生数 / 该班学生总数`**（附`已读 / 学生`辅助说明；多位家长关联同一学生只计 1 人，未关联家长的学生正常计入分母）；无学生范围时显示`暂无学生`；
   - 点击某班右侧`明细`按钮（展开后该按钮切换为`收起`），在班级汇总表正下方以浅绿柔和边框卡片**内联展开《班级阅读明细》区块**（同时完整保留上方班级汇总表的年级、班级筛选与页码）。
3. **内联展开《班级阅读明细》区块**：
   - 卡片头部展示`班级阅读明细`小标、当前班级标题 **`【年级 班级】 · 学生明细`**、本班人数与已读/已完成查收摘要，右侧提供`收起明细`按钮；
   - 卡片内筛选栏仅提供`状态`下拉框（随查收方式动态生成，绝不显示不适用状态）与`学生姓名`模糊搜索输入框＋`查询`按钮；
   - 班级学生明细表（4 列，按学生姓名拼音排序）：**`学生姓名`**（未绑定家长紧跟标注`（未关联家长）`） → **`阅读情况`**（圆角胶囊状态标签：绿色`已读` / 暖橙`未读`） → **`查收结果`**（`无需确认` / `已确认收到` / `待确认` / `已签字` / `未签字`） → **`家长回执`**（点击`查看家长明细`打开 5.5.4 表格化回执明细弹窗）。

###### 5.5.3 教师统计视图（FN-10）

切换顶部页签至`教师统计`后，沿用与学生统计一致的卡片式汇总指标栏、浅灰筛选卡片与舒展行高表格：包含`状态`下拉框（随查收方式动态变化）＋`教师姓名`输入框＋`查询`按钮 → 4 列教师名单表格（**`教师姓名` → `阅读情况`（胶囊标签） → `查收结果` → `回执明细`**，按教师姓名拼音升序排列，不展示年级与班级列，点击`查看明细`打开教师回执明细弹窗，无接收教师时显示`暂无教师`） → 每页 10 人分页栏。

###### 5.5.4 家长 / 教师阅读与回执明细弹窗（FN-11）

点击学生行`查看家长明细`或教师行`查看明细`打开，标题为`家长阅读与回执明细`（教师为`教师阅读与回执明细`），底部提供`关闭`按钮（右上角带`×`）：

1. **表格化清晰呈现**：展示 **`家长姓名`（或`教师姓名`） → `操作时间`（`YYYY-MM-DD HH:mm:ss`） → `状态`（圆角状态标签） → `签字照片`**（仅存在签字记录时展示该列，点击签名缩略图可查看原图）；表头固定、超长记录纵向滚动。
2. **无回执记录 vs 未关联家长严格区分**：
   - 若该学生已关联家长但尚无任何家长打开阅读，提示`暂无阅读或回执记录。`；
   - 若该学生尚未绑定任何家长账号，明确提示**`该学生未关联家长，暂无家长回执。`**，绝不伪造空白家长行。

##### 5.6 删除通知确认弹窗与未保存离开确认弹窗（FN-12）

1. **删除通知确认弹窗**：
   - 在家校通知列表点击有权通知的`删除`按钮打开警告确认弹窗，标题为`删除通知`，正文展示黄色感叹号图标与文案 **`确认删除该通知`**，底部按钮统一为`取消`、`确定`；
   - 点击`取消`关闭弹窗不改数据；点击`确定`再次复验当前账号管理权限与通知存在状态：校验通过后将通知移入后台删除归档（保留删除当时的内容快照、回执快照、删除人与删除时间备查），同时从代理商端、学校端、运营后台、教师端及家长端常规通知列表中立即移除（家长若从历史卡片点入显示“这条通知已删除”），弹出轻提示`删除成功`并刷新列表；前台不设“已删除”筛选或恢复入口。
2. **未保存离开确认弹窗**：
   - 在新建代发向导或修改通知页面，当标题、封面、正文内容块、附件或发布设置相比打开时发生过修改（`dirty` 状态）时：
     - 点击页内左上角返回箭头返回列表：弹出确认框 **`放弃编辑`**，正文 **`确认放弃当前输入吗？确认后将丢失本次填写内容`**，按钮为`取消`、`确定`；
     - 点击左侧其他菜单或关闭顶部`家校通知`页签：弹出确认框 **`放弃未保存内容？`**，正文 **`离开后未提交的内容不会保存。`**，按钮为`取消`、`确定`；
   - 点击`取消`留在当前编辑步骤并完整保留全部已填内容与素材；点击`确定`丢弃本次未保存输入并执行返回或切页。

##### 5.7 统一操作日志接入与演示说明面板（FN-13）

1. **操作日志接入（系统管理 → 操作日志）**：

2. **右上角“演示说明”面板**：
   - 在通知列表、新建/编辑向导、通知预览、阅读统计及各弹窗右上角统一提供`演示说明`按钮；
   - **列表态可预览场景**：`预览 · 无数据`、`预览 · 无匹配`、`预览 · 加载中`、`预览 · 加载失败`、`预览 · 加载超时`、`预览 · 无权限`及`恢复默认`；
   - **新建/编辑/确认/详情态可预览场景**：`预览 · 加载失败`、`预览 · 权限失效`、`预览 · 对象失效`；编辑页额外提供`预览 · 必填校验`、`预览 · 版本冲突`、`预览 · 提交失败`、`预览 · 结果未知`、`预览 · 附件校验`；
   - 所有演示预览仅在当前界面模拟提示，绝不真实向家长端发送消息或破坏既有演示数据，点击`恢复默认`立即复原。

#### 6. 跨端协同与界面交互规范

1. **多端数据同源协同**：代理商代发通知发布成功后，目标学校的学校 Web 端、运营后台、教师小程序（若勾选全体教师）与家长小程序（若勾选全体学生）实时读取同一份通知档案与查收状态；任一接收人在小程序端完成阅读、确认或手写签字后，本端列表人数列与《阅读与回执统计》页面刷新立即同步最新数据，且通知自动进入查收锁定不可编辑态。
