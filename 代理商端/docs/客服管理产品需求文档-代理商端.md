产品版本：V1.0.0（第一期·新增功能）  
文档编号：PRD-HUI-AG-CS-20261125  
文档版本：V1.0

#### 1. 需求背景与业务目标

在徽项目代理商后台中，本期全新上线“客服管理”模块。代理商需要在本代理商管辖范围内自主维护自有客服人员资料、为申请审核通过的学校配置专属客服、管理本机构唯一的默认兜底客服，并在系统操作日志中查阅本方客服操作记录。同时，运营后台可在授权范围内代为维护本代理商的客服资料、将平台客服关联给本代理商作为临时客服或协助切换默认客服，双端共用同一份客服数据并实时同步。

本期核心目标：

1. **自建客服与学校多对多配置**：代理商可新增、编辑、查看、删除归属本代理商的自建客服；1 名客服可同时服务本代理商名下多所审核通过的学校，1 所学校也可同时绑定多名专属客服，同一所学校与同一名客服的绑定关系唯一、不重复。
2. **本代理商唯一默认客服与首名自建自动默认**：每个代理商服务范围最多设置 1 名默认客服，人选可从“本代理商自建客服”或“运营后台已成功关联至本代理商的平台客服（临时客服）”中选择。**代理商首次新增第 1 名自建客服保存成功后，系统自动将其设为本代理商默认客服**（如之前已有平台临时客服担任本代理商默认客服，则自动替换为本次新建的首名自建客服）；第 2 名及之后新增的自建客服不自动替换当前默认，由用户在列表行内开关主动切换。当本代理商尚未设置任何有效默认客服且学校未绑定专属客服时，家长/教师小程序点击客服电话入口不打开弹窗。
3. **平台临时客服协同与权限边界**：运营后台关联至本代理商的平台客服保留原平台客服归属不变，在本端列表中附带**“临时客服”**标签，仅支持**“关联学校”**（为本代理商负责且审核通过的学校配置专属关联，不影响平台直营或其他代理商的关联关系）及**“通过默认开关设为本代理商默认客服”**，不允许在本端**查看、编辑或删除**（对应按钮置灰禁用并悬停提示原因）。
4. **严格的数据权限隔离**：代理商账号仅能查看和操作本代理商未删除的自建客服、当前有效关联至本代理商的未删除平台临时客服、本代理商负责且申请审核通过的学校，以及明确归属本代理商的当前有效客服操作日志；其他代理商数据、未关联的平台客服及已删除客服的历史日志一律不可见。
5. **跨端实时同步与上下游联动**：本端对客服资料、学校关联、默认客服的保存结果实时同步至运营后台与小程序端；当运营后台解除平台客服关联或变更学校负责机构时，本端列表、候选学校及专属绑定关系实时按最新有效状态同步更新。

#### 2. 一期功能范围

##### 2.1 本期包含范围

| 功能模块 | 代理商端业务范围说明 |
| --- | --- |

| 统一操作日志接入 | 不在客服列表页内单独设置日志按钮，所有成功生效的客服操作统一归口至左侧菜单`系统管理 → 操作日志`页面查询，展示本代理商当前未删除客服事件及归属本代理商的默认客服变更事件。 |

| 原型状态演示面板 | 客服列表及各弹窗右上角统一提供`演示说明`入口，按当前页面或弹窗上下文提供正常态、空态、校验拦截态、并发冲突态与权限异常态的隔离预览及一键恢复默认。 |

##### 2.2 本期不包含范围

本期不包含：客服账号启用/停用冻结开关、客服接待统计报表、客服资料批量导入导出、已删除客服前台恢复及已删除客服历史日志查阅、平台客服资料维护与关联代理商配置、学校负责机构转归操作入口。

#### 3. 核心业务概念、权限矩阵与全局一致性规则

##### 3.1 核心业务对象与基础规则

| 业务概念 | 业务定义与数据来源 | 一期核心业务规则 |
| --- | --- | --- |
| 客服记录 | 一名客服人员的服务档案 | 系统为每名客服生成唯一内部记录标识（页面不展示该标识）；允许不同客服同名，同名记录各自独立展示与关联、绝不自动合并；不以电话号码代替唯一记录标识。 |
| 代理商客服（自建客服） | 由本代理商创建（或运营代本代理商创建）并归属本代理商的自有客服 | 一个代理商可维护多名自建客服；**创建成功时自动绑定当前代理商且永久锁定，后续编辑严禁修改客服类型或转移给其他代理商**；在本端支持查看、编辑、删除（非默认时）、关联学校及设为默认客服。 |
| 平台客服（临时客服） | 由运营平台创建并由运营后台关联至本代理商的客服 | 仅在与本代理商关联有效期间展示在本端列表：`客服类型`显示`平台客服`，`客服姓名`旁附`临时客服`标签；保留平台客服原归属不变，**在本端仅支持`关联学校`（限定本代理商负责且审核通过的学校）与`设为本代理商默认客服`，`查看`、`编辑`、`删除`均置灰禁用** |
| 代理商机构名称 | 当前登录代理商对应的最新有效机构名称 | 页面始终展示机构最新名称；代理商改名不影响名下自建客服、已关联学校及默认客服归属关系。 |
| 学校专属客服 | 与本代理商某所学校建立明确绑定关系的客服 | 1 所学校可同时绑定多名专属客服；家长/教师小程序联系客服时，若学校绑有专属客服则优先展示全部专属客服（代理商客服排在平台客服之前），**专属客服整体优先于机构默认客服**。 |
| 代理商默认客服 | 本代理商服务范围内唯一的兜底客服 | 按代理商维度唯一（最多 1 名，不按单所学校设置默认）；当本代理商名下某学校未绑定任何专属客服时，小程序回退展示本代理商默认客服；若本代理商无有效默认客服，小程序点击客服电话入口不打开弹窗。 |
| 首次自建自动默认规则 | 本代理商从无自建客服到新建首名自建客服的自动配置规则 | 当本代理商尚无任何自建客服记录（含已删后首次新建前从未建过自建客服的初始状态）时，新建第 1 名自建客服保存成功后自动设为本代理商默认客服（若原默认是平台临时客服则自动顶替并取消原默认）；自第 2 名自建客服起不再自动切换默认。 |
| 有效候选学校 | “关联学校”弹窗中允许勾选的学校集合 | 必须同时满足：归属当前代理商负责、学校状态正常且**申请审核已通过**；本代理商其他客服已关联的学校仍允许当前客服勾选（同校多客服并存，互不抢占覆盖）；本人已关联学校支持查看与取消勾选解绑。 |
| 工作时间 | 每周工作星期多选 ＋ 单组每日起止时分 | 仅支持 1 组起止时间段；每周至少勾选 1 天、最多 7 天（周一至周日）；采用 24 小时制 `00:00`—`23:59`，同日起止、不支持跨天，**结束时间必须严格晚于开始时间**；不自动折算法定节假日。 |
| 操作人快照与发起端 | 操作成功瞬间记录的操作人员姓名及实际发起端口 | 日志保留操作当时的真实姓名快照，后续账号改名不影响历史记录；操作模块前缀按实际发起操作的端口记录为`代理商端`或`运营后台端`，不随查看端改变。 |

##### 3.2 角色权限与数据范围矩阵

| 权限控制项 | 代理商端可见与可操作范围 | 权限校验时机与无权限表现 |
| --- | --- | --- |
| 菜单与页面访问 | 具备代理商后台“客服管理”查看权限的当前代理商账号 | 左侧菜单渲染、切换页签、直接访问入口、每次查询/翻页/刷新时均校验。无权限时不展示菜单或进入后正文区居中提示**“当前账号没有客服管理权限，请联系管理员。”**，不展示任何客服数据或开关，其他有权菜单与页签保持正常可用。 |
| 客服新增 / 编辑 / 删除 | 仅限归属当前代理商的自建客服记录（平台临时客服严禁新增、编辑或删除） | 页面按钮渲染、打开弹窗时、点击`确定`提交保存时均校验。无对应写权限时隐藏或禁用按钮；强制触发操作时拦截并提示无权限。 |
| 关联学校维护 | 仅限归属当前代理商的自建客服，且候选学校须属于当前代理商负责并审核通过 | 打开关联弹窗、执行筛选查询、进入二次确认、点击最终`确定`时均校验。严禁跨代理商读取或绑定其他机构学校。 |
| 默认客服开关切换 | 本代理商未删除自建客服 ＋ 当前仍有效关联至本代理商的未删除平台临时客服 | 列表开关渲染及点击切换提交时均校验。无设置权限时拦截切换，原默认客服保持不变。 |
| 操作日志查看 | 本代理商当前未删除自建客服的操作事件 ＋ 明确归属本代理商的默认客服设置/取消事件 | 进入`系统管理 → 操作日志`查询、翻页、重置及刷新时均校验。日志查看权与客服编辑权相互独立；严禁返回已删除客服日志、其他代理商日志或无关平台日志。 |

##### 3.3 全局数据一致性、并发冲突与动态权限变化总则

1. **批量学校关联整体生效原则**：单次关联学校操作中同时包含多所学校的新增绑定或解除绑定时，采用**“全部成功或全部不生效”**原则。只要其中任一所拟新增学校在提交瞬间已不满足“归属本代理商且申请审核通过”条件，整次提交全部拦截，绝不写入半截关联数据。
2. **多人与跨端并发修改防覆盖原则**：当本代理商内部多名成员、或本代理商与运营后台人员同时操作同一名客服（编辑资料、关联学校、切换默认客服或删除）时，后提交的一方检测到客服记录已被抢先修改，立即阻止覆盖并提示**“客服信息已更新，请重新打开后操作”**（默认开关冲突提示**“默认客服已更新，请重新打开后操作”**），保留当前弹窗内用户已输入的内容供核对。
3. **防连点与网络超时防重复原则**：弹窗点击`确定`提交后，按钮立即置灰禁用防止连点或回车重复触发；列表点击默认客服开关切换期间锁定整列开关。若网络超时未收到明确结果，提示**“请求超时，操作结果未确认。请先核对记录后再重试，避免重复提交。”**，系统对同一次提交防重，绝不重复创建两条相同客服或重复生成两条日志。
4. **停留期间权限动态回收与身份切换原则**：
   - **仅收回单项写权限（仍保留查看权）**：在已打开的新增、编辑、删除、关联学校弹窗中点击`确定`或点击列表默认开关时拦截，提示**“权限已变更，当前操作无权限。”**，页面已有权查看的列表允许正常浏览与关闭弹窗；
   - **收回客服管理查看权限或缩小负责范围**：立即清空页面与弹窗中已无权查看的客服记录、学校候选与统计数字，提示权限已变更；此前发出的旧范围慢查询返回结果直接丢弃，严禁覆盖当前界面；
   - **登录失效或切换代理商账号**：登录过期提示**“当前操作人身份失效，请重新登录后操作”**；切换登录另一家代理商账号时，立即清空上一账号的页签缓存、筛选条件、客服列表与未提交表单，按新身份重新加载；
   - **权限恢复后不自动重放**：重新获得权限或重新登录后，按最新权限重新读取数据，**绝不自动重发**此前被拦截的未完成提交。
5. **外部运营解绑保护与学校转归联动原则**：
   - 若某平台临时客服当前正担任本代理商默认客服，运营后台解除该客服与本代理商关联的操作会被前置拦截，要求先将本代理商默认客服切换为其他有效客服后才允许解绑（解绑绝不自动清空本代理商默认客服）；非默认态的平台临时客服被运营解绑后，本端刷新列表立即移除该记录；
   - 当本代理商原负责的某所学校在运营后台被变更为其他代理商或平台直营时，系统自动解除该校与本代理商客服的全部专属关联并生成明细日志，本代理商默认客服配置不受影响。
6. **操作成功与日志同步原则**：仅实际保存成功的业务变更（新增、有实质字段变化的编辑、有关联增减的学校保存、默认客服切换、删除、学校转归自动解绑）生成操作日志；点击取消、校验失败、无实质改动的确定均不生成日志。

##### 3.4 主菜单导航与顶部页签通用交互规则

1. **统一入口与菜单层级**：代理商后台首次打开固定进入`校务管理 → 家校通知`实际页面；左侧主导航中，`客服管理`为独立一级菜单（位于`校务管理`下方、`用户反馈`上方），点击直接切换至客服管理主页面并在顶部页签栏创建或激活`客服管理`页签。左侧菜单与顶部页签均**不显示任何未读小红点或计数徽标**。
2. **页签切换、重新进入与关闭规则**：
   - 在本页内打开、取消或完成任何弹窗，始终保留当前列表的筛选条件、每页条数、当前页码与滚动位置；
   - 通过左侧菜单或顶部页签重新切换进入`客服管理`页面时，按主框架规则重置为初始空筛选条件与第 1 页并重新加载最新列表；
   - 点击顶部非当前激活页签的`×`直接移除该页签，不影响当前正在浏览的页面；点击当前激活`客服管理`页签的`×`时，若新增/编辑弹窗存在未保存修改，先触发《放弃未保存内容？》拦截确认，确认放弃或无未保存修改后关闭本页签，并自动切回左侧相邻已打开页签（无左侧页签则切至剩余首个页签，全部关闭则回到默认首页`家校通知`），绝不退回空白页。
3. **宿主页面加载异常兜底**：页面加载期间展示“正在加载，请稍候。”状态；若页面加载失败或超时，工作区明确展示“页面加载失败”说明及`重试`按钮，不以空白页代替错误提示，且不影响切换使用其他菜单。

#### 5. 页面与功能详细说明

---

##### 5.1 客服管理列表页（CS-01）

###### 5.1.1 页面定位与整体布局

1. **页面结构**：自上而下依次为：页面主标题`客服管理`（右上角提供`演示说明`按钮） → 筛选查询栏（`客服姓名`、`联系电话`输入框及`查询`、`重置`按钮） → 表格上方工具栏（左侧绿色主按钮`新增客服`、文字不带加号，右侧统计文案`共 X 位客服`；不设独立日志按钮或顶部默认客服卡片） → 7 列客服数据表格 → 底部分页栏。
2. **列表可见数据范围**：
   - 合并展示当前代理商名下全部未删除的**`代理商客服`**（自建客服），以及运营后台当前已成功关联给本代理商的未删除**`平台客服`**（姓名旁标记`临时客服`）；
   - 其他代理商的客服、未与本代理商建立关联的平台客服、已解除关联的平台客服及已删除客服均不展示。
3. **默认排序规则**：按客服创建时间从新到旧倒序排列；同一时间创建的客服按姓名中文拼音升序排列；姓名仍相同时按系统记录先后顺序保持稳定排列，翻页与刷新不乱序。
4. **加载态与空状态严格区分**：
   - 首次进入默认第 1 页、每页 10 条、筛选项为空；加载未完成时显示“正在加载，请稍候。”，加载失败或超时时显示明确错误提示及`重试`按钮，**严禁把加载失败展示成“0 位客服”**；
   - 当本代理商尚无任何自建客服也无已关联平台临时客服（初始零数据）或按筛选条件未查到匹配记录时，**保持页面原有框架与 7 列表头完整显示**，仅在表格第一行居中展示**`暂无对应数据`**，**不显示底部分页栏**，也不叠加额外提示框；有新增权限时`新增客服`按钮保持正常可用。

###### 5.1.2 筛选查询区

| 筛选项名称 | 控件类型与必填 | 默认值与占位提示 | 匹配规则与输入限制 |
| --- | --- | --- | --- |
| 客服姓名 | 单行文本输入框；非必填 | 默认空；占位提示`请输入客服姓名` | 最大长度 50 字；提交查询时自动去除首尾空格，在本列表全部可见客服（含自建客服与平台临时客服）中按包含关键词模糊匹配 |
| 联系电话 | 单行文本输入框；非必填 | 默认空；占位提示`请输入联系电话` | 仅允许输入或粘贴数字（自动过滤非数字字符），不限制位数上限；在本列表全部可见客服电话中按连续数字片段包含匹配 |

**筛选交互、逻辑校验与异常场景**

1. **触发查询时机**：在输入框打字过程中不实时改动表格结果；只有点击`查询`按钮或在输入框内按回车键后，才同时应用`客服姓名`与`联系电话`两个非空条件（“且”关系）过滤列表并重置回第 1 页。
2. **点击重置**：点击`重置`按钮清空`客服姓名`与`联系电话`输入框，立即恢复展示本代理商全部可见客服并回到第 1 页（每页条数保持当前设置不变，不影响默认客服开关）。
3. **查询异常与撤权保护**：查询失败或超时时保留当前已输入的筛选条件与页码，提示手动重试，不用旧结果冒充新查询结果；若查询时发现账号读取权限已被收回，则立即清空列表并提示权限已失效。

###### 5.1.3 列表字段与行内操作

**表头顺序（共 7 列，左→右固定）**：`客服类型` → `客服姓名` → `联系电话` → `工作时间` → `默认客服` → `已关联学校` → `操作`

| 列顺序与列名 | 数据来源与展示规则 |
| --- | --- |
| 1. 客服类型 | 固定位于第 1 列；展示`代理商客服`或`平台客服` |
| 2. 客服姓名 | 完整展示当前客服姓名；已关联至本代理商的平台客服在姓名右侧附`临时客服`标签；缺失显示`—` |
| 3. 联系电话 | 完整展示纯数字电话号码（保留前导 `0`，不做星号脱敏）；缺失显示`—` |
| 4. 工作时间 | 组合展示每周工作星期与起止时分（如`每周一至周五 09:00—18:00`），内容较长时自动换行；缺失显示`—` |
| 5. 默认客服 | 本代理商唯一默认客服的行内开关；当前默认客服呈**开启且置灰禁用态**，其余所有可见客服（含自建客服与平台临时客服）呈**关闭可点击态** |
| 6. 已关联学校 | 最多平铺展示该客服在本代理商范围内已关联的前 2 所学校名称，超过 2 所时附 `+N所` 标记，并在下方展示 `共 M 所`；未关联任何本代理商学校时显示`未关联学校`（**平台临时客服严格只统计和展示其在本代理商名下关联的学校，绝不泄露其在平台直营或其他代理商下关联的学校**） |
| 7. 操作 | **代理商客服**：按固定顺序展示 `查看`、`编辑`、`删除`、`关联学校`（其中当前默认客服的`删除`按钮置灰禁用，悬停提示`默认客服不可删除，请先更换其他客服为默认客服`）；**平台客服（临时客服）**：**仅 `关联学校` 可点击操作**，`查看`、`编辑`、`删除` 均置灰禁用（悬停提示`平台客服仅支持关联学校，不可查看、编辑或删除`） |

**表格排版规范**：表头与数据单元格统一水平、垂直居中；`操作`列固定单行完整展示 4 个按钮不折行，行内默认开关居中对齐。

**列表行内操作、逻辑校验与异常场景**

1. **行内默认客服开关切换规则（CS-07）**：
   - **互斥唯一与禁止置空**：本代理商服务范围同一时刻至多 1 名默认客服。已开启的默认客服开关置灰不可点击关闭，防止将默认客服置空。
   - **一键切换生效**：点击任一非默认有效客服（自建客服或平台临时客服）行的关闭态开关，无需二次确认弹窗，立即提交切换：自动取消原默认客服、将当前点击客服设为本代理商默认客服，保存成功后弹出轻提示**“默认客服已更新”**并刷新列表，运营后台同步显示同一新默认客服。
   - **平台临时客服设为默认的权限边界**：平台临时客服被设为本代理商默认客服后，其平台客服身份不变，在本端仍仅可`查看`，不会因此获得编辑、删除或关联学校权限；在其担任本代理商默认期间，运营后台若尝试解除该平台客服与本代理商的关联，系统会拦截解绑并要求先更换本代理商默认客服。
   - **切换异常拦截**：切换请求处理中锁定整列默认开关防止连续点击多行；若提交瞬间目标自建客服已被运营端删除、目标平台临时客服刚被运营解除关联、当前账号无默认设置权限或另一端刚抢先更新了默认客服，则保持原默认状态不变并提示具体原因（并发冲突提示`默认客服已更新，请重新打开后操作`）。
2. **平台临时客服点击`查看`规则**：点击平台临时客服行的`查看`按钮正常打开《查看客服》只读详情弹窗（5.8），严禁误拦截报错；若用户通过异常手段尝试对平台临时客服触发编辑、删除或关联学校，一律拦截并提示`关联的平台客服仅可查看，资料维护请在运营后台进行`（关联学校提示`关联的平台客服仅可查看，不能在代理商端关联学校`）。
3. **分页交互与边界**：底部分页栏显示`共 X 条`、每页条数选择框（`10 / 20 / 50`，默认 `10`）、`上一页`、`当前页 / 总页数`、`下一页`。第 1 页禁用`上一页`，末页禁用`下一页`；切换每页条数回到第 1 页；在第 2 页及以上删除最后一条记录导致当前页为空时，自动回退至上一有效末页。

##### 5.2 新增客服弹窗（CS-02）

点击列表左上方`新增客服`按钮打开，弹窗标题为`新增客服`，底部右侧按标准顺序排列`取消`（次按钮）、`确定`（绿色主按钮）。新建记录固定为归属当前代理商的自建客服，不在新建弹窗内直接勾选学校（保存成功后在列表点击`关联学校`配置）。

###### 5.2.1 字段定义

| 字段名称 | 必填 | 新增初始默认值 | 控件形态与格式约束 |
| --- | --- | --- | --- |
| 客服类型 | 系统锁定 | 固定为`代理商客服` | **页面隐藏不展示**；提交时系统固定按本代理商自建客服写入，禁止篡改 |
| 所属代理商 | 系统锁定 | 固定为当前登录代理商 | **页面隐藏不展示**；禁止跨代理商挂靠 |
| 客服姓名 | 是 | 默认空；占位`请输入客服姓名` | 单行文本输入框（带红色必填星号），最大输入长度 50 字；去除首尾空格后须为 1—50 字 |
| 联系电话 | 是 | 默认空；占位`请输入联系电话` | 单个单行文本输入框（带红色必填星号）；输入及粘贴时自动过滤非数字字符，仅保留纯数字（保留前导 `0`，不限制位数上限，不拆分固话区号框） |
| 每周工作日期 | 是 | 默认全选`周一`至`周日`（共 7 天） | 前缀`每周`＋`周一`至`周日` 7 个复选框（带红色必填星号），至少勾选 1 天、最多 7 天 |
| 开始时间 | 是 | 默认 `08:30` | 只读时间框，点击展开《工作时间选择层》（5.4），24 小时制 `00:00`—`23:59` |
| 结束时间 | 是 | 默认 `17:30` | 只读时间框（中间`至`连接，右侧附`24小时制`说明），点击展开《工作时间选择层》（5.4），`00:00`—`23:59`，**必须严格晚于开始时间** |

###### 5.2.2 字段校验、自动默认逻辑与异常场景

1. **客服姓名校验**：未填写或仅输入空格、或超过 50 字时，点击`确定`在弹窗顶部错误区提示**“请填写1至50字的客服姓名”**，阻止保存并保留其他已填内容；允许与已有客服同名，同名记录各自独立。
2. **联系电话校验（纯数字＋本代理商内唯一）**：
   - 未填写时点击`确定`，弹窗顶部提示**“请输入联系电话”**；
   - 含有任何非数字字符时，提示**“联系电话仅支持数字”**；
   - **唯一性校验范围**：在本代理商当前未删除的自建客服范围内，联系电话不得重复（与其他代理商的客服、或与平台客服号码相同不视为冲突；**本代理商已删除客服的原号码立即释放，允许新建客服重新使用**，重新使用该号码新建的客服作为全新独立记录，绝不恢复旧记录，也不继承旧记录的学校关系或历史日志）；
   - 若命中本代理商有效客服重号（含多人同时提交同一号码的后到达方），弹窗顶部明确点名提示**“该联系电话已被客服‘【已占用客服姓名】’使用，请勿重复添加”**。
3. **工作星期与起止时间校验**：7 个星期全部取消勾选后点击`确定`，提示**“每组工作时间请至少选择一个有效星期”**；结束时间早于或等于开始时间（如 `17:30` 至 `08:30` 或 `09:00` 至 `09:00`）时，提示**“结束时间须晚于开始时间”**，不自动替换为默认时间，保留用户当前选择供修正。
4. **首次新增自建客服自动设为默认 vs 后续新增规则**：
   - **本代理商首名自建客服**：若保存前本代理商名下尚无自建客服记录，保存成功创建该客服的同时，系统自动将其设为本代理商唯一默认客服（若此前本代理商已将某平台临时客服设为默认，则自动取消原平台临时客服默认并切换为该新自建客服），同步写入创建日志与默认客服变更日志，关闭弹窗、刷新列表并弹出轻提示**“客服信息已保存，已自动设为默认客服”**；
   - **第 2 名及后续自建客服**：保存成功后不改动当前已有的默认客服设置，新客服行内默认开关呈关闭态，仅写入创建日志，关闭弹窗、刷新列表并弹出轻提示**“客服信息已保存”**。
5. **取消、未保存关闭与提交异常**：
   - 点击弹窗底部**`取消`按钮**：无论是否输入过内容，直接清空本次未提交输入并关闭弹窗，**不弹二次确认框**；
   - 点击弹窗右上角**`×`**、按键盘 `Esc`、切换左侧菜单或关闭顶部页签：若表单相比初始状态有实质修改，弹出 5.9《放弃未保存内容？》确认弹窗；若无任何修改则直接关闭；
   - 提交失败、网络超时或中途收回新增权限时，保持弹窗打开并完整保留已填内容，分别提示重试、先核对列表防重复提交或无操作权限。

##### 5.3 客服信息弹窗（编辑，CS-03）

仅本代理商自建客服行操作列提供`编辑`按钮，点击打开，弹窗标题为`客服信息`，底部按钮为`取消`、`确定`。打开时实时读取该客服最新资料与版本号；若客服已被删除或不属于本代理商，拦截提示`客服不存在或无权访问`。

###### 5.3.1 字段回显与编辑规则

| 字段名称 | 必填 | 编辑回显值 | 编辑约束 |
| --- | --- | --- | --- |
| 客服类型 / 所属代理商 | 系统锁定 | 代理商客服 / 当前代理商 | **页面隐藏不展示**；严禁修改既有客服类型或所属代理商（异常篡改提示`已建客服类型及归属不可修改`） |
| 客服姓名 | 是 | 当前已保存姓名 | 单行文本输入，去除首尾空格后 1—50 字 |
| 联系电话 | 是 | 当前已保存纯数字号码 | 单个纯数字输入框，保留前导 `0`；未改动本人原号码时不触发与自身的重号报错，改为本代理商其他有效自建客服号码时拦截重号 |
| 每周工作日期 | 是 | 当前已保存工作星期勾选态 | `周一`至`周日`复选框，1—7 天 |
| 开始时间 / 结束时间 | 是 | 当前已保存开始与结束时间 | 点击展开《工作时间选择层》（5.4）点选，`00:00`—`23:59`，结束时间必须严格晚于开始时间 |

###### 5.3.2 保存判定、并发冲突与异常场景

1. **区分有无实质修改**：
   - **有实质字段修改**：全部字段与权限校验通过后更新该客服档案（原有内部标识、创建时间、当前默认客服状态及已关联学校关系全部保留不变），仅针对实际发生变化的字段生成前后值对比操作日志，关闭弹窗、刷新列表并轻提示**“客服信息已保存”**；
   - **无任何字段变化**（含修改后又改回原值）：点击`确定`直接关闭弹窗并轻提示`客服信息已保存`，**不增加版本号，也不产生无实质变化的空编辑日志**。
2. **双端并发更新与删除冲突拦截**：
   - 若打开编辑弹窗后，运营后台或本端另一成员已先行修改了该客服资料、学校关系或默认状态（版本号已变化），点击`确定`时在弹窗顶部拦截提示**“客服信息已更新，请重新打开后操作”**，保留当前输入框内的文字供用户核对，绝不静默覆盖最新数据；
   - 若打开编辑弹窗后该客服已被他人删除，点击`确定`提示**“客服不存在或无权访问”**，关闭后刷新列表。
3. **取消、右上角关闭与提交异常**：与 5.2 新增客服弹窗完全一致。

##### 5.4 工作时间选择层（CS-04）

点击新增（5.2）或编辑（5.3）弹窗中的`开始时间`或`结束时间`输入框时，在对应输入框旁展开内嵌浮层，标题为`选择时间`。同一时刻最多打开一个时间选择浮层，精准对应触发它的输入框。

| 浮层区域 / 按钮 | 选项范围与默认状态 |
| --- | --- |
| 小时列（时） | `00`—`23` 共 24 个两位数选项；打开时自动定位并高亮当前输入框的小时值 |
| 分钟列（分） | `00`—`59` 共 60 个两位数选项（支持任意分钟点选）；打开时自动定位并高亮当前输入框的分钟值 |
| 底部按钮 | 左侧`取消`（次按钮）、右侧`确定`（主按钮） |

**交互、校验与异常场景**

1. **回填与表单保存分离**：在小时或分钟列滚动点击时仅切换浮层内高亮项；点击浮层**`确定`**才将选中的 `HH:mm`（如 `00:00`、`08:30`、`23:59`）回填至原时间框、关闭浮层并将焦点交还该时间框。浮层确定不直接提交整个客服表单，开始与结束时间的先后关系在点击父表单`确定`时统一校验。
2. **取消与多层 `Esc` 隔离**：点击浮层`取消`、点击浮层外部区域或按键盘 `Esc`，仅关闭时间选择浮层并丢弃未确认的临时时分，原时间框值保持不变；**当时间选择层处于展开状态时，按 `Esc` 只关闭时间选择层，绝不同时关闭底层新增/编辑弹窗或误弹出放弃确认框**。
3. **屏幕边缘自适应与键盘操作**：支持键盘方向键切换选项，靠近窗口边缘时自动调整浮层位置确保完整可见、按钮不被遮挡。

3. **取消与点击`确定`差集判断**：

   - **默认客服解除专属学校无前置拦截**：即使当前自建客服正担任本代理商默认客服，也可正常取消勾选其名下绑定的学校并经二次确认解绑（解绑后若该校无其他专属客服，仍按本代理商默认客服兜底）。

**操作、复验与异常场景**

1. **点击`取消`、右上角`×`或按 `Esc`**：仅关闭本二次确认框，返回底层 5.5 关联学校弹窗并保留此前已勾选的学校选择与筛选状态，用户可继续调整勾选，不写入任何变更。

##### 5.7 删除客服确认弹窗（CS-08）

仅本代理商非默认自建客服的`删除`按钮可点击（平台临时客服的`删除`按钮置灰禁用，悬停提示`平台客服仅支持关联学校，不可查看、编辑或删除`；当前担任本代理商默认客服的自建客服行内`删除`按钮置灰禁用，悬停提示`默认客服不可删除，请先更换其他客服为默认客服`）。点击可删除自建客服的`删除`打开紧凑型警告确认弹窗（宽度 `432px`），标题为`删除客服`，正文居中展示黄色感叹号警示图标、主文案**`确认删除客服“【客服姓名】”？`**及辅助说明**`删除后将解除该客服与学校的关联。`**，底部右对齐仅提供`取消`、`确认`两个按钮。

**双重禁删保护与异常场景**

1. **提交瞬间默认客服二次拦截**：若打开删除确认弹窗时该客服并非默认客服，但在点击`确定`前刚刚被运营后台或本端另一窗口切换设为本代理商默认客服——点击`确定`时立即阻止删除并在弹窗内报错**“默认客服不可删除，请先更换其他客服为默认客服”**，绝不允许通过删除把本代理商默认客服删空。
2. **正常确认删除后的数据联动**：
   - 校验通过后将该客服标记为已删除（前台不提供恢复），在同一批次操作中自动解除其名下关联的全部学校关系，立即释放其占用的联系电话供后续新建自建客服复用，生成包含客服姓名及同时解除学校完整名称的删除日志（如`删除客服“陈思远”，同时解除学校：育才中学、鹭江第二实验小学。`），关闭弹窗、刷新列表并轻提示**“客服已删除”**；
   - **本端操作日志同步隐藏**：客服删除成功后，本端`系统管理 → 操作日志`在下一次查询或刷新时不再展示该已删除客服的历史日志（历史审计记录仅保留在运营后台供授权运营核查）。
3. **并发冲突与重复删除拦截**：确认期间该客服资料已被他人修改提示`客服信息已更新，请重新打开后操作`；已被他人先行删除提示`客服不存在或无权访问`并刷新列表，不重复写入第二条删除日志；点击`取消`直接关闭弹窗，原客服资料与学校关系毫发无损。

##### 5.10 客服操作日志（接入现有菜单：系统管理 → 操作日志，CS-11）

###### 5.10.1 对现有“系统管理 → 操作日志”菜单的增量修改要求

   - `全部操作类型`下拉框新增客服管理相关枚举：**`新增客服`、`编辑客服`、`删除客服`、`关联学校`、`设置默认客服`、`取消默认客服`**；
   - 关键词输入框支持按**客服姓名（操作对象）**或**操作详情关键词**检索；无匹配或无数据时保持原框架与 6 列表头，第一行居中展示`暂无对应数据`且不显示分页栏。
2. **6 列固定字段映射规范（与现有操作日志页完全一致）**：

| 列名 | 客服管理日志取值规则 |
| --- | --- |
| 1. 操作时间 | 操作成功的北京时间（`YYYY-MM-DD HH:mm:ss`），默认按操作时间从新到旧倒序排列 |
| 2. 操作人 | 展示`操作人姓名(手机号)`快照（如`林晓雨(13800138101)`）；运营后台代维护产生的日志如实展示该运营人员姓名快照 |
| 3. 操作类型 | 标签样式展示本次动作：`新增客服` / `编辑客服` / `删除客服` / `关联学校` / `设置默认客服` / `取消默认客服` |
| 4. 操作对象 | **不展示系统编号**（单号/编号仅适用于订单类日志）；客服管理日志固定展示**`客服姓名`**（当时快照，如`林晓雨`；平台临时客服标为`李强（平台客服）`） |
| 5. 操作详情 | 清晰记录本次业务变更内容（见下方标准文案） |
| 6. 来源 IP | 记录本次操作的客户端来源 IP（如`127.0.0.1`） |

3. **各操作类型标准`操作详情`文案**：
   - **`新增客服`**：`客服（林晓雨）创建成功`；若为本代理商首名自建客服触发自动设为默认，同批额外记录一条`设置默认客服`日志：`将【本代理商名称】默认客服由“未设置”（或原平台临时客服名）改为“林晓雨”；仅服务未绑定专属客服的学校。`；
   - **`编辑客服`**（仅列实际变化字段前后值）：`客服姓名由“林晓雨”改为“林晓雨（客服组）”；联系电话由“13800138101”改为“05925550001”；工作时间由“每周一至周五 09:00—18:00”改为“每周一至周六 08:30—17:30”。`；
   - **`关联学校`**：`新增关联学校：示范小学、阳光实验学校；解除关联学校：育才中学。`（含平台临时客服在本代理商范围内调整关联学校）；
   - **`删除客服`**：`删除客服“陈思远”，同时解除学校：育才中学、鹭江第二实验小学。`；
   - **`设置默认客服` / `取消默认客服`**：写明代理商名称及变更前后客服姓名（如`将【本代理商名称】默认客服由“林晓雨”改为“陈思远”；仅服务未绑定专属客服的学校。`）；
   - **学校负责机构转归自动解绑**：`学校“示范小学”负责机构由“【本代理商】”变为“【新机构】”，自动解除客服“林晓雨”与该学校的专属关联；后续按新负责机构的默认客服或联系人展示。`。

###### 5.10.2 代理商端日志数据隔离边界

1. **严格可见范围**：代理商端仅可查看本代理商**当前未删除自建客服**的操作日志（含运营人员在运营后台代本代理商维护产生的日志，其操作人如实显示该运营人员姓名快照、发起端显示`运营后台端`），以及**明确归属本代理商的默认客服设置/取消日志**（含将平台临时客服设为本代理商默认的日志）。
2. **严禁越权暴露**：一旦某名自建客服被删除，本端操作日志列表立即屏蔽该已删除客服的全部历史记录；其他代理商的日志、平台客服在平台或其他代理商下的操作日志一律不可见。

#### 6. 跨端协同与界面交互规范

1. **三端协同与小程序取号优先级**：
   - 代理商端与运营后台读写同一份本代理商自建客服档案与本代理商默认客服设置，任一端修改保存后另一端刷新立即同步；
   - 家长/教师小程序点击联系客服时，按目标学校实时计算：①若学校绑有 1 名或多名有效专属客服，展示全部专属客服（本代理商自建客服排在平台客服之前）；②若学校未绑定任何专属客服，回退展示本代理商当前唯一默认客服；③若学校无专属客服且本代理商也无有效默认客服，小程序客服电话入口点击不打开弹窗。
2. **统一弹窗与布局规范**：
   - 所有弹窗（新增、编辑、查看、关联学校、二次确认、删除确认、放弃确认）**顶部标题行与底部按钮操作行始终固定，仅中间正文内容区域独立纵向滚动**，外层列表页面不随弹窗滚动；
   - 常规成对操作弹窗底部按钮统一规范为左侧次按钮`取消`、右侧主按钮`确定`，只读查看弹窗仅保留`关闭`按钮，不凭空补造多余按钮。

本模块界面在不调整任何业务字段与交互逻辑的前提下，将界面视觉统一对齐至运营后台“客户管理”已上线页面的视觉规范：

| 视觉维度 | 规范要求 |
| :--- | :--- |

| 筛选区样式 | 筛选栏直接融入白色主卡片，底部使用柔和浅分割线与列表区分隔，输入框与下拉框统一标准高度与小圆角，聚焦时呈现品牌绿高亮描边。 |
