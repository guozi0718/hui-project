# 家校通知功能说明

## 适用范围

本文描述运营后台“校务管理 > 家校通知”的页面、字段、操作权限、校验、状态、异常和恢复行为。列表可以查看运营可见范围内的通知；新建、编辑和删除仍受运营账号既有学校管理权限约束。

#### 1. 需求背景与目标

运营人员需在运营后台代学校发布家校通知。通知必须先绑定一所明确学校，再填写正文和发布设置。运营后台可查看所有学校、所有来源发布的通知；发布、编辑和删除仍受当前运营账号原有学校权限限制。

本端目标：

1. 发布过程中清楚显示目标学校，避免将通知发给错误学校。
2. 地区筛选和学校名称筛选均可独立使用，也可组合使用。
3. 流程为选择学校、填写内容、准备发布三步。
4. 新建通知的学校选择、名单与发布对象，以及编辑、删除操作均限运营账号原有管理范围；通知列表、预览和统计可查看所有学校的通知。
5. 主菜单、页签和页面外框由运营后台基线项目管理。

#### 2. 一期范围

| 页面/能力 | 一期范围 |
|---|---|
| 通知列表 | 查看所有学校的通知并预览、统计；按原权限编辑或删除 |
| 选择学校 | 按地区和学校名称查找一所授权学校 |
| 填写内容 | 标题、封面、正文、附件、全文背景、预览 |
| 准备发布 | 发布对象、查收方式、学校名义、定时发送、可选截止 |
| 发布对象 | 按学生、教师选择 |
| 不包含 | Web草稿、撤回、独立链接通知类型、超出演示账号授权范围代发 |

#### 3. 业务名词、数据来源与基础规则

| 名词/事项 | 本端规则 |
|---|---|
| 目标学校 | 当前运营账号有权管理并选中用于本次发布的学校 |
| 通知归属 | 每条通知只属于一所学校；选择学校后才能进入内容填写 |
| 发布对象 | 目标学校学生和教师，不直接选家长 |
| 学校名义 | 新建代发通知时固定开启且不可关闭；运营人员不能以个人名义代学校发送 |
| 编辑 | 只允许编辑正文、封面和学校名义，且须满足共通编辑条件 |
| 删除 | 删除后通知从所有普通用户端消失；没有已删除列表 |

时间、对象动态变化、学生家长状态、统计、提醒、删除留存和PDF遵循本文件“全端共通规则”章节。

#### 6. 功能详细说明

##### 6.1 家校通知列表（OPS-01）

页面固定顺序为筛选、左侧“代发通知”按钮、列表、分页。列表展示所有学校的通知，不限制发布人或通知来源；不展示已删除通知和 Web 草稿。运营账号能查看所有记录的预览和统计；超出原有管理范围的记录仍可见，但编辑、删除按钮置灰并提示“无操作权限”。操作列固定在右侧；数据列可左右滑动。

筛选顺序为目标学校、通知来源、通知标题、通知类型、查收方式、发布状态和发布时间。目标学校按运营后台可见的学校名称模糊匹配；输入时显示包含关键词的候选项，选中后回填完整学校名。通知来源顺序为学校端、教师端、平台端、平台（代理商名称），多个代理商按系统已有配置顺序稳定排列；通知类型仅为普通通知、美文通知。下拉默认“全部”；发布状态选项按端区分：运营后台为全部、待发送、已发送，不提供“已截止”；学校 Web、代理商 Web 为全部、待发送、已发送、已截止；目标学校和通知标题的占位分别为“请输入学校名称”“请输入通知标题”。不提供“发布人”筛选。查询、重置与筛选第一行及外框对齐。

列表显示目标学校、通知来源、通知标题、发布名义、通知类型、查收方式、发布状态、发布时间、未读人数、已读人数、已确认人数、已签字人数、创建时间、操作人和操作。通知来源按实际发布端显示；通知类型为普通通知或美文通知。表头文字居中；通知标题内容靠左，其余字段内容居中；每列只展示一个字段。发布名义列的显示值不变：以学校名义发送时显示学校名称，以个人名义发布时显示教师姓名。操作人列在创建时间之后，显示发布时保存的姓名快照和操作角色：老师显示“姓名（老师）”，学校管理员显示“姓名（学校管理员）”，代理商显示“姓名（平台（代理商名称快照））”，运营后台显示“姓名（平台）”。操作角色和代理商名称均按发布时记录显示，不随之后的账号或代理商名称变化。不显示完成率。操作按钮为预览、编辑、删除、阅读统计，单行展示。

**操作与异常**

1. 查询成功后回第1页，按当前运营可见范围展示；重置清空目标学校、标题和时间，枚举恢复全部。
2. 无匹配通知显示空列表，仍可以重新筛选或代学校发布。
3. 列表读取失败时保留条件并提供再次读取入口；不把失败显示成无通知。
4. 操作目标属于其他学校或运营账号无管理权限时，仍可预览并查看统计；编辑、删除不可操作。目标记录不存在或已删除时，不打开详情并重新读取当前列表。
5. 未读人数、已读人数始终显示数字；已确认人数仅在“需确认收到”时显示数字，其他查收方式显示“--”；已签字人数仅在“需签字确认”时显示数字，其他查收方式显示“--”。
6. 每页默认10条，可选10/20/50条；总数统计所有可见学校中未删除的通知。

##### 6.2 选择学校（OPS-02）

运营代发必须先选择一所目标学校；选定后进入内容填写。新建通知时的候选学校只限当前运营账号可管理的学校；查看通知列表时仍可查看所有学校的通知。

| 字段 | 控件/默认值 | 规则 |
|---|---|---|
| 省 | 下拉，默认全部 | 更换省后市和区回到全部 |
| 市 | 下拉，默认全部 | 未选省时不可选 |
| 区/县 | 下拉，默认全部 | 未选市时不可选 |
| 学校名称 | 文本框，提示“请输入学校名称” | 可单独模糊查询，不强制先选地区 |
| 查询结果 | 学校名称、所在地区 | 只展示可管理学校 |
| 选择学校 | 单选一所 | 不默认选择第一项 |
| 查询 | 按钮 | 地区与学校名称共同筛选；条件为空时显示当前可管理学校 |
| 重置 | 按钮 | 清空学校名称，地区恢复“全部”，重新查找 |
| 下一步 | 按钮 | 选定有效学校后可继续 |

**操作步骤、校验和异常**

1. 地区按省、市、区县逐级筛选；选择省后市、区县清空到全部，选择市后区县清空到全部。
2. 学校名称可以单独查询；地区与名称同时有值时，结果同时满足两类条件。
3. 学校名称模糊匹配；同名学校必须显示所在地区，以便用户选对目标。
4. 进入内容步骤前必须手动选择一所学校；没有选择或选中学校已不在授权范围时不能继续。
5. 候选为空显示“暂无符合条件的学校”；读取失败单独显示重新查询入口。
6. 返回学校选择页时保留原有选择和已填内容。改选学校前提示用户确认；用户取消则保留原选择。确认后的内容保留/清空规则尚待确认，见第9节；无论如何都不得将原发布对象名单直接发到另一所学校。
7. 地区字段改变后，原有学校选择不再有效；必须从当前搜索结果重新选学校。

**学校结果状态**

1. 省、市、区县按顺序选择；改选省时市和区县恢复“全部”，改选市时区县恢复“全部”。未选择上一级地区时，下一级不可选。
2. 只输入学校名称即可查询；学校名称按包含输入文字查找。学校名和地区同时填写时，两类条件都必须符合。
3. 每条结果同时显示学校名称和所在地区。同名学校必须能通过地区区分；用户须明确点击一所学校后才可继续。
4. 没有任何有权管理的学校，显示“暂无可管理学校”；当前筛选无结果，显示“暂无符合条件的学校”。
5. 学校名单读取失败时提示重新查询，不显示为0所学校。用户已选学校在下一步前失去管理权限时，停止流程并要求重新选择。
改选学校后的内容保留与清空规则尚未明确；原对象名单不得直接用于新学校。
##### 6.3 填写通知内容（OPS-03）

字段与校验依本文件“全端共通规则”章节。

| 字段 | 必填 | 要求 |
|---|---|---|
| 通知标题 | 是 | 最多50字；不显示0/50计数 |
| 封面 | 否 | 标签不写“选填”，与标题内容左侧对齐且不换行；封面采用高清素材900×383px；小程序通知详情与模板预览的封面图最大宽320px、高约136px，等比居中、不裁切 |
| 通知内容 | 是 | Web富文本编辑框；普通通知只显示唯一文本块，美文通知可含文本、图片、视频和链接内容块。正文配图上传宽1080px的清晰原图；页面最大宽320px、高180px，等比缩放、不裁切，不设固定大画框或多余留白 |
| 附件 | 否 | PDF、Word、Excel、JPEG、JPG、PNG；最多9份，每份≤20MB |
| 全文背景 | 是 | 简洁白底#FFFFFF、清新绿底#F5FBF6、暖色信纸#FFFCF3 |

1. 运营后台新发布固定为美文通知；正文可包含链接，链接属于正文内容，不是独立通知类型。运营后台可以编辑符合条件的普通通知，普通通知正文只显示唯一文本块并保留原类型；不显示新增内容块入口和文本块的上移、下移、删除按钮。
2. 标题为空或超过50字、正文为空时不能进入准备发布。
3. 文件不符合格式、大小或数量要求时不加入；其他有效附件不受影响。
4. 预览只读展示已填写内容；关闭返回当前步骤并保留内容。
5. “上一步”回学校选择，“下一步”校验内容后进入准备发布。
6. 用户改选学校时，必须确认新学校；再次进入发布设置前重新核对学校、学生和教师范围。

##### 6.4 选择发布对象（OPS-05）

对象只从已选目标学校的当前名单中选择。选择页分“学生”和“教师”。

- 学生：年级和班级默认收起；选择整年级、整班或个人；班内学生按姓名A-Z。
- 教师：按姓名A-Z显示；可以单选或全选。全选后每位教师的勾选状态都显示选中。
- 学生、教师至少选择一人。空对象不能确认。
- 选择整班、部分学生、年级覆盖范围和多班级学生按共通规则处理。
- 点击确定后关闭选择页，发布对象区域显示“已选中学生X人，教师Y人”；不在下方重复展示人数。
- 点击取消不覆盖上次确认的对象。列表读取失败时不能将其当成“没有学生”。
- 学校选择发生改变，原来选中的对象不能直接发到新学校；用户需重新选择。
- 名单内同名学生/教师分别保留；不因姓名相同而合并。

##### 6.5 准备发布（OPS-04）

PC页面字段排版统一为标签在左、控件在右，同一行显示。发布对象、查收方式、学校名义和定时发送各占一行；标签不换行，控件左边缘和高度保持一致。日期时间选择器与下拉框使用同一行高。


| 字段 | 必填 | 默认/交互 |
|---|---|---|
| 发布对象 | 是 | 已选学生和教师人数显示 |
| 查收方式 | 是 | 下拉框；默认只需阅读查看，另两项为需确认收到、需签字确认 |
| 以学校名义通知 | 否 | 默认开启、固定开启且不可关闭；字段旁显示目标学校名称；运营人员代发只能使用学校名义 |
| 定时发送 | 否 | 默认关闭表示即时发送；开启后默认次日09:00:00 |

| 底部操作 | — | 上一步、发布；不提供保存草稿 |

1. 时间格式统一YYYY-MM-DD HH:mm:ss。
2. 定时发送时间必须晚于当前时间。
3. 上一步回到内容编辑时保留标题、封面、正文、附件和全文背景。
4. 发布前核对目标学校、发布对象、查收方式、学校名义、发送方式和通知内容；学校名义开关固定开启，不允许改为个人名义。
5. 发布时按钮暂时不可再次点击，避免用户重复发出同一通知。
6. 发布明确失败时停留本页，保留输入和选择；结果不明确时回到目标学校的通知列表核对标题，未找到后才可手动重试。
7. 发布成功后返回列表，显示目标学校及正确的状态和时间。

##### 6.6 阅读与回执统计（OPS-07）

统计从通知操作列的“阅读统计”进入独立页面。页面不显示通知标题。页面分为“学生统计”和“教师统计”两个页签，默认打开学生统计。Web 学生统计分为班级汇总页 A 和班级学生明细页 B；教师统计保留教师名单视图。三个 Web 端的统计行为一致。

**统计指标**

| 查收方式 | 学生统计指标 | 教师统计指标 |
|---|---|---|
| 只需阅读查看 | 学生总数、已读、未读 | 教师总数、已读、未读 |
| 需确认收到 | 学生总数、已读、未读、已确认、未确认 | 教师总数、已读、未读、已确认、未确认 |
| 需签字确认 | 学生总数、已读、未读、已签字、未签字 | 教师总数、已读、未读、已签字、未签字 |

只需阅读查看时不重复显示第二个“已读”数字。“应收学生”统一显示为“学生总数”。不展示完成率。

**学生统计 A：班级汇总**

筛选区显示筛选标题“年级”“班级”，只提供这两个筛选。候选年级和班级仅来自当前通知的学生接收范围。选择年级后，班级筛选重置为该年级范围内的“全部”；也可以直接选择“全部年级”。筛选后，页面顶部的学生总数、已读/未读和查收结果人数与表格都按相同范围重新计算。

汇总列表按以下顺序展示：

| 字段 | 规则 |
|---|---|
| 年级 | 只显示通知接收范围内有学生的年级，按学校固定年级顺序排列 |
| 班级 | 只显示通知接收范围内有学生的班级；同一年级按班级编号升序排列 |
| 统计进度 | 显示“已完成相关查收动作人数/学生总数”，例如“15/20”；只需阅读时按已读人数计算，需确认时按已确认人数计算，需签字时按已签字人数计算 |
| 明细 | 点击“明细”进入所选班级的学生明细页 B |

统计按学生汇总：同一学生关联多位家长时，只要其中一位家长完成当前通知要求的动作，该学生计为已完成；学生总数只计一次。没有关联家长的学生仍在学生总数和进度分母中，查收结果按未完成处理，并标注“未关联家长”。

**学生统计 B：班级学生明细**

页面标题显示当前查看的班级，便于确认所在班级。表格中不重复增加年级和班级列。表格字段为“学生姓名、阅读情况、查收结果、明细”；学生姓名按A-Z排列。“明细”查看该学生每位关联家长的阅读、确认或签字状态。没有关联家长时显示“未关联家长”，不生成虚假的家长状态记录。

筛选区只显示“状态”和“学生姓名”两个筛选标题，不显示年级、班级筛选。学生姓名支持模糊查询，姓名可单独查询；状态和姓名条件同时存在时按两项条件共同筛选。状态选项按查收方式变化：只需阅读查看显示全部、已读、未读；需确认收到增加已确认、未确认；需签字确认增加已签字、未签字。不能显示当前查收方式不适用的选项。

B页顶部统计数字随当前状态和姓名筛选联动。只需阅读查看显示学生总数、已读、未读；确认或签字方式另显示对应的已完成、未完成人数。筛选没有匹配学生时，各项数字为0，列表显示空状态。清空筛选或修改条件后，可以继续查看该班全部学生。

**教师统计**

教师统计继续按教师逐人展示教师姓名、阅读情况、查收结果和明细，不展示年级或班级字段。教师姓名按A-Z排序。教师状态选项和统计指标按查收方式变化；教师筛选后顶部数字与名单同步更新。教师明细展示该教师的阅读、确认或签字信息。

**分页、状态更新和异常情况**

1. A页班级列表、B页学生列表和教师列表每页显示10条；更改筛选条件后回到第1页。
2. A页切换年级时，班级自动回到该年级的“全部”；回到A页时保留A页原有年级、班级选择。
3. 在A页筛选结果为空时，统计数字全部为0并显示“暂无班级”；在B页或教师页无匹配结果时，统计数字全部为0并显示对应空状态。空结果不伪装成加载失败。
4. 统计数据以当前通知接收范围和最新阅读/回执状态为准。接收状态更新后重新查看或刷新页面，应显示最新状态。
5. 读取失败时明确显示读取失败并允许重新读取；不能把失败当作0人，也不能覆盖已显示的筛选条件。
6. 学生或家长重复查看不会重复增加学生总数；多位家长的个人记录仍可在“明细”中分别查看。
7. 学生统计、教师统计页均不显示“提醒未读”按钮；提醒功能不在该页面提供。


##### 6.7 预览/打印和PDF（OPS-06）

1. 点击通知列表或发布/编辑步骤中的“预览”，打开小程序样式的手机边框；边框内展示模拟状态栏、导航栏和通知内容。
2. 发布或编辑过程预览当前未保存内容，列表预览显示现有内容。预览只读，不显示发布对象、查收统计、名单、个人回执或发布设置。
3. 标题居中显示，较长时完整换行。正文、封面、图片、视频、链接和附件按通知内容展示；内容超出手机屏幕时只滚动手机框内的通知区域，手机框顶部和页面标题保持固定。
4. 关闭手机预览后返回打开前页面；保留列表筛选和页码，或保留发布/编辑时已填写的内容。
5. 列表入口屏幕始终显示手机边框，页面标题和底部操作栏固定；点击“导出 PDF”时只打印 A4 通知正文，不包含手机边框、模拟状态栏、“通知预览”外层标题、“演示说明”和页面按钮。页边距为上37mm、右26mm、下35mm、左28mm。
6. PDF 导出失败时留在手机框预览页，可再次主动导出；手机预览无法打开时保留当前页面和已输入内容，可重新打开。

##### 6.8 编辑、删除和提醒（OPS-08/OPS-09）

**编辑**

- 可编辑学校、教师、代理商或运营后台创建的通知，但仅限运营人员原有可管理学校范围。通知有任一已读、确认或签字记录，或已到截止时间时，编辑按钮置灰。
- 允许编辑时只能改标题、正文及附件、封面等通知内容；目标学校、对象、查收方式、发布时间、定时发送时间和来源不改。学校名义固定开启。
- 编辑前重新显示发布设置供核对；如果通知已被接收人处理或已过期，取消保存。
- 修改不向全部接收人推送通知更新提醒；页面不新增修改日志入口。

**删除**

- 点击删除后明确显示目标学校和通知标题，再由用户确认。
- 取消不改数据；确认后通知从学校、代理商、运营、教师和家长页面立即消失。
- 不显示“已删除”状态，不提供恢复入口，不发送删除消息。
- 管理留存的通知快照、个人回执、操作人和时间按共通规则处理，普通运营页面不展示留存记录。

**提醒**

- 只触发小程序提醒，不展示发送成功/失败状态，也不自动重试。
- 学生汇总未读时提醒该学生所有关联家长；已读但未确认/签字不提醒。
- 教师根据本人是否已读决定是否提醒。通知过期或已删除时不允许提醒。

#### 7. 数据、权限与跨端一致性要求

1. 运营人员只能看到和操作自己有权管理的学校和通知。
2. 每条新通知只绑定一所明确学校；学校名称和所属地区在选择及列表中清楚展示。
3. 运营后台主菜单、页签、外框由运营基线项目控制；通知链接通过基线菜单进入。
4. 与学校 Web、代理商 Web 对相同通知显示一致的来源、通知类型、内容、查收方式、统计和删除结果。学校 Web 可见本校平台端通知，不论个人名义或学校名义；学校端可见性不扩大原有编辑权限。
5. 对象名单、学生家庭关系变化和学生转班按本文件的全端共通规则执行；已发通知不因转班或离校移除接收人。
6. 更换目标学校后，原学校对象选择不得自动沿用；用户需重新确认目标学校和对象。
7. 权限发生变化时，不显示范围外通知和学校，不以旧列表内容继续提交操作。

## 当前适用的列表、编辑、统计和预览规则

### 通知列表与权限

- 来源筛选顺序为“全部、学校端、教师端、家长端、平台端、平台（代理商名称）”；多个代理商按系统既定稳定顺序排列。筛选列表不提供“发布人”。学校可见范围、发布权限和操作权限分别校验；可见但无写权限的记录仍可查看预览和统计，编辑、删除禁用并说明原因。
- 通知标题在列表单行展示，最多显示10个字，超出省略并可查看完整标题；来源单行完整展示。发布时间、创建时间统一显示到分钟。操作为预览、编辑、删除、阅读统计；操作按钮单行排列。
- 有人阅读、确认或签字后禁止编辑。普通通知编辑只保留唯一文本块，可改文字和格式；不提供新增内容块、上下移或删除块操作，保存后仍为普通通知。Web编辑器不提供录音入口。
- 删除必须二次确认。已删除通知从普通查看范围消失，不提供已删除列表。没有操作权限时仍可见记录，但不能借助直达链接执行写操作。

### 编辑离开保护

存在未保存变更时，返回、切页或关闭页面先显示“放弃编辑”确认，正文为“确认放弃当前输入吗？确认后将丢失本次填写内容”，按钮为“取消”“确定”。取消留在编辑页且保留草稿；确定离开并丢弃本次未保存内容。保存处理中不得重复提交。

### 学生与教师统计

- 阅读与回执页分学生统计、教师统计；学生统计先显示班级汇总A页，点击明细进入班级学生B页。A页只筛年级和班级，候选值限通知实际接收范围；B页只筛状态和学生姓名，姓名模糊匹配。A、B与教师列表每页10条。
- 学生汇总按学生去重；同一学生关联多位家长，任一关联家长完成当前通知要求即计学生完成。未关联家长的学生保留在总数分母并标记未关联家长。班级进度显示完成学生数/学生总数，不显示完成率。
- 只需阅读时展示总数、已读、未读；需确认或签字时再展示对应已完成、未完成数。状态筛选项随查收方式变化，不能显示不适用状态。筛选后统计数字与表格使用相同条件。
- 学生和教师统计都不提供“提醒未读”按钮。空结果显示0和空态；读取失败显示失败及重试，不能伪装成0人。条件变化回到第1页；切换A页年级后班级回到该年级的全部。

### 预览、打印与导出

- 列表预览以及新建/编辑步骤的预览均显示小程序样式手机框，页面标题固定为“通知预览”。通知正文只在手机内容区滚动；顶部标题和底部操作栏固定。预览只读，不展示接收名单、回执统计或发布设置。
- 导出 PDF 只输出通知正文的 A4 版式，不把手机框、后台操作栏、回执统计或接收名单写入 PDF。打印/导出失败时留在当前页面并允许再次手动执行；预览打不开时保留筛选、页码或表单内容。
- 关闭预览回到打开前的列表或编辑步骤，保留原筛选、页码及未提交表单。

## 共通规则正文

#### 1. 需求背景与目标

学校需要一个统一的家校通知功能，向学生、家长及教师发布学校通知，并根据通知要求查看阅读、确认和签字情况。学校人员可以在学校 Web 或教师小程序发布；代理商和运营后台可以在各自授权范围内代学校发布。

一期目标：

1. 通知内容可由 Web 和教师小程序编辑，支持纯文本、图文、视频和链接；通知类型只有“普通通知”“美文通知”两种，通知类型与正文素材形式分别管理。
2. 发布对象由教师和学生组成，不直接选择家长；通知发给学生后，该学生当前关联的所有家长均可收到。
3. 发布人可选择只需阅读、需确认收到、需签字确认三种查收方式。
4. 学生名单按发布时选择的年级、班级或个人范围处理；整班对象在有效期内随班级新增学生，部分学生对象不扩大。
5. 学生任一位家长完成当前通知要求，学生汇总即显示完成；管理端仍可查看每位家长各自的处理状态。
6. 统一记录通知发布、查看、修改、删除和统计在各端的呈现规则，减少学校、教师和家长看到的信息差异。

#### 2. 一期范围

| 端 | 一期页面与范围 | 一期明确不做 |
|---|---|---|
| 学校 Web | 通知列表、两步发布、选择发布对象、预览/打印、统计、编辑、删除 | 选学校步骤、Web 草稿、撤回、独立链接通知类型 |
| 代理商 Web | 本代理商成员代发通知列表、三步发布、选择发布对象、预览和编辑 | Web 草稿、撤回、独立链接通知类型；当前隐藏阅读统计和删除入口 |
| 运营后台 | 所有学校通知列表；授权学校内三步发布、选择发布对象、编辑和删除；所有可见通知均可预览和查看统计 | Web 草稿、撤回、独立链接通知类型 |
| 教师小程序 | 学校通知、我发布、我接收、草稿箱；普通通知、美文通知、模板、阅读统计 | 背景音乐功能、独立链接通知模块 |
| 家长小程序 | 当前登录学生的通知列表、全部/待办、通知详情、阅读/确认/签字 | 切换孩子模块 |

学校 Web、代理商 Web、运营后台和教师小程序按本说明共享通知对象与查收状态规则；各角色只读取授权范围内的数据。家长小程序只接收当前登录学生的通知。

适用规则：教师小程序可以发布普通通知和美文通知；Web新发布的通知固定为美文通知。Web可以在原有学校或授权范围内编辑各端创建的通知，但通知尚未被任何接收人阅读、确认或签字且未到截止时间时才可编辑；符合条件的普通通知按单一文本内容块打开编辑。家长端只有接收能力，没有发布能力，也不作为通知来源。代理商和运营后台代发时，“以学校名义通知”固定开启且不可关闭。代理商和运营后台当前没有草稿功能。

#### 3. 业务名词、数据来源与基础规则

##### 3.1 业务对象

| 名称 | 含义与规则 |
|---|---|
| 通知 | 归属一所学校，包含标题、封面、正文、附件、发布对象、查收方式、学校名义、发送时间和可选截止时间。 |
| 发布人 | 创建通知的学校人员、教师、代理商用户或运营人员。代发通知必须能识别目标学校。 |
| 通知来源 | 依实际创建端显示为“教师端”“学校端”“平台（代理商名称）”“平台端”。家长端只能接收，不能发布，因此不作为通知来源。 |
| 通知类型 | 仅有“普通通知”“美文通知”两种业务分类。教师小程序可发布两类；Web新发布固定为美文通知。 |
| 内容形式 | 正文实际包含的素材形式，可为纯文本、图文、视频、链接、音频或混合内容；内容形式不替代通知类型。 |
| 发布对象 | 发布时选择的教师和学生。发布人不直接选家长；一个学生的所有关联家长均可接收。 |
| 整班对象 | 选择班级全部学生后，按班级作为范围。有效期内该班新增的学生自动纳入；班级转入、离校的原接收学生仍保留原通知。 |
| 部分学生对象 | 只选择班级内部分学生后，范围固定为所选学生；后续加入该班的新学生不自动纳入。 |
| 整年级选择 | 选择时覆盖该年级当时已有的班级；每个已选班级内新增学生按整班对象规则处理。该年级之后新建班级是否加入原通知，尚待确认，见“未明确的业务边界”。 |
| 多班级学生 | 如实际名单显示同一学生同时属于两个已选班级，该学生按两个班级分别收到通知，两个班级副本分别统计。 |
| 学生汇总状态 | 学生的阅读、确认或签字结果按学生汇总；满足任一位家长完成条件即显示学生完成。 |
| 家长个人状态 | 学生关联的每位家长分别保留阅读、确认和签字状态；学生已完成不代表所有家长都已完成。 |
| 教师个人状态 | 教师以本人为单位记录阅读和查收状态，不与学生统计合并成一个个人记录。 |
| 有效期 | 明确截止时间优先使用该时间；未设截止时间时按发送时间起30个自然日。有效期内允许符合范围的新学生和新关联家长接收。 |

##### 3.2 角色、归属和权限范围

| 角色 | 可见内容 | 主要操作 |
|---|---|---|
| 学校 Web 用户 | 当前学校全部通知，包括教师、代理商和平台端为本校发布的通知，不区分学校名义或个人名义 | 按原学校端权限新增、查看、编辑、删除、打印和统计；新增来源可见性不扩大既有编辑权限 |
| 代理商用户 | 本代理商授权学校通知 | 先选择有权代发的学校，再发布、查看、预览和编辑；当前不开放删除与阅读统计 |

学校端仅显示当前学校的通知。通知来源按“教师端、学校端、平台（代理商名称）、平台端”统一显示；同一学校名下的代理商或运营后台代发通知均可见，发布身份不改变通知来源。编辑权限仍按原学校端权限范围执行，不因来源可见而自动扩权。

#### 6. 功能详细说明

##### 6.1 Web 通知列表与筛选

页面固定顺序为：筛选区域、筛选下方靠左的“发布通知/代发通知”按钮、列表、分页。查询和重置与筛选区域第一行对齐，并与筛选容器边界对齐。三个 Web 端均不显示“发布人”筛选。运营后台和代理商端筛选首项为“目标学校”，使用学校名称模糊搜索与候选回显；学校端不显示目标学校筛选。

**各端列表范围**

- 学校 Web 仅显示当前学校的通知，来源包括教师端、学校 Web、代理商和平台端代发给该校的通知。
- 代理商 Web 仅显示当前代理商的通知；同一代理商的成员共享该代理商全部成员代发的通知。代理商列表不显示“通知来源”筛选项或列表列，显示目标学校，并在创建时间后显示“操作人”；操作人显示发布时记录的姓名快照。学校 Web 和运营后台 Web 也在创建时间后显示操作人，呈现方式按表格规则区分。
- 运营后台显示所有学校的通知，不限发布人和发布来源；列表显示目标学校和通知来源。能查看记录不代表获得管理权限，编辑、删除仍受运营账号原有学校权限限制。

| 通知来源 | 下拉框 | 全部 | 学校 Web、运营后台显示全部及当前可见来源；代理商 Web 不显示此筛选项 |
| 通知标题 | 文本框 | 请输入通知标题 | 按标题关键词查找 |
| 通知类型 | 下拉框 | 全部 | 全部、普通通知、美文通知 |
| 查收方式 | 下拉框 | 全部 | 全部、只需阅读查看、需确认收到、需签字确认 |
| 发布状态 | 下拉框 | 全部 | 运营后台：全部、待发送、已发送；学校 Web、代理商 Web：全部、待发送、已发送、已截止 |

**筛选与按钮规则**

1. 下拉字段初始为“全部”，不是“请选择”。改变任一条件后点击“查询”才应用筛选。
2. 查询结果按当前条件显示，页码回到第1页。无匹配数据时显示空状态，不显示被删除通知。
3. “重置”恢复下拉为“全部”、清空目标学校、标题和发布时间范围，并回到第1页。
4. 发布时间结束早于开始时，不执行查询；保留输入并提示用户先调整时间范围。
5. 查询失败时保留已填条件和最近一次有效结果，并提供再次查询入口；不能把读取失败当成0条。
6. “发布通知”按钮不带加号；学校 Web 按钮名为“发布通知”，代理商和运营后台按钮名统一为“代发通知”。

##### 6.2 通知内容、标题、全文背景与附件

适用页面为三个 Web 发布流程的“填写通知内容”页。Web新发布的通知类型固定为“美文通知”；正文可包含链接，链接是内容形式之一，不是独立通知类型。Web可以编辑符合全端编辑条件的普通通知；普通通知以一个文本内容块呈现和修改，保留通知原类型。编辑普通通知时只显示唯一文本块，不显示新增内容块入口；该文本块不提供上移、下移和删除操作。

| 字段 | 必填 | 初始值/占位 | 内容和规则 |
|---|---|---|---|
| 通知标题 | 是 | 请输入通知标题 | 最多50个字；页面不显示0/50计数 |
| 封面 | 否 | 未设置封面 | 标签不出现“选填”；与标题输入内容左边缘对齐，不折行；封面采用高清素材900×383px；小程序通知详情与模板预览的封面图最大宽320px、高约136px，等比居中、不裁切 |
| 通知内容 | 是 | 在这里输入通知正文 | 保留富文本格式工具栏。普通通知仅显示一个文本块；美文通知可添加文本、图片、视频和链接内容块。正文配图上传宽1080px的清晰原图；页面最大宽320px、高180px，等比缩放、不裁切，不设固定大画框或多余留白 |
| 附件 | 否 | 未选择文件 | 支持PDF、Word、Excel、JPEG、JPG、PNG；最多9份，每份不超过20MB |
| 全文背景 | 是 | 简洁白底 | 简洁白底 #FFFFFF；清新绿底 #F5FBF6；暖色信纸 #FFFCF3 |

**输入与验证**

1. 标题必填，去掉首尾空格后仍须有文字；超过50字时不能进入下一步或发布。输入过程中不显示字数计数。
2. 正文必填。只有空白或空内容块时不能进入下一步。普通通知只保留唯一文本块；美文通知可按需要添加图片、视频或链接内容块，不要求用户必须选择某一种组合。
3. 封面可不选；选择图片后显示封面预览。用户取消文件选择时保持原封面；移除封面只清除封面，不清空标题和正文。
4. 附件最多9份。每份最大20MB。每个文件须为PDF、Word、Excel、JPEG、JPG或PNG。第10份、超大小或格式不支持的文件不加入附件列表；已选的有效文件保持不变。
5. 用户关闭文件选择窗口时不改变文件列表。删除一份附件只影响该附件，不清除其他已选文件。
6. 预览只展示当前已填写的内容和附件，不发布通知；关闭预览后回到原内容页，已填写内容保持。
7. 全文背景只控制通知阅读正文区域，不改变输入框、管理后台列表和页面框架样式。

##### 6.3 发布对象选择

发布对象必须包含至少一位教师或至少一名学生。发布人分“学生”和“教师”两个页签，不直接选择家长。

**学生选择**

1. 年级和班级默认收起；打开后按年级、班级、学生逐级展示。
2. 学生在同一班级内按姓名A-Z排列。选择年级、班级或单个学生均可；支持全选和部分选择。
3. 选择一个班级的全部学生时，视为整班对象。手动取消其中个别学生后，班级转为部分选择，后续新加入该班的学生不加入通知。
4. 选择整个年级时，纳入选择当时该年级已有的各班；各已选班级后续新增学生按整班规则处理。之后新设班级是否加入原通知尚待确认，见“未明确的业务边界”。
5. 点击班级行的复选框选择整班；展开班级用于查看并挑选具体学生。折叠/展开不会改变选择。
6. 学生总人数按所选学生去重后显示。实际同一学生属于多个被选班级时按班级分别生成通知副本；在对应统计和家长端分别呈现。

**教师选择**

1. 教师按姓名A-Z排列；教师同名时仍分别显示，不能合并成一个人。
2. 支持单选、全选。点击“全选教师”后，列表中每位教师的复选框均显示选中；逐一取消时，全选状态同步变化。
3. 点击确定后回到发布设置，按钮中显示“已选中学生X人，教师Y人”；按钮下方不再重复显示人数。
4. 点击取消不覆盖上一次已确定的对象；首次选择时取消则不产生已选对象。
5. 名单读取失败与确实没有学生/教师是两种情况。失败时不显示成“0人”并允许空对象发布。

##### 6.4 发布设置与发送时间

代理商端对象范围的专属规则见代理商 Web 第6.4节。代理商发布设置中的对象选项仅为全体学生、全体教师，可单选或同时选择；学校 Web 和运营后台的发布对象选择仍按各自名单选择规则执行。


| 字段 | 必填 | 默认值/选项 | 验证要求 |
|---|---|---|---|
| 发布对象 | 是 | 未选择 | 确认后显示已选学生、教师人数；不得为空 |
| 查收方式 | 是 | 只需阅读查看 | 下拉选项为只需阅读查看、需确认收到、需签字确认 |
| 以学校名义通知 | Web 否；教师小程序按本端规则 | Web端默认开启。学校端可按权限关闭；开启时显示学校名称，关闭时显示当前登录人的姓名快照。代理商和运营后台固定开启且不可关闭 | 代理商或运营后台代发不得改为个人名义；学校端开关不影响发布对象和查收方式 |
| 定时发送 | 否 | 默认关闭，表示即时发送 | 打开后默认次日09:00:00；格式为YYYY-MM-DD HH:mm:ss |
| 截止时间 | 否 | 学校 Web、代理商 Web：默认空，可选；运营后台：不展示此字段 | 学校 Web、代理商 Web 选择年月日时分秒；格式为YYYY-MM-DD HH:mm:ss |


**PC Web 发布设置排版**

1. 学校 Web、代理商 Web、运营后台的发布设置页采用统一的横向表单：每行左侧显示字段标题，右侧显示对应控件，字段标题与控件在同一行，不上下拆开。
2. 各行字段标题使用统一列宽，控件左边缘对齐；下拉框、发布对象选择框、日期时间选择框使用统一高度。开关与其字段标题同一行垂直居中。
3. 发布设置每个字段独占一行，标签文字保持完整，不因为标签长度而挤压控件或换行。页面可用宽度较窄时允许调整为纵向展示，确保控件可读可操作；PC正常宽度下保持横向同一行。
4. 三端字段顺序和必填标记仍按各端发布流程展示，不因统一排版改变字段含义或校验规则。

**必填与时间校验**

1. 发布对象和查收方式为必填项并显示红色星号。学校名义和定时发送为可选项。学校 Web、代理商 Web可设置截止时间；运营后台不提供截止时间字段。
2. 定时发送关闭时按用户点击发布的时间发送。开启时须选择晚于当前时间的日期时间；默认次日09:00:00。
3. 学校 Web、代理商 Web未设置截止时间时按默认有效期规则执行；如设置截止时间，截止点必须晚于实际发送时间，定时发送时须晚于计划发送时间。运营后台不设置截止时间，按默认有效期规则执行。
4. 即时发送与定时发送都显示完整年月日时分秒。取消日期选择不改变原值。
5. 定时发送时间不合法时不发布；保留其他字段，提示调整时间。学校 Web、代理商 Web设置的截止时间不合法时同样阻止发布；运营后台无此字段校验。

##### 6.5 学生、家长和教师状态

| 查收方式 | 打开通知 | 完成条件 | 学生汇总 |
|---|---|---|---|
| 只需阅读查看 | 打开详情记录已读 | 阅读通知 | 任意一位家长已读即学生已读；教师按本人是否已读 |
| 需确认收到 | 打开后先记录已读 | 点击确认收到 | 任意一位家长确认即学生已完成；教师按本人确认状态 |
| 需签字确认 | 打开后先记录已读 | 提交签字 | 任意一位家长签字即学生已完成；教师按本人签字状态 |

1. 任一家长阅读后，学生汇总为已读；其他家长个人状态仍分别显示。
2. 需要确认或签字时，学生“已读”不等于“已确认/已签字”。没有完成要求时，阅读统计仍按相应查收结果显示。
3. 一个学生有多位家长时，任一位完成查收要求即计为该学生完成；明细仍显示每位家长的阅读、确认、签字状态。
4. 新增关联家长在通知有效期内加入该学生通知；该家长个人状态从未操作开始，但不把已经完成的学生汇总改回未完成。
5. 教师按人统计，不以家庭为单位。教师阅读和确认状态与学生统计分开。
6. 没有家长关联的学生，在统计中标注“未关联家长”；仍计入学生总数，不能伪造家长状态行。
7. 当前规则不展示完成率字段。

##### 6.6 阅读与回执统计页面（Web 三端）

学校 Web 和运营后台从“阅读统计”进入独立页面，不显示通知标题，页面分“学生统计”和“教师统计”页签，默认打开学生统计。学生统计包括班级汇总页 A 和班级学生明细页 B；教师统计保留教师名单视图。代理商端当前隐藏阅读统计入口，不能从代理商端进入统计页面。

**统计指标**

| 查收方式 | 学生统计指标 | 教师统计指标 |
|---|---|---|
| 只需阅读查看 | 学生总数、已读、未读 | 教师总数、已读、未读 |
| 需确认收到 | 学生总数、已读、未读、已确认、未确认 | 教师总数、已读、未读、已确认、未确认 |
| 需签字确认 | 学生总数、已读、未读、已签字、未签字 | 教师总数、已读、未读、已签字、未签字 |

只需阅读查看时不重复显示第二个“已读”数字。“应收学生”统一显示为“学生总数”。不展示完成率。

**学生统计 A：班级汇总**

筛选区显示筛选标题“年级”“班级”，只提供这两个筛选。候选年级和班级仅来自当前通知的学生接收范围。选择年级后，班级筛选重置为该年级范围内的“全部”；也可以直接选择“全部年级”。筛选后，页面顶部的学生总数、已读/未读和查收结果人数与表格都按相同范围重新计算。

汇总列表按以下顺序展示：

| 字段 | 规则 |
|---|---|
| 年级 | 只显示通知接收范围内有学生的年级，按学校固定年级顺序排列 |
| 班级 | 只显示通知接收范围内有学生的班级；同一年级按班级编号升序排列 |
| 统计进度 | 显示“已完成相关查收动作人数/学生总数”，例如“15/20”；只需阅读时按已读人数计算，需确认时按已确认人数计算，需签字时按已签字人数计算 |
| 明细 | 点击“明细”进入所选班级的学生明细页 B |

统计按学生汇总：同一学生关联多位家长时，只要其中一位家长完成当前通知要求的动作，该学生计为已完成；学生总数只计一次。没有关联家长的学生仍在学生总数和进度分母中，查收结果按未完成处理，并标注“未关联家长”。

**学生统计 B：班级学生明细**

页面标题显示当前查看的班级，便于确认所在班级。表格中不重复增加年级和班级列。表格字段为“学生姓名、阅读情况、查收结果、明细”；学生姓名按A-Z排列。“明细”查看该学生每位关联家长的阅读、确认或签字状态。没有关联家长时显示“未关联家长”，不生成虚假的家长状态记录。

筛选区只显示“状态”和“学生姓名”两个筛选标题，不显示年级、班级筛选。学生姓名支持模糊查询，姓名可单独查询；状态和姓名条件同时存在时按两项条件共同筛选。状态选项按查收方式变化：只需阅读查看显示全部、已读、未读；需确认收到增加已确认、未确认；需签字确认增加已签字、未签字。不能显示当前查收方式不适用的选项。

B页顶部统计数字随当前状态和姓名筛选联动。只需阅读查看显示学生总数、已读、未读；确认或签字方式另显示对应的已完成、未完成人数。筛选没有匹配学生时，各项数字为0，列表显示空状态。清空筛选或修改条件后，可以继续查看该班全部学生。

**教师统计**

教师统计继续按教师逐人展示教师姓名、阅读情况、查收结果和明细，不展示年级或班级字段。教师姓名按A-Z排序。教师状态选项和统计指标按查收方式变化；教师筛选后顶部数字与名单同步更新。教师明细展示该教师的阅读、确认或签字信息。

**分页、状态更新和异常情况**

1. A页班级列表、B页学生列表和教师列表每页显示10条；更改筛选条件后回到第1页。
2. A页切换年级时，班级自动回到该年级的“全部”；回到A页时保留A页原有年级、班级选择。
3. 在A页筛选结果为空时，统计数字全部为0并显示“暂无班级”；在B页或教师页无匹配结果时，统计数字全部为0并显示对应空状态。空结果不伪装成加载失败。
4. 统计数据以当前通知接收范围和最新阅读/回执状态为准。接收状态更新后重新查看或刷新页面，应显示最新状态。
5. 读取失败时明确显示读取失败并允许重新读取；不能把失败当作0人，也不能覆盖已显示的筛选条件。
6. 学生或家长重复查看不会重复增加学生总数；多位家长的个人记录仍可在“明细”中分别查看。
7. 学生统计、教师统计页均不显示“提醒未读”按钮；提醒功能不在该页面提供。


##### 6.7 通知有效期、名单变化与编辑、删除、提醒

**有效时间和名单变化**

1. 已发布通知以实时名单为准。整班通知有效期内新增学生时，新增学生及其所有关联家长自动收到通知；定时发送通知在计划时间到达前加入的新学生，随计划时间收到通知。
2. 仅选择个别学生时，后续加入该班的学生不加入通知。
3. 学生转班或离校后，仍保留在原通知中，可以继续阅读、确认或签字并计入原通知统计；不会再因原班级关系收到该班后续通知。
4. 通知截止时间已设时，截止后不再增加新学生或新关联家长；未设截止时，从发送时间起30个自然日内接受新增对象。
5. 通知超过有效时间后仍可查看和统计；接收人不再能确认/签字，发布人不能编辑；允许删除。
6. 没有单独设置截止时间时，编辑成功后重新按编辑时间计算30个自然日；已设置的截止时间不可编辑，仍按原截止时间执行。编辑不会让已到期通知重新开放。

**修改**

1. Web可编辑学校、教师、代理商和运营后台创建的通知，但必须在该Web账号原有学校或授权范围内；新增来源可见性不扩大该账号权限。编辑内容限通知标题、正文及附件、封面和学校名义；原通知类型保持不变。
2. 发布对象、查收方式、发布时间、定时发送时间不能编辑；截止时间不作为当前确认的可编辑字段。
3. 发布后任一接收人已阅读、确认或签字，三个 Web 端的编辑按钮均置灰且不能提交；普通通知、美文通知使用相同限制。
4. 通知过期后不能编辑。编辑成功保留原发送设置和原有阅读/回执记录。
5. 编辑保留修改历史；前台不新增操作日志页面，也不向所有接收人发送“通知已修改”的提醒。

**删除**

1. 删除不受通知有效期限制；删除前须由用户再次确认目标。
2. 删除成功后，通知立即从学校 Web、代理商/运营代发列表、教师端和家长端消失；没有“已删除”状态、已删除页或恢复入口。
3. 删除不向接收人发送消息。删除时保留该通知当时的内容和发布设置、发布对象范围、每位教师及家长的阅读/确认/签字状态，以及删除操作人和删除时间。该留存仅用于管理追溯，普通用户页面不展示，也不提供恢复入口（按Q21/Q30所选A口径）。

**一键提醒**

1. 提醒只下发小程序提醒消息，不改变通知的阅读、确认、签字状态。
2. 学生汇总未读时，向该学生的所有关联家长提醒；任一家长已读后学生汇总已读，不再向该学生所有家长提醒。已读但尚未确认或签字的学生暂不提醒。
3. 教师按教师个人状态处理未读提醒；不把教师提醒与学生提醒混为一类。
4. 提醒不显示任务状态或成功/失败人数；失败不自动重试。用户再次点击时才发起新一次提醒。
5. 超过通知有效期后不能提醒。删除后的通知没有提醒入口。

##### 6.8 预览、打印和 PDF

1. 三个 Web 端从通知列表或发布/编辑页面点击“预览”时，统一显示小程序样式的手机边框预览。手机边框内展示小程序状态栏、导航栏和通知内容，页面外层标题为“通知预览”。
2. 预览内容反映当前通知已有内容；在发布或编辑过程中打开预览时，使用当前页面尚未保存的标题、封面、正文、附件和全文背景。预览为只读，不提供编辑、查收或签字操作。
3. 手机页面内展示通知标题、封面、正文内容块、图片、视频、链接和附件；不展示接收对象名单、已读/确认/签字统计、个人回执记录或发布设置。标题居中，过长时完整换行。
4. 列表入口打开独立“通知预览”页面：页面标题和底部操作栏固定，手机框内的通知正文独立滚动。发布/编辑入口打开手机框预览弹窗，关闭后回到原步骤并保留未保存内容；列表入口关闭后回到原筛选结果和页码。
5. 列表预览页面点击“导出 PDF”时，打印只使用隐藏的 A4 通知正文，不打印屏幕上的手机框、模拟状态栏、页面标题、“演示说明”或底部按钮。PDF 页边距为上37mm、右26mm、下35mm、左28mm，长内容可分页；屏幕预览始终保持手机框效果。
6. PDF 导出失败时留在当前手机框预览页，可再次手动导出；失败不改变通知内容。手机预览打开失败时，保留当前页面和已输入内容，用户可重新打开预览或返回。

##### 6.9 页面通用的校验和异常行为

| 场景 | 用户看到的结果 | 保留内容与后续操作 |
|---|---|---|
| 页面没有权限或目标学校不在授权范围 | 不展示无权通知或学校 | 可以返回有权页面，不以旧学校数据代替 |
| 数据正在读取 | 显示必要的读取中状态 | 不把尚未读完显示成0条或0人 |
| 列表或统计读取失败 | 显示简短失败信息和重新读取入口 | 保留筛选条件；不能把失败当成无数据 |
| 标题为空、正文为空或发布对象为空 | 阻止下一步/发布并定位缺项 | 保留已填内容 |
| 标题超过50字 | 阻止下一步/发布 | 不显示实时字数计数，保留输入便于修改 |
| 附件数量、格式或大小不符合要求 | 只拒绝不符合要求的文件并说明原因 | 其余有效附件保留 |
| 定时发送时间已过去 | 不允许发布 | 保留内容和对象，重新选择时间 |
| 学校 Web、代理商 Web的截止时间早于实际或计划发送时间 | 不允许发布 | 保留其他设置，允许调整截止时间；运营后台不展示截止时间字段 |
| 发布期间重复点击 | 只处理一次发布动作并显示处理中 | 不新增重复通知 |
| 发布后页面没有明确结果 | 返回列表核对目标学校和通知标题 | 已出现通知则不再重新发布；未出现才允许重试 |
| 编辑期间通知有人阅读/确认/签字 | 阻止保存并让用户知道此通知已不能编辑 | 当前通知内容和状态保持原样 |
| 删除已经成功 | 所有端均不再显示该通知 | 无恢复入口，也不显示“已删除”状态 |
| 家长/教师提交确认或签字时发生问题 | 保留通知详情和可恢复输入，核对当前状态后再继续 | 不重复产生一条确认/签字记录 |
| PDF导出失败 | 留在预览页并允许再次导出 | 不修改通知 |

#### 7. 数据、权限与跨端一致性要求

1. 一条通知始终归属一所学校；代理商和运营发布时先选学校，学校 Web 和教师小程序按当前学校账号进入，不再选学校。
2. Web 三端通知列表、通知详情、编辑限制、删除结果、统计口径应一致；不同端只在学校选择步骤、页面外框和角色权限上有差别。
3. 教师小程序、家长小程序和三个 Web 端显示同一通知内容和查收方式。已读/确认/签字状态按前述学生汇总规则与个人状态规则展示。
4. 新增学生、转班、离校和新绑定家长按实时名单规则处理；原通知接收人不因名单变化被从原通知移除。
5. 删除一条通知后，用户从所有接收端均不能继续查看其内容；管理留存记录不出现在普通操作页面。
6. 本文不定义菜单权限名称、组织数据来源或实现方式；各端只能按其已有账号权限显示菜单和允许的操作。
7. 用户输入内容、时间、所选学校、对象及查收方式在返回上一步时保持；用户主动取消时不误保存成已发布通知。

#### 9. 编号规则与未明确的业务边界

编号用于定位本功能中的页面要求与验收条件。尚未明确的业务边界单独列示；明确前，不推断接收范围或数据保留策略。


| 边界 | 已明确规则 | 仍需确认的内容 |
|---|---|---|
| 全年级新增班级范围 | 选择时已有班级中的整班学生按实时名单规则处理 | 之后新建的班级是否加入原通知，以及其中学生是否接收 |
| 更换目标学校时的内容保留范围 | 新通知只能属于一所学校；原发布对象名单不能直接用于新学校 | 更换学校后哪些通知内容保留、哪些字段清空，是否再次确认 |

已明确的提醒规则为：学生汇总未读时，提醒该学生所有关联家长；教师按个人未读状态提醒。全年级选中后，已选班级内新增学生按整班规则纳入；未来新建班级是否自动纳入仍待确认。

当前规则：Web新发布的通知类型为美文通知；通知类型仅有普通通知和美文通知，文字、图片、视频、链接等属于内容形式；家长端只接收、不发布，也不作为通知来源；学校可以查看本校教师、代理商和平台端通知，但编辑权限仍按对应角色授权；代理商和运营后台均不提供草稿。

### 当前列表、编辑、发布及跨端补充

- Web新建通知默认类型为美文通知；普通通知与美文通知是通知类型，文本、图片、视频、链接是内容形式。家长端只接收通知，不作为来源或发布端。
- 列表标题与筛选使用统一字段：目标学校、来源、标题、通知类型、查收方式、状态、发布时间；不出现发布人筛选。重置后输入清空、下拉恢复全部、分页回第1页。
- 学校、代理商、运营的PC发布设置中，标签和控件同一行、标题列宽统一、控件起始位置和高度一致。运营代发固定以学校名义发布；学校名义开关不能关闭。运营选择学校后才配置对象。
- 普通通知正文编辑保留唯一文本块，保持原通知类型；空正文不能保存。美文通知维持内容块编辑规则。
- Web通知预览使用手机框；手机内容区独立滚动，页面标题和底部操作保持可见。PDF为独立A4版式。
- 目标学校筛选支持学校名模糊输入并提供候选；地区可单独或与名称组合筛选。运营不得使用未经当前账号授权的学校执行新增、编辑、删除。

## 未明确的业务边界

- 选择全年级后，未来新建班级是否自动加入该通知接收范围尚未明确；已明确的是选择时已有班级及其学生按实时名单规则处理，所选年级中已选班级新增学生按整班规则处理。
- 从发布流程返回学校步骤并更换目标学校后，标题、正文、封面和附件是否保留尚未明确；无论最终选择如何，旧学校的学生/教师名单不能直接用于新学校，必须重新选择并校验对象。
