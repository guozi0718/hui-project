# 学校反馈｜学校 Web 功能说明

## 页面入口与范围

学校 Web 主菜单“学校反馈”使用稳定菜单 ID school-feedback。页面由统一菜单、顶部页签和链接宿主承载，列表、详情和新增反馈在同一功能页面中切换。

## 筛选条件

筛选项依次为反馈来源、反馈人、联系电话、反馈类型和状态。反馈来源可选全部、学校端、教师端、家长端；反馈类型为功能建议或问题反馈；状态为待回复或已回复。学校端不提供所在区域、所属单位或所在机构筛选。

“查询”应用当前条件；“重置”清空筛选并恢复默认列表。筛选区不展示任何组织归属字段。

## 列表字段与操作

列表依次展示反馈来源、反馈人、联系电话、关联学生、反馈类型、反馈内容、反馈时间、状态和操作。列表不展示所在区域、所属单位或所在机构。

“关联学生”紧跟联系电话：

- 家长反馈显示提交时保存的学生快照名称。
- 学校端和教师端反馈显示“—”。

学校反馈记录和四条教师/家长来源样例的操作均为“查看”。样例详情只读；查看样例不会改变记录状态或新增查看日志。

教师和家长来源样例详情提供“查看线索”，在新标签页打开运营后台对应人员资料。运营后台资料页的“反馈信息”页签展示该人员关联的反馈记录。

## 新增反馈

学校人员可以提交学校反馈。反馈类型、标题和内容为必填；标题长度为 1—50 个字符，正文长度为 1—200 个字符。附件可选，仅支持 JPEG、JPG、PNG 图片，最多 9 张、每张不超过 10MB。

校验失败时保留表单内容并提示需要修正的字段。提交成功后生成一条待回复反馈；提交后不能在学校端修改标题、类型、正文或附件。学校端列表和详情不提供回复、追问、删除或撤回操作。

## 反馈详情

反馈人信息区展示反馈来源、反馈人、联系电话和关联学生。详情不展示所在区域、所属单位或所在机构。家长来源关联学生取提交时的学生快照；学校端和教师端显示“—”。

反馈编号不放在反馈人信息区；编号和反馈类型显示在反馈内容区。消息按时间由近到远排列，附件随所属消息展示。代理商或运营发出的回复在学校端显示为“平台客服”，不显示个人客服姓名。

学校真实反馈仅允许查看；新增反馈后等待受理方答复，收到答复后状态为已回复。只有成功提出反馈时才新增学校操作日志；查看、查询及校验失败不记日志。

## 页面与弹窗

工作区保留统一左右留白，筛选区、列表和操作按钮在内容容器内对齐。详情及新增表单弹窗的标题行和底部操作行固定，中间内容区域独立滚动。弹窗宽度和字段布局按具体功能需要设置。

## 演示数据边界

当前记录、样例和表单结果保存在浏览器本地演示数据中，不连接生产账号权限、服务端持久化、真实客服消息服务或运营后台生产线索。
