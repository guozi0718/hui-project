# 学校 Web

本目录是学校 Web 主原型的唯一维护目录。当前最新版本为 v0.73；后续学校端修改只在本目录内新增递增版本并更新固定入口，不再关联功能项目。已发布版本保留，不覆盖。

## 固定入口

[打开学校端原型](https://guozi0718.github.io/hui-project/%E5%AD%A6%E6%A0%A1%E7%AB%AF/index.html?page=school-feedback)

固定入口读取 `当前版本.json` 指向的版本。进入后可从统一左侧菜单切换学校反馈和家校通知；顶部页签管理已打开的页面。

- 运行包：菜单页面、反馈/通知页面、脚本、样式和素材均随版本保存。

## 维护约定

后续修改从 `当前版本.json` 读取当前版本，在 `版本/` 下新建下一版本；保留现有版本和其功能说明，不把页面链接指向功能项目或本机地址。菜单切换应展示实际页面或明确错误提示，不以空白容器通过验收。菜单和页签沿用统一宿主；弹窗标题行及底部操作行固定，中间内容区滚动。

本原型使用本地示例数据，不连接生产权限、接口、通知投递或签收服务。
